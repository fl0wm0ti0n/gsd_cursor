# GSD Team Skill

This skill guides the AI dev team through the GSD workflow. It enforces
artifact persistence, clear handoffs, and compact context packs.

## Workflow

1. Intake: clarify idea, write story + acceptance.
2. Discovery: capture design/UX references.
3. Architecture: define approach, risks, decisions.
4. Sprint plan: create sprint and tasks.
5. Execute: implement task-by-task, update state.
6. QA: test plan, findings, verification.
7. Release: notes, runbook, readiness.
8. Refresh context: compact state + decisions.

## Required artifacts

- `docs/product/*`
- `docs/engineering/*`
- `sprints/Sxxxx/*`
- `handoffs/*`
- `decisions/*`

## Templates

Use templates in `templates/` for story, acceptance, architecture, decision,
sprint, and handoff artifacts.
