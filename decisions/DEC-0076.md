# DEC-0076 — Dual-level architecture story headings, diff-gated forward enforcement, and triad archiver extension (BUG-0010)

## Status

Accepted — 2026-06-06

## Context

**Composes on `DEC-0054`** (triad hot-surface compaction — `architecture.md` story-section
semantics) and **`DEC-0043`** (artifact ownership — history-preserving architecture
appends). Does **not** rewrite `DEC-0054` threshold keys or rollover locations.

Research anchor **`R-0076`** (`orchestrator_run_id=auto-20260606-02`) confirmed root
cause: `scripts/enforce-triad-hot-surface.py` `STORY_HEADING` matches only H1
`# US-\d{4}`; repos with H2 `## US-xxxx` story sections hit
`STATE_ARCHIVE_BOUNDARY_AMBIGUOUS` when `architecture.md` exceeds `ARCH_HOT_MAX_LINES`
because `split_arch_stories` returns zero boundaries.

Operator scope (intake): **both** tracks — (A) backward-compatible rollover for legacy
`## US-xxxx` sections; (B) forward enforcement mandating H1 `# US-xxxx` for new
`/architecture` writes.

## Decision

Adopt the architecture below. Acceptance-criteria traceability is published in
§AC-Traceability at the end.

### 1. Dual-level story-heading patterns (Option B — two-pattern scan + H1-wins)

Replace monolithic `STORY_HEADING` with:

```text
STORY_HEADING_H1 = ^# (?:US|BUG)-\d{4}\s*[:\u2014\-].+$
STORY_HEADING_H2 = ^## US-\d{4}\s*[:\u2014\-].+$
```

**Normative constraints**:

- H2 pattern matches **`## US-` only** — no `## BUG-` in v1 (kit inventory has no H2 BUG sections).
- Delimiter class `:`, `—` (U+2014), `-` identical for H1 and H2.
- Generic `## Foo` subheadings inside a story block are **not** story boundaries.

**Alternatives rejected**:

- **Option A** — single alternation regex: loses per-id H1-wins precedence (**R-0076** Q1).
- **Option C** — two-pass H1-blocks-first merge: complex ordering risk in mixed files (**R-0076** Q1).

### 2. `split_arch_stories` merge algorithm (normative)

1. Scan all lines; collect boundary candidates `(idx, story_id, level)` where line matches `STORY_HEADING_H1` or `STORY_HEADING_H2`.
2. Build `h1_ids = {story_id for candidates with level==1}`.
3. `boundaries = sorted([c for c in candidates if not (c.level==2 and c.story_id in h1_ids)], key=lambda c: c.idx)`.
4. Split preamble + contiguous blocks between boundary indices (unchanged oldest-first rollover loop in `rollover_architecture`).

**Precedence table** (regression anchor — kit-shaped mixed file: 26×H1 + 5×H2):

| Scenario | Precedence | Archival unit |
|----------|------------|---------------|
| `# US-0067` only | H1 boundary | Block from `# US-0067` to next boundary |
| `## US-0067` only (no H1 for 0067) | H2 boundary | Block from `## US-0067` to next boundary |
| Both `# US-0067` and `## US-0067` | **H1 wins** — H2 ignored as boundary | Single unit starting at `# US-0067` |
| Adjacent `## US-0068` then `## US-0069` (no H1) | Each H2 is boundary | Two units, oldest-first rollover |
| `### US-0099` or `## Architecture:` | **Not** a story boundary | Intra-section content |
| `# BUG-0009` | H1 boundary | Same as `# US-xxxx` |
| Preamble before first boundary | Retained in hot file | Never archived alone |

### 3. Forward enforcement — in-place extension (Option C — diff-gated hard fail)

Extend **`scripts/enforce-triad-hot-surface.py` in place** (stdlib-only). **Do not** add
`scripts/validate_architecture_headings.py` (**R-0076** Q3).

**API sketch** (same file):

| Function / flag | Purpose |
|-----------------|---------|
| `count_h2_story_headings(text: str) -> int` | Count lines matching `STORY_HEADING_H2` |
| `check_arch_heading_policy(text_after, baseline_h2_count: int) -> Optional[str]` | Return `ARCH_STORY_HEADING_LEVEL_INVALID` when `count_h2_story_headings(after) > baseline_h2_count` |
| `--check-arch-heading-policy [--baseline-h2-count N]` | CLI hook for `/architecture` triad gate step |

**`/architecture` step 9 contract** (active + `template/.cursor/commands/architecture.md`):

1. Capture `baseline_h2_count = count_h2_story_headings(architecture.md)` **before** mutating the file.
2. Append new section as H1 `# US-xxxx` (stories) or `# BUG-xxxx` (bugs).
3. Run `--rollover` then `--check` (existing triad gate).
4. Run heading policy check with captured baseline; on `ARCH_STORY_HEADING_LEVEL_INVALID` → **hard fail** (non-suppressible `blocked`).

**Alternatives rejected**:

- **Option A** — new standalone validator script: duplicates regex; extra installer surface (**R-0076** Q3).
- **Option B** — contract test only: no runtime enforcement at phase boundary (**R-0076** Q4).
- **Static fail on any `## US-`**: false-positive on kit repo's 5 grandfathered H2 sections (**R-0076** Q4).

**Grandfathering**: existing `## US-xxxx` sections remain rollover-visible; count **must not increase** during `/architecture`. Normalizing `##`→`#` (count decrease) is allowed.

### 4. Reason-code family (no proliferation without DEC)

| Code | When |
|------|------|
| `ARCH_STORY_HEADING_LEVEL_INVALID` | H2 `## US-xxxx` story-heading count increased during `/architecture` |
| `STATE_ARCHIVE_BOUNDARY_AMBIGUOUS` | (unchanged) oversize file, zero boundaries after dual-level scan |
| `ARTIFACT_HOT_SURFACE_OVERSIZE` | (unchanged) single block exceeds cap post-rollover |

### 5. Regression matrix and harness §29A

| Fixture class | Assert |
|---------------|--------|
| `##`-only rollover | 4× `## US-100x` over low `ARCH_HOT_MAX_LINES` → rollover moves ≥1; post `--check` exit 0 |
| `# US-` non-regression | Existing self-test `# US-0001`/`# US-0002` fixture unchanged |
| Mixed H1+H2 same id | `# US-0067` + `## US-0067` → single boundary at H1 |
| Idempotent second rollover | Second `--rollover` → no-op when within caps |
| Enforcement delta | `count_h2` increases → `ARCH_STORY_HEADING_LEVEL_INVALID` |
| Inner `##` subheading | `# US-0001` block containing `## Details` → no extra boundary |

### 7. Operator documentation — legacy `## US-` remediation

Ship verbatim blurb in runbook triad subsection (active + `template/`):

> **Architecture file blocked on rollover?** If story sections use legacy H2 `## US-xxxx`
> headings, the archiver now recognizes them for rollover after **BUG-0010**. For new work,
> `/architecture` must append H1 `# US-xxxx` (or `# BUG-xxxx` for defects). To converge an
> existing repo, optionally normalize `## US-xxxx` → `# US-xxxx` manually (count decrease is
> allowed; adding new `## US-` story headings is blocked).

**Out of scope**: mandatory bulk `##`→`#` normalization in kit repo (operator may remediate manually).

### 8. DEC-0054 §2 semantic amendment (doc-only)

`DEC-0054` §2 states story sections are `# US-xxxx` blocks. This decision **amends operational semantics** without renumbering `DEC-0054`:

- **Rollover read path**: accepts H1 `# US-xxxx`, H1 `# BUG-xxxx`, and legacy H2 `## US-xxxx` (H1-wins when both exist).
- **Authoring write path**: new story sections **must** be H1 `# US-xxxx`; new bug sections **must** be H1 `# BUG-xxxx`.

Threshold keys (`ARCH_HOT_MAX_LINES`, `ARCH_HOT_MAX_STORY_SECTIONS`) unchanged.

### 9. Non-goals

- No new standalone heading-validator script.
- No static fail on any pre-existing `## US-` in file.
- No `## BUG-` pattern in v1.
- No global markdownlint MD025 on entire `architecture.md`.
- No change to `state.md` or `po_to_tl.md` rollover semantics.
- No threshold key changes in scratchpad defaults.

## Consequences

- Downstream `##`-only repos can auto-archive when `architecture.md` exceeds caps.
- Kit mixed H1+H2 file rollovers without double-counting.
- New `/architecture` writes converge on canonical H1 story sections per **DEC-0054** intent.
- `STATE_ARCHIVE_BOUNDARY_AMBIGUOUS` narrows to genuinely unsliceable files (zero boundaries at either level).
