# DEC-0084: Dev environment auto-launch profile — detect, persist, relaunch, connect (US-0098)

- Date: 2026-06-14
- Status: Accepted
- Story: `US-0098`
- Composes on: **`DEC-0071`** / **US-0085** (no `.env` reads; names-only persisted refs), **US-0064** (connectivity schema unchanged), **US-0086** (remote precedence when both profiles on), **US-0065** (phase QA boundary), **US-0093** (`DEV_SERVER_*` / `process_health` compose)
- Related: **US-0067**, **`R-0085`**, **US-0099**, **`R-0086`**
- Supersedes: none

## Context

Operators on the Docker host need **execute-phase** rebuild/restart of dev stacks plus **Connect** surfacing after implementation changes — distinct from **US-0065** phase runtime QA, **US-0086** automation test routing, and **US-0067** release-only hints. Discovery and research locked a default-off scratchpad gate, local persisted profile JSON, four-label detection matrix, execute-triggered Tier A/B/C relaunch (no mandatory background watch daemon v1), and bounded retries.

Research basis: **`R-0085`** Q1–Q7.

## Decision

### 1. Scratchpad gate (AC-1)

| Key | Values | Default | Notes |
|-----|--------|---------|-------|
| **`DEV_AUTO_LAUNCH_PROFILE`** | **`off`** \| **`deterministic_v1`** | **`off`** | When **`off`**, execute step **24** skipped with zero overhead |
| **`DEV_ENVIRONMENT_CONFIG`** | repo-relative path | **`.cursor/dev-environment.json`** | Optional override |

Orthogonal to **`AUTO_REMOTE_AUTOMATION_PROFILE`** (**US-0086**). Publish in active + **`template/.cursor/scratchpad.md`** + **`template/.cursor/scratchpad.local.example.md`**.

**Rejected alternatives**:

- Always-on relaunch (**rejected** — breaks manual workflows; default-off required).
- Doc-only profile (**rejected** — schema/tier/detection need testable stdlib helper per **R-0085** Q5).

### 2. Profile schema v1 + git policy (AC-2)

**Canonical path**: **`.cursor/dev-environment.json`** (override via **`DEV_ENVIRONMENT_CONFIG`**). Committed example: **`template/.cursor/dev-environment.json.example`**.

| Field | Type | Operator seed | Agent write | Notes |
|-------|------|---------------|-------------|-------|
| **`schema_version`** | integer | optional | required | **`1`** for v1 |
| **`detected_mode`** | enum | optional | required | **`local`** \| **`docker-host-local`** \| **`docker`** \| **`ssh`** |
| **`operator_seeded`** | boolean | set **`true`** on first manual seed | may flip **`false`** after agent merge | audit only |
| **`last_updated`** | ISO UTC string | optional | required on write | idempotent merge key |
| **`compose_file`** | string path | yes | yes | required for docker modes when known |
| **`service`** | string | yes | yes | compose service name |
| **`target_id`** | string | yes | yes | when **`docker`**/**`ssh`** via **US-0086** |
| **`connect`** | object | yes | yes | **`endpoint`**; **`health_path`**; **`*Env`** keys only (**`hostEnv`**, **`portEnv`**, **`protocolEnv`**) — never values |
| **`rebuild_recipe`** | object | optional | yes | **`default_tier`** **`A`**\|**`B`**\|**`C`**; optional command templates (no secret literals); optional **`restart_on_source_change`** (default **`false`**) |
| **`env_refs`** | string[] | yes | merge | sorted unique env **names** only |
| **`evidence_refs`** | string[] | no | append | sprint/task/handoff refs |

| Artifact | Track in git? |
|----------|---------------|
| **`template/.cursor/dev-environment.json.example`** | **yes** — names-only placeholders |
| **`.cursor/dev-environment.json`** | **no** — add to **`.gitignore`** + **`.cursorignore`** |

**Bootstrap posture (US-0099 — amended 2026-06-14)**:

| Surface | Contract |
|---------|----------|
| **When** | **`installer.py`** **`missing`** + **`upgrade`** after **`run_scratchpad_postinstall`**, before **`bootstrap_runbook_commands`**; **`bin/postinstall.js`** via **`dev_environment_lib.py --bootstrap`** |
| **Action** | Copy **`template/.cursor/dev-environment.json.example`** → resolved path (**`DEV_ENVIRONMENT_CONFIG`** or default **`.cursor/dev-environment.json`**) **only when target absent** |
| **Never** | Overwrite, merge, or byte-refresh an existing local profile |
| **Reason family** | **`DEV_ENV_BOOTSTRAP_*`** (install-time) — distinct from **`DEV_ENV_PROFILE_*`** (runtime) |
| **Contrast** | **`.cursor/remote.json`** remains **manual-seed** (opt-in remote; default-off **US-0086**) |

**No change** to **`release-targets.json`** schema (**US-0064** unchanged).

### 3. Detection matrix + precedence (AC-3, AC-6)

| Mode | Meaning | Resolution |
|------|---------|------------|
| **`local`** | Process dev server on workstation | **`DEV_SERVER_COMMAND`** / stack profile inferable |
| **`docker-host-local`** | Same-machine compose/docker (operator on Docker host) | Compose resolvable + local **`docker`** CLI succeeds |
| **`docker`** | Remote docker target | **US-0086** resolves docker-type target |
| **`ssh`** | Remote SSH hop target | **US-0086** resolves ssh-type target |

**Precedence algorithm**:

1. **`DEV_AUTO_LAUNCH_PROFILE=off`** → no detection/relaunch.
2. Load profile from **`DEV_ENVIRONMENT_CONFIG`** or default path.
3. When **`AUTO_REMOTE_AUTOMATION_PROFILE=deterministic_v1`** **and** **US-0086** resolves target: docker → **`docker`**; ssh → **`ssh`** (**US-0086** wins over **docker-host-local**).
4. Else when compose resolvable + local **`docker`** CLI succeeds → **`docker-host-local`**.
5. Else when **`DEV_SERVER_COMMAND`** or stack inferable → **`local`**.
6. Else → fail closed **`DEV_ENV_DETECT_AMBIGUOUS`**.

### 4. Tier A/B/C relaunch table (AC-4, AC-8)

**Highest matching tier wins** when multiple file classes touch in one execute task. Shared container surface globs align with **US-0086** / **`R-0068`**.

| Tier | Action | Key patterns | Recipe |
|------|--------|--------------|--------|
| **A — rebuild** | image rebuild + recreate | `Dockerfile*`, lockfiles, dependency manifests, `docker-compose*.yml`, `compose.y*ml` | `docker compose build` + `up -d` |
| **B — restart** | config / non-hot-reload | `*.env.example`, nginx/traefik configs, `application.y*ml`, entrypoint scripts under `scripts/docker/` or `docker/` | `docker compose restart <service>` or process restart |
| **C — local dev server** | process restart | **`detected_mode=local`**; hot-reload source paths when A/B absent | **`DEV_SERVER_COMMAND`** / stack profile |
| **Skip** | no relaunch | docs/tests/handoffs/sprints unless runtime script matches A/B | **`DEV_ENV_RELAUNCH_SKIPPED_NO_SURFACE`** |

**Bind-mounted source on docker-host-local**: when only Tier C-like paths change and **`rebuild_recipe.restart_on_source_change=false`** (default), emit **`DEV_ENV_RELAUNCH_SKIPPED_NO_SURFACE`** — operator may force via explicit refresh (**§6**).

**v1 exclusion**: no mandatory unbounded **`docker compose watch`** daemon — execute-triggered automation only.

**Bounded retries**: **`retry_count`** max **2** (attempts 0..1 retry); delays **5s** then **15s**; non-transient failures fail fast.

### 5. Execute step 24 (AC-4, AC-5, AC-7)

Placement: after step **23** (**US-0097**), before execute completion / QA handoff.

| Sub-step | Contract |
|----------|----------|
| **24 (preamble)** | Read **`DEV_AUTO_LAUNCH_PROFILE`** (default **`off`**) and optional **`DEV_ENVIRONMENT_CONFIG`**. When **`off`**, skip **24a–24d** with zero overhead. |
| **24a Gate + profile load** | Validate profile path; names-only schema check; fail → **`DEV_ENV_PROFILE_INVALID`**. Missing + no infer → **`DEV_ENV_PROFILE_MISSING`**. |
| **24b Detection + persist** | Run detection (**§3**); merge fields idempotently into profile file. |
| **24c Relaunch (bounded)** | When touched files match Tier A/B/C **or** explicit refresh fired: run tier recipe; bounded retries (**§4**). |
| **24d Connect + handoff** | Append **Dev environment relaunch** + **Connect** sections to **`handoffs/dev_to_qa.md`**. |

**Orthogonality**: step **18** (**US-0065**) runtime QA autopilot — distinct evidence. Step **17** (**US-0084** remote cues) composes when both fire.

### 6. Explicit refresh hook (AC-7)

| Trigger | v1 behavior |
|---------|-------------|
| **Primary NL phrase** | Exact literal **`refresh dev environment`** (case-sensitive, whole-phrase match) |
| **Runbook synonyms** | Documentation only — not parsed v1 |
| **Profile off** | **`DEV_ENV_PROFILE_DISABLED`** + remediation |
| **Explicit refresh** | Always attempts relaunch (tier from **`rebuild_recipe.default_tier`** or **B** when unset) even without file-class match |

### 7. Connect block + composition (AC-5, AC-6)

Mandatory fields when step **24** runs and profile **on**: `runtime_mode`, `connect_endpoint`, `health_path`, `service_id`/`container_id`, `target_id` (when remote), `env_refs`, `relaunch_outcome`. Align **`docs/engineering/runtime-connectivity.md`** — no parallel connectivity schema.

**US-0093** **`process_health`** may consume relaunch outcome; **US-0098** owns profile + rebuild orchestration.

### 8. Stdlib helper (AC-9)

Ship **`scripts/dev_environment_lib.py`** (+ **`template/scripts/`** mirror):

| Function / CLI | Purpose |
|----------------|---------|
| **`load_profile(path) -> dict`** | Parse JSON; reject inline secrets |
| **`classify_touched_files(paths) -> tier\|None`** | Tier table |
| **`detect_mode(repo, profile, scratchpad) -> (mode, reason_code\|None)`** | Detection precedence |

| **`python scripts/dev_environment_lib.py --self-test`** | **`[DEV_ENVIRONMENT_SELF_TEST_OK]`** |

### 9. Security audit (AC-2, AC-8) — US-0085 inheritance

| Layer | Control |
|-------|---------|
| 1 — Schema | Reject inline secret-like literals; only **`*Env`** suffix keys in **`connect`** |
| 2 — Ignore files | **`.gitignore`** + **`.cursorignore`** block local profile |
| 3 — Agent rules | No **`.env`** read; Connect lists **`env_refs`** names only |
| 4 — Runtime | Relaunch subprocess inherits operator shell env — helper never opens **`.env`** |

Violation → **`DEV_ENV_SECRET_SURFACE_VIOLATION`**.

## Risks

| Risk | Mitigation |
|------|------------|
| **R1** Relaunch loops / duplicate containers | **`retry_count`≤2** + idempotent profile writes + no watch daemon v1 |
| **R2** **docker-host-local** conflated with remote docker | Precedence step **3** vs **4** + explicit matrix |
| **R3** Secret leakage in persisted profile | Four-layer audit + gitignore local profile |
| **R4** Execute step proliferation | Step **24** gated default-off |
