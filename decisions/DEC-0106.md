## 1. Context

US-0106 boots a single YAML manifest (`.cursor/sovereign-role-manifest.yaml`) that declares:

- per-role `objective_function` (what each role optimizes),
- a directed `review_obligations` graph (who reviews whom for what, at which phase boundary),
- `allowed_self_overrides` (closed enum of mutable facets — hard constraints immutable),
- `cross_model_policy` (ordering with US-0104 critic at boundary),
- `escalation_rules` (blocking-review → US-0107 deferral chain).

The manifest is the **additive** layer on top of US-0069 spawn machinery. Review spawns are supplementary post-phase hooks, never substitutes for the US-0069 producer role.

## 2. Decision

### 2.1 Scratchpad keys (default OFF — zero overhead)

| Key | Default | Semantics |
|-----|---------|-----------|
| `SOVEREIGN_ROLE_MANIFEST` | `0` | Master switch. When `0`: no manifest reads, no objective injection, no review dispatch. |
| `SOVEREIGN_ROLE_OBJECTIVE_MAX_CHARS` | `512` | Hard truncate for `role_objective_block` at spawn. |
| `SOVEREIGN_ROLE_REVIEW_MAX_PER_PHASE` | `2` | Cap on obligations dispatched per completed producer phase. |

When `SOVEREIGN_ROLE_MANIFEST=0`, overhead is strictly zero (no file I/O, no spawn, no dispatch). This is the contract-test anchor for `test_us0106_zero_overhead_default`.

### 2.2 YAML v1 schema

```
schema_version: 1
roles:
  - role_id: <po|tech-lead|dev|qa|release|curator>
    objective_function: <1..1024 chars>
    constraints: []          # optional, immutable strings
review_obligations:
  - obligation_id: <slug>
    reviewer_role: <role_id>
    target_role: <role_id>
    trigger_phase: <canon phase_id from US-0069 matrix>
    review_focus: <user_value_drift|testability|buildability|deployability>
    artifact_refs: [<bounded path/glob>...]
    blocking: <bool>         # default false
allowed_self_overrides:
  <verbosity|detail_level|tone>: <bool>
cross_model_policy:
  default_order: <role_review_first|critic_first|critic_only|role_review_only>
  overrides: []              # optional {obligation_id, order}
escalation_rules:
  blocking_review_action: <rework_then_gate|gate_only|defer>
  rework_max: <int>          # default 1
  deferral_reason_code: ROLE_REVIEW_BLOCKED
```

### 2.3 Validator CLI

`scripts/sovereign_role_manifest_validate.py` with flags `--file`, `--repo`, `--self-test`, `--enforce`. Success token `[SOVEREIGN_ROLE_MANIFEST_VALIDATION_OK]`. Fail-closed on:

- unknown `role_id` (not subset of US-0003 canonical roles)
- unknown `trigger_phase` (not in US-0069 phase matrix)
- cyclic obligations without `escalation_rules` escape
- `objective_function` > 1024 chars
- secret-shaped literals (API_KEY, TOKEN patterns)

### 2.4 Lib API

`scripts/sovereign_role_manifest_lib.py`:

- `load_manifest(scratchpad) -> dict`
- `resolve_role_objective(role_id, manifest) -> str`
- `build_objective_injection_block(scratchpad, role_id) -> str` (truncate to `SOVEREIGN_ROLE_OBJECTIVE_MAX_CHARS`)
- `list_obligations_for_phase(phase_id, target_role, manifest) -> list` (cap `SOVEREIGN_ROLE_REVIEW_MAX_PER_PHASE`)
- `dispatch_role_review(obligation, producer_evidence, scratchpad) -> dict`
- `self_test() -> bool` → `[SOVEREIGN_ROLE_MANIFEST_SELF_TEST_OK]`

`SOVEREIGN_ROLE_MANIFEST=0` short-circuits all reads to no-op.

### 2.5 Review dispatch contract

After producer phase checkpoint passes US-0069 **`PHASE_ROLE_*`** gates:

1. `list_obligations_for_phase(completed_phase, producer_role, manifest)`
2. For each obligation (cap `SOVEREIGN_ROLE_REVIEW_MAX_PER_PHASE`): spawn fresh **reviewer** subagent with `reviewer_role` capability preflight + `role_review` boundary token (distinct from phase role).
3. Reviewer produces read-only verdict against `artifact_refs[]`.
4. Append row to `handoffs/sovereign_role_reviews.jsonl`:

```
{schema_version:1, obligation_id, reviewer_role, target_role, trigger_phase,
 orchestrator_run_id, ts, verdict:{pass|fail|waived}, blocking, findings_ref}
```

Spawn-only per BUG-0006 / US-0069. Review spawn is never a substitute for producer phase completion.

### 2.6 `cross_model_policy` (US-0104 compose)

Four ordered modes:

| Mode | Effect |
|------|--------|
| `role_review_first` | role review → critic (US-0104) |
| `critic_first` | critic → role review |
| `critic_only` | skip role review at that boundary |
| `role_review_only` | skip critic at that boundary |

Per-obligation `overrides[]` may refine. Critic lenses and `sovereign_critic_findings.jsonl` schema unchanged. When either `CROSS_MODEL_REVIEW=0` or `SOVEREIGN_ROLE_MANIFEST=0`, the corresponding branch is zero overhead.

### 2.7 `escalation_rules` (US-0107 compose)

Blocking review verdict `fail` rule chain:

1. Bounded same-role rework (cap `SOVEREIGN_ROLE_REVIEW_REWORK_MAX` default `1`).
2. On rework cap exhaustion: operator `decision_gate`.
3. When `blocking_review_action=defer` + `AUTO_SOVEREIGN=1`: optional `sovereign_loop_lib.append_deferral(reason_code=ROLE_REVIEW_BLOCKED, ...)` → US-0107 register. Fail-open on deferral errors (log `ROLE_REVIEW_DEFERRAL_FAILED`, do not block).

US-0107 `sovereign_deferrals.jsonl` schema unchanged.
