# DEC-0078: Full-autonomy flow mode, outer driver, self-verify UAT, and TOKEN_PROFILE orthogonality (US-0092)

- Date: 2026-06-06
- Status: Accepted
- Story: `US-0092`
- Composes on: **`US-0088`** (continuous `/auto` + outer-driver equivalence class), **`DEC-0062`** (token-cost metrics — **`TOKEN_PROFILE`** semantics narrowed to context breadth only), **`DEC-0047`** (runtime QA autopilot — probe catalog extension), **`DEC-0048`** (generated-test auto-run — baseline test probe path)
- Extends: **`DEC-0069`** (boundary refresh at drain segments), **`DEC-0038`** (strict runtime proof unchanged), **`DEC-0022`** (backlog drain)
- Related: **`US-0044`**, **`US-0065`**, **`US-0066`**, **`US-0080`**, **`US-0087`**, **`R-0078`**
- Supersedes: none

## Context

**US-0088** documents continuous multi-phase `/auto` and backlog drain, but Cursor often ends the orchestrator turn after one phase — operators must manually re-invoke `/auto` despite scratchpad auto flags. **US-0092** ships an **opt-in** **`AUTO_FLOW_MODE=full_autonomy`** (exact literal, default-off) with a **stdlib outer-driver script**, expanded self-verify for **`/verify-work`** and **`/qa`**, bounded block auto-resolve, drain-without-pause, and a **`TOKEN_PROFILE`** orthogonality audit so tier choice affects **context breadth / token cost only** — never automation level, phase depth, drain, or outer-driver invocation.

Operator hard constraint (intake): conflicting prose implying **`TOKEN_PROFILE`** gates automation must be removed (**known conflict**: runbook “lowers default automation breadth” in active + template).

## Decision

### 1. Flow-mode contract (AC-1)

**`AUTO_FLOW_MODE`** enum (architecture-locked literals):

| Value | Semantics |
|-------|-----------|
| **`manual`** | Default when unset — operator invokes phases explicitly. |
| **`auto_until_decision`** | Existing — continuous until **`decision_gate`**. |
| **`full_autonomy`** | **New** — enables outer-driver loop, relaxable transient stops, drain-without-pause; **default-off**. |

**Orthogonal keys (unchanged semantics)**:

| Key | Role under **`full_autonomy`** |
|-----|--------------------------------|
| **`TOKEN_PROFILE`** | **`lean` \| `balanced` \| `full`** — context breadth / token cost **only** (**DEC-0062** / **US-0080**); **must not** change flow mode, drain, driver invocation, or phase depth. |
| **`PHASE_MODE`** / **`PERMISSION_MODE`** | Unchanged — no substitution for **`full_autonomy`**. |
| **`AUTO_BACKLOG_DRAIN`** / **`AUTO_BUG_QUEUE`** | Compose per **US-0044** / **US-0087** scheduler mutex. |
| **`AUTO_LOOP_MAX_CYCLES`** / **`AUTO_BACKLOG_MAX_STORIES`** | Hard caps — unchanged. |
| **`RELEASE_PUBLISH_MODE=auto`** | Explicit opt-in for publish — unchanged default-off. |

**New scratchpad keys (architecture-locked)**:

| Key | Default | Scope |
|-----|---------|-------|
| **`AUTO_BLOCK_RETRY_MAX`** | **`3`** | Per **`(story_id, stop_reason)`** recoverable retries before **`BLOCK_RETRY_CAP_EXHAUSTED`**. |
| **`AUTO_OUTER_DRIVER_TIMEOUT_SECONDS`** | unset (no timeout) | Optional subprocess/hook timeout → exit **124**. |

### 2. Shipped outer-driver script (AC-2)

**Path**: **`scripts/auto_outer_driver.py`** (active) + **`template/scripts/auto_outer_driver.py`** (**US-0017**).

**Stdlib-only**: **`argparse`**, **`json`**, **`hashlib`**, **`pathlib`**, **`subprocess`**, **`re`**, **`datetime`**.

**Activation gate**: merged scratchpad **`AUTO_FLOW_MODE=full_autonomy`** required — else exit **2** with **`AUTO_FLOW_MODE_NOT_FULL_AUTONOMY`**.

**Argv**:

| Flag | Purpose |
|------|---------|
| **`--repo PATH`** | Repository root (default `.`). |
| **`--max-cycles INT`** | Optional override of **`AUTO_LOOP_MAX_CYCLES`**. |
| **`--max-stories INT`** | Optional override of **`AUTO_BACKLOG_MAX_STORIES`**. |
| **`--dry-run`** | Emit planned invocations only. |
| **`--invoke-cmd TEXT`** | Optional shell prefix for documented **`/auto`** hook; default prints normative **`/auto …`** line. |

**Loop body**: (1) read **`handoffs/resume_brief.md`** **`intended_resume_phase`** + **`orchestrator_run_id`**; (2) invoke hook; (3) parse **`state.md`** phase-boundary for **`stop_reason`**, **`next_scheduled_phase`**, drain counters; (4) branch — continue, drain-advance, block-retry, or exit.

**Exit codes**:

| Code | Meaning |
|------|---------|
| **0** | **`completed`** — segment/portfolio terminal per policy. |
| **1** | Hard stop — **`decision_gate`**, unrecoverable **`error`**, isolation/strict-proof failure, security deny. |
| **2** | Configuration — **`AUTO_FLOW_MODE`** not **`full_autonomy`**, scratchpad parse failure. |
| **3** | **`loop_max`** — **`AUTO_LOOP_MAX_CYCLES`** exhausted. |
| **4** | **`BACKLOG_MAX_STORIES_REACHED`** / drain cap. |
| **5** | **`pause_request`** / **`AUTO_PAUSE_REQUEST`**. |
| **6** | **`BLOCK_RETRY_CAP_EXHAUSTED`**. |
| **124** | Subprocess/hook timeout. |

**Spawn-only preserved**: script **loops invocations**, never performs phase-role work (**`BUG-0006`** / **`AUTO_ORCHESTRATOR_PHASE_EXECUTION`** unchanged).

**Rejected alternatives** (per **`R-0078`** Q1): documented Cursor hook only (sole delivery); **`/loop`** composition (in-session cadence, not cross-turn lifecycle).

### 3. Full_autonomy stop matrix (AC-7)

**Invariant**: **`full_autonomy`** relaxes **recoverable transient stops** and **operator re-invocation**, not **governance gates**.

| Condition | **US-0088** (all modes) | **`full_autonomy` delta** |
|-----------|-------------------------|---------------------------|
| Next phase, no hard stop | Continue inner `/auto` | Same; outer driver **re-invokes** when Cursor ends turn early |
| **`decision_gate`** | Hard stop | **No change — hard** |
| Unrecoverable **`error`** | Hard stop | **No change — hard** |
| Critical **`missing_input`** | Hard stop | **No change — hard** |
| Transient **`missing_input`** (recoverable) | Hard stop | **Relaxable** — bounded block-retry |
| **`pause_request`** / **`AUTO_PAUSE_REQUEST`** | Hard stop | **No change — hard** |
| **`loop_max`** / **`AUTO_LOOP_MAX_CYCLES`** | Hard stop | **No change — hard** |
| **`blocked`** — sync/scope/transient | Hard stop | **Relaxable** when ledger classifies recoverable |
| **`blocked`** — isolation / strict-proof / ownership | Hard stop | **No change — hard** |
| UAT/QA fail | Hard stop (operator) | **Relaxable** when **`AUTO_IMPLEMENTATION_LOOP=1`** |
| Segment complete + **`AUTO_BACKLOG_DRAIN=1`** | Advance (may need manual re-**`/auto`**) | **Drain-without-pause** — outer driver schedules next item **immediately** |
| **`BACKLOG_MAX_STORIES_REACHED`** | Hard stop | **No change — hard** |
| **`AUTO_SCHEDULER_CONFLICT`** | Hard stop | **No change — hard** |
| **`RELEASE_PUBLISH_MODE=auto`** | Explicit opt-in | **No change — hard default-off** |
| Security deny (**.env`**, intake evidence mutation) | Hard deny | **No change — hard** |

### 4. Self-verify UAT probe contract (AC-3)

**Shared resolver lib**: **`scripts/uat_probe_lib.py`** (+ **`template/scripts/`** mirror).

**Probe catalog** (acceptance step → probe):

| Probe kind | Resolves when | Execution |
|------------|---------------|-----------|
| **`build`** | Stack profile maps build script | Subprocess, bounded timeout |
| **`test`** | **`TEST_COMMAND`** non-empty or profile default (**DEC-0048**) | Subprocess |
| **`api_health`** | **`runtime-connectivity.md`** or acceptance names URL/health | HTTP GET (stdlib **`urllib`**) |
| **`process_health`** | Acceptance names startup command (**DEC-0047**) | Subprocess + readiness poll |
| **`browser_smoke`** | Web stack + optional **`PLAYWRIGHT_*`** / curl fallback | Subprocess or HTTP |
| **`cli_smoke`** | Acceptance names CLI + expected exit/output | Subprocess |
| **`manual_operator`** | Step requires human judgment | **Not auto-run** |

**Fail-closed reason codes** (no silent PASS):

| Code | When |
|------|------|
| **`UAT_PROBE_UNRESOLVED`** | Step cannot map to any probe |
| **`UAT_STACK_PROFILE_UNKNOWN`** | No deterministic profile from repo signals |
| **`UAT_PROBE_TIMEOUT`** | Probe exceeded bounded timeout |
| **`UAT_PROBE_FAILED`** | Probe ran; assertion failed |
| **`UAT_PROBE_FORBIDDEN`** | Would require **`.env`**, secret path, or intake evidence mutation |
| **`UAT_PROBE_PASS`** | Probe succeeded (evidence recorded) |

**Evidence surfaces**: **`uat.json`** `probe_results[]`, **`qa-findings.md`** — path refs for stdout/stderr, not inline secrets.

**Composition**: **`/verify-work`** and **`/qa`** share resolver; generated-project fast path when **`stack_profile=generated`** (**US-0065** / **US-0066**).

### 5. Block-retry ledger (AC-4)

**Path**: append-only **`handoffs/auto_block_retry/<orchestrator_run_id>.jsonl`** — names-only; no secrets, no file contents.

**Record schema** (one JSON object per line):

```json
{
  "attempt_id": "br-<orchestrator_run_id>-<seq>",
  "timestamp": "<ISO8601Z>",
  "orchestrator_run_id": "<id>",
  "story_id": "US-xxxx|BUG-xxxx|(none)",
  "stop_reason": "blocked|missing_input|uat_fail|qa_fail",
  "reason_code": "<optional sub-code>",
  "remediation_action": "execute|qa|verify-work|refresh-context|outer_reinvoke",
  "outcome": "retry_scheduled|hard_stop|cap_exhausted",
  "outer_cycle_index": 1,
  "implementation_loop_index": 1
}
```

**Cap interaction**:

| Cap | Scope |
|-----|-------|
| **`AUTO_LOOP_MAX_CYCLES`** | Outer-driver **`/auto`** invocations (incl. drain advances) |
| **`AUTO_IMPLEMENTATION_LOOP`** | Inner **`execute`↔`qa`↔`verify-work`** remediation when **`1`** |
| **`AUTO_BLOCK_RETRY_MAX`** | Per-**`(story_id, stop_reason)`** recoverable retries |
| **`AUTO_BACKLOG_MAX_STORIES`** | Drain breadth — outer driver exit **4** |

**Ordering**: outer driver checks **`AUTO_LOOP_MAX_CYCLES`** first; inner orchestrator checks **`AUTO_IMPLEMENTATION_LOOP`** + **`AUTO_BLOCK_RETRY_MAX`** before scheduling remediation; unrecoverable classes bypass ledger.

### 6. Drain-without-pause (AC-5)

With **`AUTO_FLOW_MODE=full_autonomy`** + drain/bug-queue enabled, segment completion triggers **immediate** next-item scheduling via outer driver without operator re-run. **`handoffs/resume_brief.md`** + **`docs/engineering/state.md`** refresh per **DEC-0069** at every boundary.

### 7. TOKEN_PROFILE orthogonality audit (AC-6)

**Hard rule**: **`TOKEN_PROFILE=lean|balanced|full`** affects **context breadth / token cost only** — never automation level, phase depth, drain, outer-driver invocation, or **`AUTO_FLOW_MODE`**.

**Grep scope** (active + **`template/`** where mirrored):

| Surface | Purpose |
|---------|---------|
| **`.cursor/scratchpad.md`**, **`template/.cursor/scratchpad.md`**, **`.cursor/scratchpad.local.example.md`** | Comment blocks |
| **`docs/engineering/auto-orchestration-reference.md`** | TOKEN_PROFILE tier prose |
| **`docs/engineering/runbook.md`** | Token-cost section — **fix** “automation breadth” conflict |
| **`README.md`**, **`template/README.md`** | Operator-facing tier docs |
| **`.cursor/commands/auto.md`** | Cross-refs only |

**Forbidden pattern grep** (contract negative assertions): `automation breadth`, `lowers default automation`, `TOKEN_PROFILE.*drain`, `TOKEN_PROFILE.*outer`, `TOKEN_PROFILE.*full_autonomy`, `lean.*less automation`, `full.*more automation`.

**Contract-test markers** (execute): positive **`TOKEN_PROFILE controls context breadth / token cost only`**; positive **`AUTO_FLOW_MODE=full_autonomy`** literal; negative runbook must not contain **`lowers default automation breadth`** after fix; positive **`scripts/auto_outer_driver.py`** exists post-execute.

### 8. Security (AC-10)

**`full_autonomy`** must not auto-read **`.env`**, mutate intake evidence, or publish without **`RELEASE_PUBLISH_MODE=auto`**. Block-retry ledgers are names-only (no secrets).

## Alternatives considered

1. **Manual-only outer driver** (US-0088 Option B equivalence class alone) — rejected; **US-0092** requires shipped script.
2. **`/loop` command** as outer driver — rejected; in-session cadence, not **DEC-0038** / **DEC-0069** boundary refresh.
3. **`TOKEN_PROFILE=lean`** as proxy for automation depth — rejected (operator constraint + **DEC-0062** non-goals).
4. **Silent PASS on unresolvable UAT steps** — rejected; fail closed **`UAT_PROBE_UNRESOLVED`**.

## Consequences

- **`/execute`** implements outer driver, probe lib, ledger writer, orthography fixes, contract tests, and template parity per sprint tasks.
- **`/architecture`** **`# US-0092`** is normative companion; **`R-0078`** research findings narrowed by this decision’s literals.
- Isolation (**US-0048**) and strict-proof (**DEC-0038**) gates remain mandatory and non-relaxable under **`full_autonomy`**.
