# DEC-0040: Deterministic Artifact Ordering Matrix and Fail-Safe Write Contract

- Date: 2026-03-14
- Status: Accepted
- Related story: US-0058
- Research refs: R-0033

## Context

Workflow artifacts were being updated with mixed insertion directions and
inconsistent ordering, reducing trust in `state.md`, `backlog.md`, and
`acceptance.md`.

## Decision

1. Introduce a canonical ordering matrix in
   `docs/engineering/artifact-ordering-policy.md`.
2. Require command contracts that mutate workflow artifacts to reference and
   follow this matrix.
3. Enforce append-bottom checkpoints for `state.md`.
4. Enforce sorted-canonical story ordering for backlog and acceptance surfaces.
5. Fail closed on missing/ambiguous placement anchors with
   `ARTIFACT_ORDERING_ANCHOR_AMBIGUOUS`.
6. Require idempotent no-op reruns with no ordering oscillation.

## Consequences

- Artifact updates become deterministic and auditable across command runs.
- Operators receive explicit fail-safe diagnostics for anchor issues.
- Regression coverage and active/template parity are required to keep behavior
  stable over time.
