# DEC-0110: Goal-Based Convergence Loops (US-0110)

- **Date**: 2026-06-28
- **Status**: Accepted
- **Story**: `US-0110`
- **Composes on**: **US-0088** (quiet mode), **US-0092** (full-autonomy outer driver), **US-0095** (native-chain segments), **US-0044** (backlog drain), **US-0103** (decision ledger) — **do not amend**; US-0110 **reads** composed surfaces only
- **Related**: `R-0091` (research anchor), **US-0104** (critic findings — optional conjunct), **US-0107** (deferral register + drain-generate consumer), **US-0109** (deploy smoke — orthogonal v1), **US-0045** (status authority)
- **Supersedes**: none
- **Default-off**: `SOVEREIGN_GOAL_MODE=phase_driven` — zero overhead when not `goal_convergence`

## Context

Sovereign-loop terminal condition (US-0103..US-0110). When operators enable goal-driven autonomy, the outer driver needs a deterministic **convergence predicate** beyond per-segment phase exhaustion, **mid-loop progress visibility**, and a **partial-delivery artifact** on timeout. **US-0088 / US-0092 / US-0095 / US-0044 / US-0103 are UNCHANGED** — US-0110 evaluates read-only compose surfaces and emits its own artifacts only.

Research basis: `R-0091` Q1–Q7 closed.

## Decision

### §1 — Scratchpad keys (AC-1)

| Key | Values | Default | Notes |
|-----|--------|---------|-------|
| **`SOVEREIGN_GOAL_MODE`** | **`phase_driven`** \| **`goal_convergence`** | **`phase_driven`** | When `phase_driven`, zero overhead — no evaluation, no `goal_progress`, no partial-delivery write. |
| **`SOVEREIGN_GOAL`** | free-text string | *(empty)* | Explicit goal text; wins over vision auto-derive. |
| **`SOVEREIGN_GOAL_TOP_N`** | int ≥ 1 | **`3`** | Vision auto-derive paragraph count. |
| **`SOVEREIGN_GOAL_MAX_CHARS`** | int ≥ 64 | **`512`** | Truncation cap for explicit or derived goal text. |
| **`SOVEREIGN_GOAL_TIMEOUT_MAX`** | int ≥ 0 | **`0`** | **Iteration count** (drain-loop evaluations), not wall-clock. `0` = disabled. |

Both active + **`template/.cursor/scratchpad.md`** byte-parity per **US-0017**.

**Rejected**: wall-clock timeout as v1 default (**rejected** — non-deterministic across pause/resume; iteration count aligns with **US-0092** drain loops).
**Rejected**: mandatory goal text without auto-derive fallback (**rejected** — vision auto-derive covers zero-config path).

### §2 — `ConvergenceResult` schema v1 (AC-2)

Returned by `evaluate_convergence(repo, scratchpad) -> ConvergenceResult`.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| **`converged`** | bool | yes | `true` iff all **active** conjuncts pass |
| **`unmet_conditions`** | string[] | yes | Human-readable gaps; includes informational skips |
| **`blocked_by`** | string[] | yes | Reason codes blocking convergence |
| **`conjuncts`** | object | yes | Per-conjunct `{name, status, reason_code\|null, skipped: bool}` |
| **`evaluated_at`** | ISO 8601 UTC | yes | Evaluation timestamp |
| **`orchestrator_run_id`** | string \| null | no | From caller context when available |
| **`cache_key`** | string \| null | no | Memoization fingerprint (§9) |
| **`schema_version`** | int | yes | Always **`1`** for v1 |

**Conjunct names** (fixed order): `backlog_clear`, `zero_deferrals`, `critic_resolved`, `smoke_green`, `ledger_clean`.

**Conjunct status** enum: `pass` | `fail` | `skip`.

Exit semantics: `converged=true` only when every non-skipped conjunct is `pass`.

```json
    "blocked_by": ["CONVERGENCE_OPEN_STORIES_REMAIN"],

      "backlog_clear": {"status": "fail", "reason_code": "CONVERGENCE_OPEN_STORIES_REMAIN", "skipped": false}

    "orchestrator_run_id": "auto-20260628-04",
    "schema_version": 1
  }
}
```

Wrapped in markdown fenced JSON under heading **`### goal_progress`** (deterministic placement: after latest orchestration pointer, before prior pointers).

### §4 — Five-conjunct predicate + degrade matrix (AC-2, AC-7)

| # | Conjunct | Source | When artifact absent | On failure |
|---|----------|--------|---------------------|------------|
| 1 | **backlog clear** | `docs/product/backlog.md` line-scoped `- Status: OPEN` in `## US-xxxx` blocks | never skip | `CONVERGENCE_OPEN_STORIES_REMAIN` → **blocked_by** |
| 2 | **zero deferrals** | `handoffs/sovereign_deferrals.jsonl` | file absent → **skip** (`deferral_register_not_yet_deployed` in **unmet_conditions** only) | non-empty register → `CONVERGENCE_DEFERRALS_PENDING` → **blocked_by** |
| 3 | **critic resolved** | `handoffs/sovereign_critic_findings.jsonl` tail **OR** latest sprint `qa-findings.md` `cross_reviewer_findings` | both absent → **skip** (`critic_register_not_yet_deployed` in **unmet_conditions** only) | open blocking finding → `CONVERGENCE_CROSS_REVIEWER_OPEN` → **blocked_by** |
| 4 | **smoke green** | `tests/report.md` overall PASS **AND** active sprint `uat.json` latest smoke step PASS | either missing → **fail** (fail-closed) | `CONVERGENCE_SMOKE_PROBE_FAIL` → **blocked_by** |
| 5 | **ledger clean** | `handoffs/sovereign_decisions/<run>.jsonl` via **US-0103** `read_entries(last_n=100)` | `AI_DECISION_LEDGER=0` → **skip** (`ledger_disabled_skip` in **unmet_conditions** only) | unapproved `PLAN_FIDELITY_EXTENSION` / `PLAN_FIDELITY_SCOPE_GATE` without matching `PLAN_FIDELITY_OVERRIDE` → `CONVERGENCE_LEDGER_EXTENSIONS_UNAPPROVED` → **blocked_by** |

**Smoke canonical chain (R3 closed)**: repo-level **`tests/report.md`** + active sprint **`uat.json`** smoke step (**US-0093**). **US-0109** post-deploy smoke is **out of scope** for convergence v1 — consumed by **US-0107** deferral path only.

**Skip vs fail rule**: upstream stories **OPEN** (US-0104/US-0107 not deployed) → **skip** conjunct (informational **unmet_conditions**, not **blocked_by**). Missing smoke evidence under `goal_convergence` → **fail-closed**.

### §5 — Vision auto-derive algorithm (AC-3)

`resolve_goal(scratchpad, repo) -> (goal_text, goal_source, reason_code|None)`:

1. If `SOVEREIGN_GOAL` non-empty after strip → return `(truncated_text, "explicit", None)`.
2. Read `docs/product/vision.md` UTF-8; missing/unreadable → `(None, None, SOVEREIGN_GOAL_DERIVE_FAILED)`.
3. Walk lines top-to-bottom; collect **eligible paragraphs**:
   - **Skip**: ATX headings (`#`..`######`), fenced code blocks, list lines (`-`, `*`, `+`, `\d+.`), blockquotes (`>`), HTML comments, empty/whitespace-only lines.
   - **Skip sections**: from `## Discovery Notes —` through next `##` not matching `Discovery Notes`; from `## Intake Notes —` through next `##` not matching `Intake Notes`.
   - **Eligible**: contiguous non-skipped prose lines; join internal newlines with space.
4. Take first **`SOVEREIGN_GOAL_TOP_N`** eligible paragraphs (default 3).
5. Join with `" — "`; truncate to **`SOVEREIGN_GOAL_MAX_CHARS`** (default 512) on word boundary when possible.
6. Zero eligible paragraphs → `SOVEREIGN_GOAL_DERIVE_FAILED`.

`SOVEREIGN_GOAL_MISSING` is **informational only** (in **unmet_conditions**, not **blocked_by**) when goal empty but mode is `phase_driven`.
