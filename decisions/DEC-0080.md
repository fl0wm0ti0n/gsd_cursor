# DEC-0080: Native in-Cursor `/auto` auto-chain — IDE-primary continuation, drain-advance, and unified cap ledger (US-0095)

- Date: 2026-06-07
- Status: Accepted
- Story: `US-0095`
- Composes on: **`DEC-0078`** (full-autonomy flow mode, outer driver, stop matrix, block-retry ledger — **amends IDE-primary path only**; outer driver **not removed**), **`US-0088`** (continuous `/auto` + reference Step 5), **`BUG-0006`** / **`US-0069`** (spawn-only + isolation preflight/post-checks — **unchanged**)
- Extends: **`DEC-0069`** (boundary refresh at phase and drain segments), **`DEC-0038`** (strict runtime proof unchanged), **`DEC-0022`** (backlog drain)
- Related: **`US-0044`**, **`US-0087`**, **`US-0023`**, **`US-0048`**, **`US-0056`**, **`R-0081`**
- Supersedes: none (partial amendment to **DEC-0078** §2 outer-driver **primary** labeling for IDE context only)

## Context

**US-0092** / **DEC-0078** shipped **`scripts/auto_outer_driver.py`** as the multi-turn bridge when Cursor ends an orchestrator turn after one phase. Operators enabling **`AUTO_FLOW_MODE=full_autonomy`** + **`AUTO_BACKLOG_DRAIN=1`** in the IDE still receive **`stop_reason=completed (segment exhausted)`** with prose directing them to re-run `/auto` or the outer driver — contradicting hands-off drain expectations documented in **US-0088**.

**US-0095** promotes a **primary IDE path**: one `/auto` orchestrator invocation **self-chains in-chat** across intersected lifecycle phases and backlog-drain segment boundaries via a **foreground sequential Task/subagent loop**. The outer driver remains for headless/CI/`--invoke-cmd` contexts and as an **optional** IDE fallback when native chain is unavailable.

Research basis: **`R-0081`** Q1–Q6.

## Decision

### 1. Native in-chat auto-chain activation (AC-1)

**Activation gate** (all must hold):

1. Merged scratchpad **`AUTO_FLOW_MODE=full_autonomy`** (exact literal).
2. Invocation context = **Cursor IDE** (default when `/auto` runs in Agent panel without `--invoke-cmd`).
3. Orchestrator has **Task tool** access for foreground subagent spawn.

**Normative chain driver** — orchestrator executes **reference Step 5** as a **`while` continuation loop**:

1. Resolve next `phase_id` from intersected schedule **or** drain-advance target (§2).
2. **US-0069** preflight (role matrix + capability gate).
3. **Spawn fresh subagent** (`Task` tool, `subagent_type` = canonical role, `readonly` when phase is read-only).
4. **Await** subagent completion (foreground — blocks until done).
5. Verify isolation evidence + **DEC-0038** strict-proof tuple in `state.md`.
6. Increment continuation counters (§3).
7. Branch stop matrix → continue spawn, drain-advance, block-retry, or hard stop.

**Forbidden** (**BUG-0006** invariant):

- Orchestrator authors phase deliverables in-band.
- Orchestrator merges subagent output as phase completion without spawn.
- Orchestrator skips spawn for any scheduled `phase_id`.
- Background subagent fleet for lifecycle phase ordering (phases remain **strictly sequential**).

**Turn-boundary semantics**: under native chain, **`stop_reason=completed (segment exhausted)`** is **invalid** when (a) next intersected phase exists, (b) drain policy selects another OPEN item, or (c) relaxable stop is within retry budget — orchestrator **must** schedule continuation instead of emitting operator wait instructions.

**Rejected alternatives** (per **`R-0081`** Q1): orchestrator in-band phase execution; background subagent + poll for phase chain; outer-driver-only as IDE primary; Cursor hooks (`subagentStop` follow-up) as v1 primary (deferred optional overlay).

### 2. IDE drain-advance-without-pause (AC-2, AC-7)

Deterministic algorithm when **`full_autonomy`** + (**`AUTO_BACKLOG_DRAIN=1`** or bug-queue per **US-0087**).

**Trigger** (all must hold):

- Segment terminal phase completed: `stop_phase=refresh-context` (or story terminal when `refresh-context` omitted).
- `stop_reason=completed` (not hard gate).
- Drain enabled per scheduler mutex (**US-0087** unchanged).
- `backlog_drain_stories_remaining_budget > 0` (story drain) or bug-queue budget not exhausted.

**Algorithm** (orchestrator scheduling only):

```
1. READ latest phase-boundary block in docs/engineering/state.md
   (stop_phase, stop_reason, story_id, sprint_id, orchestrator_run_id,
    backlog_drain_stories_remaining_budget, bug_queue_remaining).
2. ASSERT DEC-0069 pairing: completed phase refreshed resume_brief + state.md
   (stale → fail-closed RESUME_BRIEF_STALE; no drain advance).
3. IF story drain:
     a. DECREMENT backlog_drain_stories_remaining_budget in state boundary.
     b. SELECT next OPEN story per AUTO_STORY_SELECTION (priority_then_backlog_order).
     c. IF no eligible OPEN story → drain_terminated=true,
        drain_terminated_reason=no_open_stories; STOP chain (completed).
     d. IF budget == 0 → stop_reason BACKLOG_MAX_STORIES_REACHED (hard).
   ELSE IF bug-queue (US-0087):
     a. SELECT next OPEN BUG-#### ascending; respect AUTO_BUG_MAX_ITEMS.
     b. IF queue empty → AUTO_BUG_QUEUE_EMPTY (hard).
4. RELOAD merged scratchpad; MATERIALIZE resolved_phase_plan (US-0070);
   INTERSECT with segment entry phase.
5. PREPEND handoffs/resume_brief.md top pointer with story_id|bug_id,
   intended_resume_phase=<first scheduled phase>, orchestrator_run_id unchanged,
   backlog_drain_active, budget counters.
6. APPEND state.md materialization breadcrumb for new segment.
7. IMMEDIATELY spawn first phase subagent (goto §1 chain step 2) — no operator
   re-/auto, no outer-driver instruction under full_autonomy IDE path.
```

**Scheduler mutex** (**US-0087**): unchanged — `AUTO_SCHEDULER_CONFLICT` when both drain flags set without `bug-target=` argv.

### 3. Unified cap + ledger accounting (AC-4, AC-10)

**Principle**: IDE native chain and outer driver **share one accounting model** — same scratchpad keys, same ledger path, same counter semantics.

| Cap | Scope | Native chain | Outer driver |
|-----|-------|--------------|--------------|
| **`AUTO_LOOP_MAX_CYCLES`** | Continuation cycles per `orchestrator_run_id` — each phase spawn boundary + each drain segment advance counts **1** | Orchestrator increments `outer_cycle_index` in state breadcrumb; at cap → `stop_reason=loop_max` (hard) | Unchanged (**DEC-0078**) |
| **`AUTO_IMPLEMENTATION_LOOP`** | Inner `execute`→`qa`→`verify-work` remediation | `implementation_loop_index` increments per full cycle; hard stop when `>= AUTO_LOOP_MAX_CYCLES` | Unchanged |
| **`AUTO_BLOCK_RETRY_MAX`** | Per `(story_id, stop_reason)` recoverable retries | Read ledger before retry; append on schedule | Unchanged |
| **`AUTO_BACKLOG_MAX_STORIES`** | Drain breadth per run | Decrement `backlog_drain_stories_remaining_budget` at segment advance | Exit **4** unchanged |

**Ledger path** (unchanged): append-only **`handoffs/auto_block_retry/<orchestrator_run_id>.jsonl`**.

**New `remediation_action` values** (ratified): `phase_respawn`, `native_chain_continue`, `drain_advance` — alongside existing `outer_reinvoke`.

**State breadcrumb fields** (required on each phase boundary when `full_autonomy`):

| Field | Type | Semantics |
|-------|------|-----------|
| **`native_chain_active`** | `true` \| `false` | `true` when IDE native chain is driving continuation |
| **`outer_cycle_index`** | int ≥ 0 | Continuation cycles this run |
| **`implementation_loop_index`** | int ≥ 0 | Inner remediation cycles for current story segment |

**Ordering** (unchanged from **DEC-0078**): check **`AUTO_LOOP_MAX_CYCLES`** first; then **`AUTO_IMPLEMENTATION_LOOP`** + **`AUTO_BLOCK_RETRY_MAX`** before recoverable retry; unrecoverable classes bypass ledger.

### 4. Outer-driver fallback boundary (AC-5)

| Context | Native in-chat chain | Outer driver | Operator messaging |
|---------|---------------------|--------------|-------------------|
| **Cursor IDE + `full_autonomy`** | **Primary** | **Optional fallback** | Must not state outer driver is **required** for drain |
| **Headless / CI / scripted runner** | **Unavailable** | **Recommended** | Runbook labels **headless primary** |
| **`--invoke-cmd` / external agent runner** | N/A | **Required** bridge | Document in runbook |
| **`manual` / `auto_until_decision`** | Not required | Optional | No change |
| **`NATIVE_CHAIN_UNAVAILABLE`** | Stops | Suggested fallback (non-mandatory) | Non-suppressible error |

**DEC-0078** amendment (IDE labeling only): runbook subsection **`### Full-autonomy outer driver (US-0092)`** is demoted to **fallback**; new **`### Native in-chat auto-chain (US-0095)`** is **primary** for IDE. Script path, argv, exit codes, and spawn-only loop semantics **unchanged**.

**README demotion** (execute): replace mandatory "run outer driver once" as **sole** full-autonomy recipe with **"run `/auto` once in Cursor"** (primary); outer driver **"for headless/CI or when native chain is unavailable"**. Preserve **US-0092** autonomy headline — demote, do not delete.

### 5. Operator messaging + `AUTO_QUIET` (AC-6)

**Invariant**: Under **`full_autonomy`** IDE native chain, segment and phase handoffs **must not** emit **mandatory wait** instructions when continuation is schedulable.

| Event | `AUTO_QUIET=0` | `AUTO_QUIET=1` |
|-------|----------------|----------------|
| Routine phase PASS | May notify | **Suppress** |
| Native chain continuing to next phase | Compact breadcrumb OK | **Suppress** |
| Drain advance to next story/bug | Segment handoff notify OK | **Suppress** routine segment prose; **no** outer-driver instruction |
| `decision_gate`, errors, `loop_max`, `blocked`, missing critical input, pause | **Always** | **Always** |
| `BACKLOG_MAX_STORIES_REACHED`, `BLOCK_RETRY_CAP_EXHAUSTED` | **Always** | **Always** |
| **`NATIVE_CHAIN_UNAVAILABLE`** | **Always** + fallback hint | **Always** |

**Forbidden grep patterns** (active `auto.md` + reference `full_autonomy` IDE sections):

- `run the outer driver` (as mandatory IDE step)
- `re-run /auto` (between segments when drain active + native chain available)
- `segment exhausted` (as terminal under `full_autonomy` when continuation pending)
- `python scripts/auto_outer_driver.py` without **optional** / **fallback** qualifier in IDE-primary prose

**Orthogonality**: **`AUTO_QUIET`** unchanged vs **`TOKEN_PROFILE`** (**DEC-0035** / **US-0088**).

### 6. Fail-closed reason codes (AC-1, AC-4)

| Code | When | Recoverable |
|------|------|-------------|
| **`NATIVE_CHAIN_UNAVAILABLE`** | Task tool denied, spawn depth limit, or IDE context cannot schedule foreground subagent | No — suggest outer driver as optional fallback |
| **`RESUME_BRIEF_STALE`** | **DEC-0069** pairing failed before drain advance | No |
| **`BLOCK_RETRY_CAP_EXHAUSTED`** | Ledger count ≥ **`AUTO_BLOCK_RETRY_MAX`** | No |
| **`BACKLOG_MAX_STORIES_REACHED`** | Drain budget exhausted | No |
| **`AUTO_SCHEDULER_CONFLICT`** | Drain mutex violation | No |

Hard gates from **DEC-0078** stop matrix remain **unchanged** — native chain does not relax **`decision_gate`**, isolation/strict-proof violations, security deny, unrecoverable **`error`**, or **`pause_request`**.

### 7. Contract tests + template parity (AC-8, AC-9)

**Pytest**: `pytest -k us0095 tests/auto_command_contract_test.py` — six `test_us0095_*` markers per **`R-0081`** Q6.

**Template parity scope**: `--scope=us-0095` (or equivalent 8-row inventory) — `auto.md`, reference excerpts, runbook subsection, README family demotion, contract tests, architecture `# US-0095`.

**No new scratchpad keys** — reuse existing caps from **DEC-0078**.

### 8. Security (AC-10)

Unchanged from **DEC-0078**: no auto-read **`.env`**, no intake evidence mutation, no publish without **`RELEASE_PUBLISH_MODE=auto`**.

## Risks

| Risk | Mitigation |
|------|------------|
| **R1** Cursor depth/tool-policy blocks nested spawns | **`NATIVE_CHAIN_UNAVAILABLE`** fail-closed + optional outer-driver hint |
| **R2** Docs claim drain while behavior stops at segment exhausted | Contract tests + forbidden-pattern grep |
| **R3** Spawn-only violation on continuation | **US-0069** preflight/post-checks + **BUG-0006** regression tests |
| **R4** Stale `resume_brief` between advances | **DEC-0069** fail-closed **`RESUME_BRIEF_STALE`** |
| **R5** Dual-path operator confusion | Runbook primary/fallback table (§4) |
| **R6** Cap desync between IDE chain and outer driver | Unified ledger + shared breadcrumb fields (§3) |

## Consequences

- **`auto.md`** and **`auto-orchestration-reference.md`** gain **Native in-chat auto-chain (US-0095)** sections; Step 5 amended for IDE primary path.
- **`DEC-0078`** outer-driver runbook label shifts from sole primary to **IDE fallback**; script implementation unchanged.
- Contract tests **`test_us0095_*`** guard native chain literals, drain-advance, spawn-only, messaging, and parity.
- Operators in Cursor IDE with **`full_autonomy`** run **`/auto` once** for hands-off multi-phase + drain delivery.
