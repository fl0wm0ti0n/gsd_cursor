# DEC-0070 — `remote_config_summary.py` behavior when `REMOTE_EXECUTION=0`

## Status

Accepted (US-0084 / S0069).

## Context

**`architecture.md`** **`# US-0084`** defines exit codes for
**`scripts/remote_config_summary.py`**, including a branch for
**`REMOTE_EXECUTION=0`** fast exit (**exit 5** *or* map no-op to **exit 0**).

## Decision

When **`REMOTE_EXECUTION`** is unset or not truthy (**`0`**, falsey), the helper
**does not** read **`REMOTE_CONFIG`**; it prints a one-line skip reason to
**stderr** and exits **`0`**.

Rationale: matches runbook **“skip remote-config validation entirely (zero overhead)”**
and avoids treating “remote off” as a failure in CI or local scripts.

Exit code **`5`** remains reserved for a future distinct “skipped with non-zero”
policy if product governance changes; it is **not** used for **`REMOTE_EXECUTION=0`**
in this repository.
