# DEC-0085: Version-scoped release changelog and GitHub release-note attachment (US-0100)

- Date: 2026-06-15
- Status: Accepted
- Story: `US-0100`
- Composes on: **`DEC-0020`** / **US-0040** (sprint-scoped notes + queue unchanged), **`DEC-0036`** / **US-0054** (publish confirmation boundary), **US-0067** (Run/Connect/Verify stay in sprint notes), **US-0008** (`release-all.sh` GitHub step extension)
- Related: **`R-0087`**, **US-0091**, **US-0097**
- Supersedes: none

## Context

**US-0040** delivers per-sprint release notes (`handoffs/releases/Sxxxx-release-notes.md`) and a release queue, but operators lack a semver-aligned cumulative changelog listing **US-xxxx** / **BUG-xxxx** with short summaries, and **`scripts/release-all.sh`** still invokes **`gh release create --generate-notes`**, ignoring canonical its-magic bodies. Research (**`R-0087`**) closed backfill tiers, semver coalesce, **`[Unreleased]`** promotion, per-version **`-F`** SOT, and a **`RELEASE_CHANGELOG_*`** validator family.

## Decision

### 1. Canonical artifact paths (AC-1, AC-2)

| Artifact | Path | Role |
|----------|------|------|
| **Cumulative changelog** | repo-root **`CHANGELOG.md`** | Keep a Changelog **1.1.0** shape: mandatory top **`## [Unreleased]`** + semver sections newest-first with ISO dates |
| **Per-version release body** | **`handoffs/releases/{semver}-release-notes.md`** | **GitHub `-F` SOT** — semver stem without leading **`v`** (e.g. **`0.1.2-41-release-notes.md`**) |
| **Sprint evidence (unchanged)** | **`handoffs/releases/Sxxxx-release-notes.md`** | **US-0040** workflow evidence; **never** passed to **`gh -F`** |
| **Backfill manifest** | **`docs/engineering/context/release-version-backfill.manifest.yaml`** | Operator Tier B **`sprint_id`→`semver`** overrides |
| **Shared library** | **`scripts/release_changelog_lib.py`** (+ **`template/scripts/`** mirror) | Derivation, coalesce, promote, fingerprint idempotency |
| **Validator** | **`scripts/release_changelog_validate.py`** (+ template mirror) | Fail-closed **`--enforce`** checks |
| **Backfill script** | **`scripts/release_changelog_backfill.py`** (+ template mirror) | One-time/idempotent Tier A/B/C seed |
| **Example pattern** | **`template/handoffs/releases/vX.Y.Z-release-notes.md.example`** | Rename-at-use doc; not a live semver file |

**Template stub**: **`template/CHANGELOG.md`** — Keep a Changelog header + empty **`[Unreleased]`** only.

**Rejected alternatives**:

- Parse **`CHANGELOG.md`** at **`gh`** attach time (**rejected** — explicit per-version file simpler, fail-closed per **`R-0087`** Q4).
- Replace sprint notes with version docs (**rejected** — violates **US-0040** / discovery **L3**).

### 2. Derivation precedence (AC-3, AC-4)

Structured work-item extraction order (single helper — no duplicate logic in shell):

1. Sprint note **`## What's new`** bullets + inline **US-xxxx** / **BUG-xxxx** refs
2. Backlog **`## US-xxxx`** / **`### BUG-xxxx`** title + summary (one-liner)
3. Queue row **`story_refs`** (fallback when sprint note sparse)

**Category mapping** (Keep a Changelog categories):

| Work item | **`CHANGELOG.md`** category | Per-version **`## Work items`** |
|-----------|------------------------------|--------------------------------|
| **`US-xxxx`** (default) | **Added** | Flat bullet + one-liner |
| **`BUG-xxxx`** | **Fixed** | Flat bullet + one-liner |
| **`user_visible: false`** story in **`story_refs`** | **Changed** | Include when listed in sprint refs |

**Per-version doc sections** (minimum):

- **`## Work items`** — merged, deduped bullets
- **`## Sprint evidence`** — links to each contributing **`handoffs/releases/Sxxxx-release-notes.md`**
- Optional cross-link only to **US-0067** operator hints in sprint notes (hints stay in sprint layer)

### 3. `release_changelog_lib.py` API (AC-3, AC-6, AC-7)

| Symbol | Contract |
|--------|----------|
| **`normalize_semver(raw: str) -> str`** | Strip leading **`v`**; semver-parse; raise **`RELEASE_CHANGELOG_VERSION_MISSING`** on empty/invalid |
| **`derive_work_items(sprint_ids, repo_root) -> list[WorkItem]`** | L4 precedence; stable sort **US** then **BUG** numeric |
| **`coalesce_sprints_by_semver(rows, repo_root) -> dict[str, list[str]]`** | Group **`released`** queue rows by normalized semver |
| **`build_version_doc(semver, sprint_ids, repo_root) -> Path`** | Write **`handoffs/releases/{semver}-release-notes.md`**; return path |
| **`promote_unreleased(semver, sprint_ids, repo_root, release_date=None) -> None`** | Move **`[Unreleased]`** items into **`## [{semver}] - {ISO date}`**; recreate empty **`[Unreleased]`** |
| **`append_unreleased(work_items, repo_root) -> None`** | Append categorized bullets under top **`[Unreleased]`** only |
| **`version_fingerprint(semver, work_item_ids) -> str`** | **`semver + sorted(work_item_ids)`** joined — idempotency key |
| **`bind_queue_release_version(sprint_ids, semver, repo_root) -> None`** | Target-scoped queue row mutation only |
| **`extract_changelog_section(semver, repo_root) -> str \| None`** | Read cumulative section text (validator helper) |

**Idempotency (L7)**:

- Same fingerprint on re-run → no-op; log **`RELEASE_CHANGELOG_IDEMPOTENCY_OK`** (informational, not a fail code)
- Same semver, different fingerprint → **`RELEASE_CHANGELOG_DUPLICATE_VERSION`** fail-closed
- Duplicate work-item bullets same version on re-run → **`RELEASE_CHANGELOG_IDEMPOTENCY_VIOLATION`**

### 4. `[Unreleased]` workflow (AC-3)

| Trigger | **`CHANGELOG.md`** | Per-version file | Queue **`release_version`** |
|---------|-------------------|------------------|----------------------------|
| **`/release`** PASS, semver **unknown** | Append under **`[Unreleased]`** only | **Do not create** | Leave empty |
| **`/release`** PASS, semver **explicit** on row | **Promote** per Keep a Changelog | **Create/update** **`{semver}-release-notes.md`** | Set **`release_version`** |
| **`release-all.sh`** post-**`npm version`** | Promote using **`NEW_VERSION`** | Same | Bind coalesced rows |

**`[Unreleased]`** header is **mandatory** at top of **`CHANGELOG.md`**. Absence → **`RELEASE_CHANGELOG_UNRELEASED_MISSING`**.

### 5. Multi-sprint semver coalesce (AC-6)

- **Coalesce key** = normalized semver (handles duplicate explicit values e.g. **`S0070`/`S0071`→`0.1.2-41`**)
- **Dedupe** work items by id within coalesced group
- **Date** on **`CHANGELOG`** section = latest contributing sprint **`last_updated`** UTC date component
- **`release-all.sh` window**: after **`npm version`**, coalesce **`released`** rows with empty **`release_version`** since last tag (or documented operator window) into **`NEW_VERSION`**

### 6. Three-tier backfill (AC-6)

Process **`released`** queue rows sorted by **`last_updated`** ascending:

| Tier | Source | Semver assignment | Side-effect label |
|------|--------|-------------------|-------------------|
| **A — explicit** | Row **`release_version`** non-empty | Use as-is | No synthetic label |
| **B — operator manifest** | **`release-version-backfill.manifest.yaml`** | Manual map | **`remediation=backfill_manifest=<semver>`** |
| **C — synthetic workflow** | Remaining rows | **`0.0.0-wf.{NNN}`** (**`S0089`→`0.0.0-wf.089`**) | **`remediation=backfill_synthetic=0.0.0-wf.089`** |

**Manifest schema** (`release-version-backfill.manifest.yaml`):

```yaml
schema_version: 1
entries:
  - sprint_id: S0050
    semver: "0.1.2-30"
    notes: optional operator prose
```

- **`schema_version`**: integer **`1`**
- **`entries[]`**: each requires **`sprint_id`**, **`semver`**; optional **`notes`**
- Manifest collision (two sprints → same semver without coalesce intent) → **`RELEASE_CHANGELOG_BACKFILL_AMBIGUOUS`**
- Missing sprint note → skip row with **`RELEASE_CHANGELOG_SPRINT_ORPHAN`** in backfill report (no invented work items)

**Rejected**: assign all blank rows to current **`package.json`** semver — loses audit trail.

### 7. `/release` derivation hook (AC-3, AC-8)

Insert **step 19** (after step **18** operator hints — **US-0067**) in active + **`template/.cursor/commands/release.md`** (byte-identical block per **US-0017**):

**19. Version changelog derivation (US-0100 / DEC-0085)** — only after step **9** successful finalization (`unreleased → released`):

- **19a**: Resolve target semver — explicit queue **`release_version`**, else empty (→ **`[Unreleased]`** path only)
- **19b**: **`derive_work_items`** from target sprint + coalesce peers when semver known
- **19c**: If semver known → **`build_version_doc`** + **`promote_unreleased`** + **`bind_queue_release_version`**; else **`append_unreleased`** only
- **19d**: Optional **`python scripts/release_changelog_validate.py --repo . --enforce`** when **`RELEASE_CHANGELOG_ENFORCE=1`** (default **`1`** post-bootstrap in scratchpad); record outcome in **`sprints/Sxxxx/release-findings.md`** § version-doc gates

Doc writes are **not** publish execution — **`RELEASE_PUBLISH_MODE=disabled`** remains valid (**US-0054**).

### 8. GitHub / git publish attachment (AC-5)

**`release-all.sh`** (replace **`--generate-notes`** default):

```bash
VERSION_NOTES="handoffs/releases/${NEW_VERSION}-release-notes.md"
if [[ -f "$VERSION_NOTES" ]]; then
  python scripts/release_changelog_validate.py --repo "$REPO_ROOT" --enforce
  gh release create "$TAG_NAME" -F "$VERSION_NOTES" --title "$TAG_NAME" $GH_PRERELEASE
else
  # fail-closed; optional scratchpad RELEASE_CHANGELOG_ALLOW_GENERATE_NOTES=1 fallback only
  err "RELEASE_CHANGELOG_VERSION_DOC_MISSING: $VERSION_NOTES"
fi
```

**`/release` publish path** (**US-0054**): when **`RELEASE_PUBLISH_MODE`** **`confirm|auto`** and git-type target enabled, use same **`-F`** path.

**Scratchpad keys**:

| Key | Default | Notes |
|-----|---------|-------|
| **`RELEASE_CHANGELOG_ENFORCE`** | **`1`** | Validator at **`/release`** step **19d** and **`release-all.sh`** pre-attach |
| **`RELEASE_CHANGELOG_ALLOW_GENERATE_NOTES`** | **`0`** | Opt-in **`--generate-notes`** fallback when version doc missing |

### 9. Validator reason codes (AC-7)

**Script**: **`scripts/release_changelog_validate.py`** — **`--repo`**, **`--enforce`**, optional **`--backfill-report`**.

| Code | Condition |
|------|-----------|
| **`RELEASE_CHANGELOG_VERSION_MISSING`** | **`released`** row bound semver but no matching **`CHANGELOG`** section + per-version file |
| **`RELEASE_CHANGELOG_DUPLICATE_VERSION`** | Two **`CHANGELOG`** sections same semver, or fingerprint mismatch on re-derive |
| **`RELEASE_CHANGELOG_WORK_ITEM_GAP`** | Queue **`story_refs`** / sprint work item absent from semver doc |
| **`RELEASE_CHANGELOG_ORDER_INVALID`** | Semver sections not newest-first |
| **`RELEASE_CHANGELOG_UNRELEASED_MISSING`** | No top **`[Unreleased]`** header |
| **`RELEASE_CHANGELOG_QUEUE_DRIFT`** | Queue **`release_version`** ≠ changelog binding for sprint |
| **`RELEASE_CHANGELOG_VERSION_DOC_MISSING`** | Semver finalized but per-version file absent |
| **`RELEASE_CHANGELOG_SPRINT_ORPHAN`** | **`released`** sprint not in any semver section nor **`[Unreleased]`** |
| **`RELEASE_CHANGELOG_BACKFILL_AMBIGUOUS`** | Manifest collision / unresolved semver |
| **`RELEASE_CHANGELOG_IDEMPOTENCY_VIOLATION`** | Duplicate work-item bullets same version on re-run |

Informational (not fail): **`RELEASE_CHANGELOG_IDEMPOTENCY_OK`**.

### 10. Compose rules (US-0040 / US-0054 / US-0067 / US-0008)

| Story | Compose rule |
|-------|--------------|
| **US-0040** | Sprint notes remain canonical workflow evidence; version layer **adds** semver docs; never overwrite non-target **`Sxxxx`** files |
| **US-0054** / **DEC-0036** | Doc derivation ≠ publish; confirmation gates unchanged |
| **US-0067** | Run/Connect/Verify/ Credentials/Known Issues stay in sprint notes; version doc links only |
| **US-0008** | Extend GitHub step in **`release-all.sh`**; npm/choco/brew flow unchanged |
| **US-0017** | Active + **`template/`** parity for scripts, **`CHANGELOG.md`**, **`release.md`** step **19**, **`release-all.sh`** |

### 11. Risks

| Risk | Mitigation |
|------|------------|
| **R1** Synthetic semver noise (**`0.0.0-wf.*`**) | Tier B manifest + clear **`remediation`** labels on queue rows |
| **R2** **`[Unreleased]`** promotion race | Fingerprint idempotency; serialize promotion per semver in helper |
| **R3** Pre-release filename edge cases (**`0.1.2-41`**) | Semver stem as filename (no **`v`**); contract test |
| **R4** **`--generate-notes`** fallback temptation | Default fail-closed; scratchpad opt-in only |
