# DEC-0081: Native-chain orchestrator compliance enforcement and continuation-truth breadcrumbs (BUG-0012)

- Date: 2026-06-12
- Status: Accepted
- Bug: `BUG-0012`
- Composes on: **`DEC-0080`** (native in-chat auto-chain — **amends enforcement layer only**; contract intent unchanged), **`DEC-0078`** (hard gates unchanged), **`BUG-0006`** / **`US-0069`** (spawn-only unchanged), **`DEC-0069`** (boundary pairing), **`DEC-0038`** (strict proof)
- Extends: **`US-0095`** delivery (post-regression compliance fix)
- Related: **`R-0083`**, **`US-0088`**, **`US-0092`**, **`US-0044`**
- Supersedes: none (partial amendment to **DEC-0080** §1 turn-boundary semantics and §3 breadcrumb fields)

## Context

**US-0095** / **DEC-0080** / **S0084** (released **2026-06-07**) shipped native in-chat auto-chain contract, seven **`test_us0095_*`** markers, and forbidden-prose inventory. Operator report **2026-06-12**: with **`AUTO_FLOW_MODE=full_autonomy`** + **`AUTO_BACKLOG_DRAIN=1`**, orchestrator still stops after every story segment and instructs manual re-**`/auto`** despite schedulable continuation.

Research **`R-0083`** Q1–Q6: **not** missing **DEC-0080** contract — **agent compliance gap**. Static contract tests pass; runtime fails because (a) no executable hook enforces orchestrator `while` loop; (b) residual **US-0088** Option B / **US-0092** outer-driver re-invoke prose primes turn-boundary stop; (c) drain-advance **step 7** spawn skipped after **DEC-0069** steps 1–6; (d) **`native_chain_active`** reflects gate eligibility only, not continuation action.

**BUG-0012** closes contract-vs-runtime gap without re-litigating **US-0095** intent.

## Decision

### 1. Orchestrator-only continuation mandate (AC-1, AC-2)

**Normative addition** to `.cursor/commands/auto.md` (orchestrator context only — **not** phase-role commands):

After **any** foreground subagent returns, when continuation is schedulable (next intersected phase, drain-advance target, or relaxable retry within budget), orchestrator **MUST**:

1. **Not** treat subagent handoff as run terminal.
2. **Not** instruct operator to re-run **`/auto`** or mandatory **`auto_outer_driver.py`**.
3. **Task-spawn** the next phase-role subagent per **US-0069** preflight.

**Phase-role vs orchestrator distinction** (locked):

| Actor | After phase completes |
|-------|----------------------|
| Phase-role subagent (`po`, `tech-lead`, `dev`, `qa`, …) | Stop; hand off via artifacts only (**BUG-0006** correct) |
| **`/auto` orchestrator** | **Continue** — schedule next spawn when schedulable (**DEC-0080** / **BUG-0012**) |

**Native-chain precedence** under **`AUTO_FLOW_MODE=full_autonomy`** + IDE + Task available:

- **DEC-0080** native in-chat chain is **primary** for continuation.
- **US-0088** Option B (outer-driver equivalence when single invocation cannot schedule multiple turns) applies **only** when **`NATIVE_CHAIN_UNAVAILABLE`** or headless/CI/`--invoke-cmd` context.
- **US-0092** full-autonomy matrix row "outer driver re-invokes when Cursor ends turn early" is **scoped to fallback** — not IDE-primary **`full_autonomy`** path.

**Required doc literals** (contract-test anchors): **`orchestrator MUST Task-spawn`**, **`post-subagent continuation`**, **`native chain supersedes Option B`**, **`phase-role stop is not run terminal`**.

### 2. Drain-advance step 7 spawn obligation (AC-3)

Amend **DEC-0080** §2 algorithm: between steps **6** and **7**, orchestrator **must not**:

- Emit operator wait instructions.
- Set **`stop_reason=completed (segment exhausted)`** when drain budget > 0 and eligible OPEN item exists.
- Skip Task-spawn for step **7**.

**Step 7 attestation**: on drain-advance boundary, orchestrator appends `drain_advance_action=spawned|skipped|not_applicable` to `state.md` phase boundary. **`skipped`** when budget exhausted or portfolio empty is valid; **`skipped`** when budget > 0 and OPEN item exists is **invalid** (regression).

### 3. Continuation-truth breadcrumbs (AC-4)

Amend **DEC-0080** §3 state breadcrumb fields:

| Field | Type | Semantics |
|-------|------|-----------|
| **`native_chain_active`** | `true` \| `false` | Gate eligibility (unchanged) |
| **`native_chain_continuing`** | `true` \| `false` | Orchestrator scheduled next spawn/advance **this** boundary |
| **`drain_advance_action`** | `spawned` \| `skipped` \| `not_applicable` | Step 7 outcome at segment boundary |
| **`outer_cycle_index`** | int ≥ 0 | Unchanged |
| **`implementation_loop_index`** | int ≥ 0 | Unchanged |

**Invariant**: when `native_chain_continuing=true`, **`stop_reason`** must **not** be `completed (segment exhausted)` and operator-facing prose must **not** mandate re-**`/auto`**.

### 4. Forbidden-prose negative enforcement (AC-5, AC-6)

Extend forbidden-pattern contract beyond **DEC-0080** §5 positive native-section guards:

**Negative grep scope** (under **`full_autonomy`** normative blocks in **`auto.md`** + **`auto-orchestration-reference.md`**):

- Mandatory `re-run /auto` between drain segments.
- `segment exhausted` as terminal when continuation pending.
- Mandatory `run the outer driver` in IDE-primary path.
- Unqualified `python scripts/auto_outer_driver.py` (without **optional** / **fallback** qualifier).

**Demote ambiguous rows**:

- **US-0088** continuous matrix "Stop segment; drain may advance" → clarify native chain **must** advance in IDE **`full_autonomy`**.
- Reference full-autonomy matrix L783 outer-driver re-invoke → scope to **`NATIVE_CHAIN_UNAVAILABLE`** / headless fallback only.

### 5. Contract tests (AC-5)

**Pytest**: `pytest -k bug0012 tests/auto_command_contract_test.py` — four **`test_bug0012_*`** markers per **`R-0083`** Q6:

| Test | Intent |

| `test_bug0012_orchestrator_post_subagent_spawn_mandate` | **`auto.md`** contains orchestrator **MUST Task-spawn** after subagent return when schedulable |

| `test_bug0012_native_chain_precedence_over_option_b` | Native chain primary supersedes US-0088 Option B under **`full_autonomy`** |

**Preserved**: all seven **`test_us0095_*`** subtests remain green — **BUG-0012** is additive enforcement, not replacement.

### 6. `resume_brief` spawn wording (AC-7)

**DEC-0069** pairing contract lines must state orchestrator **MUST Task-spawn** next phase — not "operator runs `/auto`". **`/auto`** label is orchestrator invocation context only.

### 7. Operator E2E recipe (AC-8)

Runbook § **BUG-0012 regression verify** — multi-segment operator recipe (≥2 story boundaries, single **`/auto`**, evidence: `drain_advance_action=spawned`, `resume_brief` `story_id` advance).

### 8. Template parity

**Scope**: `--scope=bug-0012` (or equivalent 6-row inventory): `auto.md`, reference excerpts, `resume_brief` pairing contract, contract tests, architecture `# BUG-0012`, runbook E2E subsection.

## Non-goals

- Weakening **BUG-0006** spawn-only (orchestrator still never executes phase-role work in-band).
- Relaxing **DEC-0078** hard gates (`decision_gate`, isolation, security deny, `loop_max`, `pause_request`).
- Removing **`scripts/auto_outer_driver.py`** (optional IDE fallback preserved).
- Changing **US-0096** delivery-mode axis.
- Rewriting **DEC-0080** intent — amendment only.

## Risks

| Risk | Mitigation |
|------|------------|
| **R1** Over-broad doc edits weaken hard gates | **DEC-0078** matrix explicitly unchanged; contract test asserts no relaxation |
| **R2** Static markers pass; runtime still fails | Operator E2E recipe + `native_chain_continuing` truth fields |
| **R3** Phase-role "stop" conflated with orchestrator terminal | Explicit actor distinction table (§1) |
| **R4** Cursor spawn depth limits | **`NATIVE_CHAIN_UNAVAILABLE`** path unchanged |
| **R5** **AUTO_QUIET=1** suppresses continuation | Messaging table forbids wait prose; scheduling independent of quiet |

## Consequences

- **`auto.md`** and reference gain orchestrator-only continuation block; US-0088/Option B rows scoped to fallback.
- Four **`test_bug0012_*`** contract subtests guard compliance layer.
- **`state.md`** breadcrumbs gain continuation-truth fields.
- Operators with **`full_autonomy`** + drain observe hands-off multi-segment advance after fix.
