# DEC-0031: Legacy DONE-Story Acceptance/Traceability Backfill Guard

- Date: 2026-03-02
- Status: Accepted
- Related story: US-0049
- Research refs: R-0023

## Context

Stories completed before reconciliation/guardrails existed (e.g. US-0017, US-0030)
can remain DONE in backlog while acceptance checkmarks or traceability/release
artifacts are missing or inconsistent. US-0049 must add deterministic
detection, bounded repair, and an ongoing guard so this gap does not recur,
without changing canonical status ownership (US-0045) or broad reconciliation
semantics (US-0043).

## Decision

1. **Detection rule**: A story is in legacy drift when backlog status is DONE
   and at least one of: acceptance item unchecked, traceability/state lacks
   entry, release artifacts lack clear representation for that story.
2. **Canonical audit artifact**: `docs/engineering/legacy-drift-audit.md` with
   required fields per entry: story ID, prior acceptance state, prior
   traceability state, resolved state(s), reason code, evidence reference.
3. **Reason-code vocabulary**: `BACKLOG_DONE_ACCEPTANCE_UNCHECKED`,
   `BACKLOG_DONE_TRACEABILITY_MISSING`, `BACKLOG_DONE_RELEASE_ARTIFACT_MISSING`,
   each with documented remediation guidance.
4. **One-time backfill mode**: Explicit trigger runs detection and target-scoped
   repair once; idempotent when no drift; only stories matching the detection
   rule are mutated; audit report is appended.
5. **Ongoing guard**: At release or reconciliation boundaries (or dedicated
   check), detect legacy drift and either block with reason code and remediation
   or perform target-scoped repair with audit append; behavior is deterministic
   and documented.
6. **Scope**: Target-scoped repair only; no change to US-0045 canonical ownership
   or US-0043 forward reconciliation; template parity and regression coverage
   required for backfill/guard behavior.

## Consequences

- Legacy DONE-story vs acceptance/traceability drift becomes detectable and
  repairable with an auditable report.
- Release/reconciliation can optionally block or repair when drift is present,
  with explicit reason codes so operators can fix or escalate by decision.
- Aligns with US-0045 and US-0043 without duplicating their contracts.
