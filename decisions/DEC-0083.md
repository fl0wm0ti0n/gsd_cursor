# DEC-0083: Project-owned root README — installer boundary, bootstrap, per-story growth, and gate separation (US-0097)

- Date: 2026-06-13
- Status: Accepted
- Story: `US-0097`
- Amends: **`DEC-0045`** (completes installer ownership — root `README.md` no longer framework install payload)
- Reframes: **`DEC-0074`** path scope (**US-0091** validator reads **`its_magic/`** family only; root excluded)
- Composes on: **`DEC-0059`** (dual-audience framework docs — project README uses simpler product sections), **`US-0030`** (delta doc gate unchanged), **`US-0071`** (prose hygiene on project blurbs), **`US-0017`** (template parity)
- Related: **`US-0062`**, **`US-0091`**, **`US-0032`**, **`US-0077`**, **`R-0084`**
- Supersedes: none

## Context

**DEC-0045** / **US-0062** declared **`its_magic/README.md`** as the canonical framework README surface, but **`installer-owned-paths.manifest`** still installs root **`README.md`** (~1600-line its-magic catalog). Consumer repos inherit a framework encyclopedia at root with no project-owned overview that grows as stories ship.

**US-0091** / **DEC-0074** validates framework feature coverage against root **`README.md`** + **`docs/developer/README.md`** — conflating framework and project surfaces. Operators need separated gates: framework catalog under **`its_magic/`**, project overview at root with mandatory bootstrap and per-shipped-story growth.

Research basis: **`R-0084`** Q1–Q8.

## Decision

### 1. Installer ownership boundary (AC-1) — amends DEC-0045

| Path | Today | Target |
|------|-------|--------|
| Root **`README.md`** | In **`[install_paths]`** (manifest line 42) | **Removed** from framework install payload — **project-owned** |
| **`its_magic/README.md`** | Present (mirrors framework catalog) | **Canonical** framework README (**DEC-0045** §2) |
| **`template/its_magic/README.md`** | Parity / install source | Unchanged — framework kit source |
| **`template/README.md`** | Framework byte source (**US-0017**) | Stays kit source; **not** copied to consumer root on **`missing`** install |

**Normative**: fresh **`missing`** install on empty consumer target lays down **no** framework README at root.

**Rejected alternatives**:

- Keep root README in install with "pointer stub" only (**rejected** — still conflates ownership; bootstrap on first execute is cleaner per **R-0084** Q4).
- Single README for both framework + project (**rejected** — violates **DEC-0045** intent and operator **/ask** requirement).

### 2. Placeholder sentinel table (AC-2, AC-3)

| Signal ID | Detection rule | Verdict |
|-----------|----------------|---------|
| **S1** | H1 matches `# its-magic — AI dev team` (exact or normalized whitespace) | placeholder |
| **S2** | Contains `<!-- readme-feature-coverage-catalog -->` | placeholder |
| **S3** | Heading contains `Feature coverage catalog (US-0091)` | placeholder |
| **S4** | Byte-identical to `template/README.md` on consumer install | placeholder |
| **S5** | None of S1–S4 **and** custom title/purpose outside framework blocks | **operator-authored** — preserve |

**Detection order**: **`FRAMEWORK_KIT_REPO=1`** → sentinel table → operator-authored heuristic.

**Ambiguous** (partial S1–S4 + mixed operator content) → **`PROJECT_README_MIGRATION_AMBIGUOUS`** or **`PROJECT_README_SENTINEL_CONFLICT`** (fail closed).

### 3. Kit-repo exception (AC-1, AC-5)

| Repo kind | **`FRAMEWORK_KIT_REPO`** | Root README | Bootstrap/delta |
|-----------|--------------------------|-------------|-----------------|
| Consumer (default) | **`0`** (default) | Project-owned | Execute **23a**/**23b** mandatory |
| its-magic dev repo | **`1`** | Dual-purpose preserved | Skip **23a**/**23b**; project validator skips root |

Consumer repos **never** set **`FRAMEWORK_KIT_REPO=1`**.

### 4. Project README scaffold (AC-3, AC-5)

Execute materializes when root missing **or** any **S1–S4** sentinel matches:

```
# {Project Name}          ← vision.md H1
{1–3 sentence purpose}    ← vision Problem/Value distillate
## For users
## For developers
## Features
<!-- project-readme-feature-catalog -->
*(catalog grows per shipped US-xxxx)*
*Framework workflow commands: see [its_magic/README.md](its_magic/README.md).*
```

Framework **`USER_*`/`DEV_*`** catalogs remain in **`its_magic/README.md`** only (**DEC-0059** / **US-0077** unchanged).

### 5. Migration algorithm M1–M5 (AC-2)

| Step | Condition | Action | Re-run |
|------|-----------|--------|--------|
| **M1** | **`FRAMEWORK_KIT_REPO=1`** | Skip consumer migration | no-op |
| **M2** | Root **S5** (operator-authored) | Never overwrite root; copy framework to **`its_magic/README.md`** if missing/older | idempotent |
| **M3** | Root **S1–S4** and **`its_magic/README.md`** missing | Copy root → **`its_magic/README.md`** | skip if populated |
| **M4** | Root **S1–S4** after **M3** | Replace root with project scaffold (**§4**) | skip if project scaffold present |
| **M5** | Hybrid (see **R-0084** Q7) | Fail closed **`PROJECT_README_MIGRATION_AMBIGUOUS`** | same error |

**Grandfathering**: **`PROJECT_README_ENFORCE=0`** during migration; flip to **`1`** only after **`--report`** shows **`coverage_missing: []`** for explicit **`user_visible: true`** DONE rows (same activation pattern as **`README_FEATURE_COVERAGE_ENFORCE`** per **DEC-0074**).

### 6. Execute step 23 — bootstrap + delta (AC-3, AC-4, AC-8)

New step **23** after step **22** (triad hot-surface):

| Sub-step | Contract |
|----------|----------|
| **23 (preamble)** | Read **`FRAMEWORK_KIT_REPO`** (default **`0`**). When **`1`**, skip **23a**/**23b**. Read **`PROJECT_README_ENFORCE`** for delta context. |
| **23a Bootstrap** | When root missing or **S1–S4** matches, materialize scaffold (**§4**) from **`docs/product/vision.md`**. |
| **23b Per-story delta (mandatory)** | Before **`/execute`** PASS: add/update ≥1 user-facing catalog bullet under **`<!-- project-readme-feature-catalog -->`** containing **`\bUS-xxxx\b`** for **`user_visible: true`** stories. Fail closed → **`PROJECT_README_DELTA_SKIPPED`**. |
| **23c Hygiene compose** | Prose edits subject to execute step **20** (**US-0071**) — no duplicate validator when README unchanged. |

**Orthogonality**: execute step **16** (**US-0032** / **`USER_GUIDE_MODE`**) — zero overhead when off.

### 7. Release step 3g — project README gate (AC-4, AC-7)

New step **3g** immediately after **3f**, before step **4** (UAT):

| Gate | Contract |
|------|----------|
| **3g Project README coverage** | Read **`PROJECT_README_ENFORCE`** (default **`1`** post-bootstrap). When **`0`**: skip with **`skipped`** evidence (migration only). When **`1`**: run **`python scripts/validate_project_readme_coverage.py --repo . --enforce`**. On failure: umbrella **`PROJECT_README_COVERAGE_BLOCKED`** + sub-codes. Active + **`template/.cursor/commands/release.md`** byte-identical **3g** block. |

**Gate order**: **3e → 3f (framework) → 3g (project) → 4 (UAT)** — independent enforce toggles.

### 8. Gate separation — reframes DEC-0074 paths (AC-5, AC-6)

| Surface | **US-0091** (framework) — after reframe | **US-0097** (project) — new |
|---------|----------------------------------------|----------------------------|
| Root **`README.md`** | **Excluded** from framework predicate | **Sole** project validator input |
| **`its_magic/README.md`** | **Primary** framework catalog | Out of scope (pointer only) |
| **`template/its_magic/README.md`** | Parity / install source | Out of scope |
| **`docs/developer/README.md`** | Remains framework DEV shard for **US-0091** | Out of scope for project gate |

**DEC-0074** body is **not rewritten** — path reframe is normative via this DEC + architecture **`# US-0097`**.

### 9. Project validator (AC-6)

| Script | Role |
|--------|------|
| **`scripts/project_readme_coverage_lib.py`** | Sentinel detection (S1–S5), backlog parser reuse, catalog extractor, coverage predicate |
| **`scripts/validate_project_readme_coverage.py`** | CLI entrypoint |

**CLI flags**: **`--repo`**, **`--backlog`**, **`--self-test`**, **`--report`**, **`--audit-out`**, **`--enforce`**, **`--no-kit-skip`**.

**`--report` JSON schema v1**: **`report_schema_version`**, **`status`**, **`repo_root`**, **`catalog_marker_present`**, **`coverage_present[]`**, **`coverage_missing[]`**, **`coverage_total`**, **`gaps[]`**, **`framework_paths_excluded`**, **`kit_repo_skipped`**.

**Self-test token**: **`[PROJECT_README_COVERAGE_SELF_TEST_OK]`**.

### 10. Scratchpad keys (AC-7)

| Key | Values | Default | Notes |

| **`PROJECT_README_ENFORCE`** | **`0`** \| **`1`** | **`1`** post-bootstrap | **`0`** migration/grandfathering only |
| **`FRAMEWORK_KIT_REPO`** | **`0`** \| **`1`** | **`0`** | Consumer repos never **`1`** |

Publish in active + **`template/.cursor/scratchpad.local.example.md`**.

### 12. Contract tests + parity (AC-9, AC-10)

## Risks

| Risk | Mitigation |
|------|------------|
| **R1** Migration deletes operator prose | **S5** preserve + **M5** ambiguous fail-closed |
| **R2** **US-0091** regression | Explicit path table + regression guard test |
| **R3** Kit vs consumer repo | **`FRAMEWORK_KIT_REPO`** detection order + validator skip |

2. **Tranche B** — project README bootstrap scaffold
3. **Tranche C** — execute step **23** + release step **3g** + scratchpad keys
4. **Tranche D** — validators + contract tests + runbook
