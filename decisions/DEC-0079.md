# DEC-0079: Cursor browser-integrated UAT self-test — two-tier execution, evidence schema, and probe stub completion (US-0093)

- Date: 2026-06-06
- Status: Accepted
- Story: `US-0093`
- Composes on: **`DEC-0078`** (UAT probe catalog + fail-closed vocabulary — **extends execution**, does not weaken), **`US-0065`** (runtime QA browser guidance), **`US-0066`** (generated-project fast path), **`US-0048`** (spawn-only subagent model — **BUG-0006** unchanged)
- Extends: **`DEC-0047`** (process_health readiness poll), **`DEC-0038`** (strict runtime proof unchanged)
- Related: **`US-0092`**, **`US-0088`**, **`R-0079`**, **`R-0041`**
- Supersedes: none

## Context

**US-0092** / **DEC-0078** delivered the UAT probe catalog and fail-closed reason-code family via **`scripts/uat_probe_lib.py`**, but **`browser_smoke`**, **`process_health`**, and **`cli_smoke`** remain stub branches returning **`UAT_PROBE_UNRESOLVED`**, and **`manual_operator`** is always unresolved at execution. Operators classifying web acceptance steps get no runtime browser path in **`/verify-work`**, **`/qa`**, or **`/execute`**.

**US-0093** closes that gap with a **two-tier contract**: stdlib lib classifies, completes subprocess probes, and emits fallback plans; phase subagents invoke **Cursor built-in browser MCP** as the **primary** web self-test path when **`UAT_BROWSER_PROBE_MODE=cursor`** (default). Deterministic HTTP / Playwright subprocess fallbacks apply when MCP is unavailable (CI/headless). Automatable **`manual_operator`** UI steps re-route to browser probe plans. Evidence lands in **`uat.json`** `probe_results[]` via **`browser_evidence_refs`** — **no silent PASS**.

Operator intake locks Cursor browser as primary path per **R-0041**; stdlib-only Playwright-as-primary rejected.

## Decision

### 1. Two-tier execution model (AC-2, AC-3)

**Invariant**: **`scripts/uat_probe_lib.py`** **never** calls Cursor browser MCP directly (**BUG-0006** / spawn-only preserved).

| Tier | Owner | Responsibility |
|------|-------|----------------|
| **Tier 1 — stdlib** | **`uat_probe_lib.py`** | Classify steps; complete **`process_health`** / **`cli_smoke`**; HTTP/Playwright fallback subprocesses; emit probe plans with **`execution_tier`**; reason codes; **`--merge-result`** validation |
| **Tier 2 — agent** | **`/verify-work`**, **`/qa`**, **`/execute`** subagents | When **`UAT_BROWSER_PROBE_MODE=cursor`** and kind is **`browser_smoke`** or automatable **`manual_operator`**, execute MCP sequence; write **`browser_evidence_refs`** to **`uat.json`** + **`qa-findings.md`** |

**Dispatch table**:

| Caller | `execution_tier` | Behavior |
|--------|------------------|----------|
| **`uat_probe_lib.py` CLI** (`--report`) | **`stdlib`** or **`agent_deferred`** | In **`cursor`** mode: emit plan + **`UAT_PROBE_UNRESOLVED`** until agent completes — **never fabricate** **`browser_evidence_refs`**. |
| Phase subagents | **`agent`** | Execute normative MCP sequence (§2); merge final **`probe_results[]`** row. |

**Rejected alternative**: stdlib-only Playwright as primary — violates operator intake and **R-0041**.

### 2. Scratchpad keys (AC-1)

| Key | Values | Default | Role |
|-----|--------|---------|------|
| **`UAT_BROWSER_PROBE_MODE`** | **`cursor`** \| **`http_fallback`** \| **`playwright_fallback`** | **`cursor`** | Primary probe path selection |
| **`UAT_BROWSER_FALLBACK_CHAIN`** | **`0`** \| **`1`** | **`1`** in CI (`CI=true` or `GITHUB_ACTIONS=true`); **`1`** elsewhere | Enable HTTP → Playwright chain after MCP unavailable |
| **`UAT_PROCESS_HEALTH_POLL_SECONDS`** | positive int | **`60`** | Readiness poll cap for **`process_health`** |
| **`UAT_PROCESS_HEALTH_POLL_INTERVAL_SECONDS`** | positive int | **`2`** | Poll interval |
| **`DEV_SERVER_PORT`** | int | unset | URL/port inference override |
| **`DEV_SERVER_COMMAND`** | shell command | unset | **`process_health`** startup override |

**Orthogonal keys (unchanged)**: **`PERMISSION_MODE`**, Cursor browser approval settings (manual / allow-list / auto-run per vendor docs), **`runtime-connectivity.md`** health URLs.

Document interaction in scratchpad comment blocks (active + **`template/`** + local example), runbook, and **`auto-orchestration-reference.md`**.

### 3. Agent-browser MCP sequence (AC-2)

Normative sequence locked in **`.cursor/commands/verify-work.md`**, **`qa.md`**, **`execute.md`** — subsection **`### Browser UAT self-test (US-0093)`**:

1. **Resolve target URL** — **`docs/engineering/runtime-connectivity.md`** first `http(s)://`; else dev-server port from **`package.json`** + **`DEV_SERVER_PORT`**; prefer existing running server (vendor dev-server awareness).
2. **`browser_navigate`** — load health/app URL; respect enterprise origin allowlist.
3. **Step plan** — map acceptance verbs to **`browser_click`** / **`browser_type`** / **`browser_scroll`** when automatable (§4); **never** fill password/credential fields or read **`.env`** paths.
4. **`browser_screenshot`** — write to **`sprints/Sxxxx/evidence/browser/<probe_id>-<seq>.png`** (max **5** per probe).
5. **Console + network evidence** — counts + summary path refs only (no inline secrets).
6. **Verdict** — set **`passed`**, **`reason_code`**, **`browser_evidence_refs`**; **`passed=true`** in **`cursor`** mode **requires** non-empty **`navigation_url`** + at least one screenshot or console/network summary path — else downgrade to **`UAT_BROWSER_PROBE_FAILED`**.
7. **Fallback trigger** — MCP unavailable → record **`UAT_BROWSER_UNAVAILABLE`**, run stdlib fallback chain (§5) when mode allows; both fail → **`UAT_BROWSER_PROBE_FAILED`** (no PASS).

**Write-back**: subagent updates **`uat.json`** `probe_results[]` in place (match **`probe_id`**); optional **`python scripts/uat_probe_lib.py --merge-result <fragment.json>`** validates schema + evidence-required-on-PASS.

### 4. `manual_operator` verb routing (AC-3)

**Classifier extension** in **`classify_step`** — **precedence: judgment deny signals win** over automatable UI signals.

| Signal class | Tokens (case-insensitive substring) | Route |
|--------------|-------------------------------------|-------|
| **Judgment-only** | `visually`, `aesthetically`, `operator confirms`, `subjective`, `human judgment`, `eyeball`, `manually verify appearance`, `approve layout` | **`manual_operator`** → **`UAT_PROBE_UNRESOLVED`** |
| **Secret/forbidden** | `.env`, `password`, `credential`, `api key`, `intake_evidence` | **`UAT_PROBE_FORBIDDEN`** |
| **Automatable UI** | `click`, `fill`, `navigate`, `smoke`, `form`, `submit`, `button`, `page load`, `scroll`, `type into`, `select`, `checkbox`, `dropdown`, `ui`, `browser` | Reclass to **`browser_smoke`** when URL/stack resolves |
| **Generic manual** | `manual`, `operator`, `human`, `judgment` (without UI verbs) | **`manual_operator`** → **`UAT_PROBE_UNRESOLVED`** |

Mixed-verb example: `"operator visually confirms button click"` → judgment wins → unresolved.

### 5. Fallback selection (AC-2, AC-6)

| Mode | Primary | Fallback chain |
|------|---------|----------------|
| **`cursor`** | Agent MCP (§3) | **`http_fallback`** → optional **`playwright_fallback`** when **`UAT_BROWSER_FALLBACK_CHAIN=1`** |
| **`http_fallback`** | Stdlib **`urllib`** GET (reuse **`api_health`** + optional HTML title sniff) | Fail **`UAT_BROWSER_PROBE_FAILED`** |
| **`playwright_fallback`** | Subprocess Playwright when detected | **`http_fallback`** if missing → **`UAT_BROWSER_UNAVAILABLE`** |

**MCP-unavailable heuristic** (deterministic):

1. **`CI=true`** or **`GITHUB_ACTIONS=true`** → skip MCP; enter fallback with **`UAT_BROWSER_UNAVAILABLE`** on probe row.
2. Subagent tool inventory lacks browser MCP → same.
3. Enterprise origin allowlist blocks URL → **`UAT_BROWSER_UNAVAILABLE`**.

**HTTP vs Playwright precedence**: HTTP first (stdlib-only); Playwright only when step requires DOM interaction verbs and HTTP 200 insufficient.

### 6. `process_health` / `cli_smoke` stub completion (AC-4)

**`process_health`** (**`execution_tier=stdlib`**):

- Command extraction: backtick command, quoted `"npm start"`, regex after startup verbs; fallback **`package.json`** `scripts.start`/`scripts.dev`; scratchpad **`DEV_SERVER_COMMAND`** override.
- Readiness poll: **`_read_health_url(repo)`** every **`UAT_PROCESS_HEALTH_POLL_INTERVAL_SECONDS`** until 2xx or **`UAT_PROCESS_HEALTH_POLL_SECONDS`** cap.
- Verdict: **`UAT_PROBE_PASS`** | **`UAT_PROBE_TIMEOUT`** | **`UAT_PROBE_FAILED`** (same family as **DEC-0078** §4).

**`cli_smoke`**:

- Backtick command; patterns `exit code 0`, `exits successfully`, `run CLI`.
- Assertion: **`exit_code == 0`**; optional stdout substring from `expect "..."` / `output contains "..."`.
- No LLM command inference — regex/deterministic only.

### 7. Evidence schema (AC-5)

**Artifact layout**: **`sprints/Sxxxx/evidence/browser/`** (binary gitignored OK; path refs in JSON only).

**`probe_results[]` extension** (extends **DEC-0078**):

```json
{
  "probe_id": "pr-<uuid>",
  "probe_kind": "browser_smoke",
  "execution_tier": "agent",
  "probe_mode": "cursor",
  "step": "<truncated acceptance step>",
  "passed": true,
  "reason_code": "UAT_PROBE_PASS",
  "browser_evidence_refs": {
    "navigation_url": "http://localhost:3000/",
    "screenshots": ["sprints/Sxxxx/evidence/browser/pr-<uuid>-01.png"],
    "console_summary": {
      "error_count": 0,
      "warning_count": 1,
      "summary_path": "sprints/Sxxxx/evidence/browser/pr-<uuid>-console.txt"
    },
    "network_summary": {
      "failed_request_count": 0,
      "summary_path": "sprints/Sxxxx/evidence/browser/pr-<uuid>-network.txt"
    }
  }
}
```

**Cardinality**: max **5** screenshots; summary files paths only. **`qa-findings.md`** mirrors under **Runtime browser evidence** subsection (**US-0065** AC-6).

### 8. New fail-closed reason codes (AC-6)

| Code | When |
|------|------|
| **`UAT_BROWSER_UNAVAILABLE`** | MCP unavailable and fallback not attempted or not configured |
| **`UAT_BROWSER_PROBE_FAILED`** | Browser or fallback ran; assertion/evidence check failed |
| **`UAT_BROWSER_PROBE_TIMEOUT`** | Browser probe exceeded bounded timeout |

Existing **DEC-0078** codes unchanged. Extend **`uat_probe_lib.py --self-test`** + command docs.

### 9. Security (AC-7)

- No auto-read **`.env`**, no credential auto-fill, no intake evidence mutation.
- **`UAT_PROBE_FORBIDDEN`** unchanged for secret paths.
- Respect Cursor origin/approval guardrails; production-like auto-bypass requires explicit scratchpad opt-in (out of scope).
- **DEC-0078** §8 security deny-list **not weakened**.

### 10. Operator docs (AC-8)

Runbook + **`auto-orchestration-reference.md`**: enable browser self-test, dev-server detection, evidence locations, fallback behavior, **`@browser`** / Agent panel manual override recipe.

## Alternatives considered

1. **Stdlib Playwright as primary** — rejected (operator intake + **R-0041**).
2. **Lib invokes browser MCP directly** — rejected (**BUG-0006** spawn-only).
3. **Silent PASS when MCP unavailable** — rejected; fail closed **`UAT_BROWSER_UNAVAILABLE`** + fallback chain.
4. **LLM command inference for `cli_smoke`** — rejected; deterministic parse only.
5. **Auto-bypass browser approval in production** — rejected without explicit scratchpad opt-in.

## Consequences

- **`/execute`** implements lib extensions, command contracts, evidence schema, contract tests, and template parity per sprint tasks.
- **`/architecture`** **`# US-0093`** is normative companion; **`R-0079`** research narrowed by this decision's literals.
- CI repos should set **`UAT_BROWSER_PROBE_MODE=http_fallback`**; never false PASS.
