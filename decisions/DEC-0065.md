# DEC-0065: Codebase map bootstrap lifecycle and ownership (US-0082)

- Date: 2026-03-31
- Status: Accepted
- Story: `US-0082`
- Research: `R-0060`
- Supersedes: none

## Context

Agents and operators expect `docs/engineering/codebase-map.md` to exist in fresh repos without memorizing manual steps. **`/map-codebase`** already defines outputs and writer roles, but lifecycle invocation is not guaranteed (**US-0001** done; **BUG-0002** closed as expectation mismatch). **`R-0060`** catalogs hook families; this decision selects a minimal normative binding that satisfies **AC-1..AC-10** without silent **`/auto`** scope creep (**DEC-0052**).

## Options considered

1. **Diagnostics-only** — runbook + `/ask` detect missing map; no lifecycle hook. Rejected: fails **AC-1** for unattended fresh repos.
2. **Every `/auto` phase** — regenerate map on each boundary. Rejected: churn risk on **`state.md`** and merge noise (**R-0060**).
3. **CI-only guard** — fail builds without map. Rejected as sole solution: late feedback; still needs lifecycle owner (**AC-1**).
4. **Phase-gated bootstrap + manual override (chosen)** — primary guarantee at **`/architecture`** exit; secondary optional refresh at **`/refresh-context`**; **`/map-codebase`** remains explicit manual path (**AC-2**).

## Decision

### 1. Lifecycle points (normative)

- **Primary**: **`/architecture` phase completion** (role **tech-lead**) — before handoff to **`/sprint-plan`**, the responsible party MUST ensure `docs/engineering/codebase-map.md` exists **or** emit deterministic skip/block diagnostics per §4 (implementation may invoke **`/map-codebase`** semantics or an idempotent script; sprint owns mechanism).
- **Secondary (optional refresh)**: **`/refresh-context`** (role **curator**) MAY re-check map freshness when project policy enables map refresh at context rollover (scratchpad/profile-gated; default off for churn control).
- **Manual**: **`/map-codebase`** remains the explicit operator command; documentation MUST state when auto/bootstrap vs manual applies (**AC-2**).

### 2. Idempotency (**AC-3**)

- Regeneration MUST be safe to rerun: stable section ordering, no spurious timestamp-only churn unless an acceptance test explicitly requires audit stamps; prefer content-hash or structural equality skip.

### 3. Ownership and writes (**AC-4**)

- Map generation MUST respect the same artifact boundaries as **`/map-codebase`**: primary writes to `docs/engineering/codebase-map.md` and declared companion outputs (e.g. `docs/engineering/dependencies.json`); **`docs/engineering/state.md`** remains append-only with bounded, ownership-safe map-related checkpoints only where the command contract already allows.

### 4. Diagnostics (**AC-5**)

- When map creation is skipped or blocked, emit deterministic reason codes with remediation, e.g.:
  - **`CODEBASE_MAP_MISSING`**
  - **`CODEBASE_MAP_BLOCKED:<subreason>`**
- Remediation text MUST point to **`/map-codebase`** and the runbook section anchored in **`architecture.md`** **`# US-0082`**.

### 5. Guidance (**AC-6**)

- Runbook and **`/ask`** guidance MUST name **`/architecture`** as the primary lifecycle owner for bootstrap and **`/map-codebase`** as the manual override.

### 6. Parity and regression (**AC-7**, **AC-8**)

- Active + `template/` surfaces for commands, rules, and docs participating in bootstrap MUST stay mirrored; regression tests MUST cover fresh-repo path, idempotent rerun, and failure-path diagnostics.

### 7. Backward compatibility (**AC-9**)

- Existing repos with a pre-existing map MUST remain valid; generators MUST merge or refresh without destructive truncation unless explicitly operator-triggered.

### 8. Bug tracking (**AC-10**)

- **`BUG-0002`** remains **DONE** as expectation mismatch; **`US-0082`** owns delivery — no duplicate defect tracking.

### 9. Profile / phase-plan containment (**DEC-0052**)

- Default **`/auto`** behavior MUST NOT run map generation on every phase; hooks are limited to §1 points and explicit policy flags documented in sprint implementation.

## Consequences

- Fresh-repo agent bootstrap gains a named lifecycle owner without mandating heavy automation on every orchestrator tick.
- Sprint work wires commands, optional validators, tests, and docs to this contract.

## Risks

| Risk | Mitigation |
|------|------------|
| Architecture phase skipped in custom profiles | Document profile gap + **`CODEBASE_MAP_MISSING`** diagnostic; optional CI guard (**AC-8**). |
| Curator refresh causes churn | Default off; idempotent skip rules §2. |
| Template drift | Parity checks §6. |

## Decision outcome

- Approved option: **4** (phase-gated bootstrap + manual override)
- Approval source: architecture phase (**tech-lead**), `orchestrator_run_id=auto-20260331-02`
