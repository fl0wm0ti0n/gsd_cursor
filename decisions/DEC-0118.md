## Context

**US-0096** / **DEC-0082** optimized lifecycle **shape** via global `DELIVERY_MODE` (standard / ultra_lean / mega_quick); **DEC-0052** provided per-invocation phase selection via `AUTO_PHASE_*`. However, both are **global / per-invocation** controls â€” neither derives the routing from the **story's actual shape**. Operators pay architecture / qa / verify-work overhead just to update a README, because every `US-xxxx` story runs the same canonical lifecycle (or one global `DELIVERY_MODE`) regardless of whether it is a README tweak, a mini code fix, or a full feature.

Operator pain (verbatim from intake): "wir mÃ¼ssen beim erstellen von userstories bzw abarbeiten erkennen ob es coding betrifft oder doku / text schreiben oder mini implementierungen welche keine komplette phasen durchlÃ¤ufe benÃ¶tigen. wie zb Architecture, qa, etc... aktuell laufen wir zb den ganzen overhead durch nur um ein readme zu aktualisieren."

**US-0118** introduces a deterministic **per-story work-kind classifier** `scripts/work_kind_classify_lib.py:classify_work_kind(story_prose, acceptance_criteria, touched_file_hints, component_scope) -> WorkKindClassification` returning `work_kind âˆˆ {doc, mini, code}` + `recommended_delivery_mode âˆˆ {standard, ultra_lean, mega_quick}` + `recommended_phase_plan` (list of canonical phase ids) + `rationale` + `evidence_refs` (+ optional `rule_trace` via `--explain`). A new default-off scratchpad flag `WORK_KIND_ROUTING=0|1` gates the feature (zero overhead when off â€” early-return in `/auto` `resolve_delivery_mode` step 0 + `/intake` step 5 skip when `WORK_KIND_ROUTING != "1"`). Backlog rows gain optional `work_kind` + `recommended_delivery_mode` fields set at intake (operator accept/override; recorded in intake evidence bundle per US-0078 / DEC-0060). The classifier reuses `scripts/dev_environment_lib.py:classify_touched_files()` (tier A/B/C + `TIER_C_SKIP_PREFIXES`) â€” import, do not reinvent (Q9 LOCKED).

Research basis: **`R-0106`** Q1â€“Q10 (10/10 closed LOCKED).

## Decision

### 1. Work-kind enumeration — 3-tier `doc` / `mini` / `code` (AC-1, AC-2)

**Enumeration**: `work_kind ? {"doc", "mini", "code"}` returned by `scripts/work_kind_classify_lib.py:classify_work_kind(...)`.

**Mapping to delivery mode + phase plan**:

| work_kind | recommended_delivery_mode | recommended_phase_plan | Rule |
|-----------|---------------------------|------------------------|------|
| **`doc`** | **`standard`** (phase plan itself encodes the skip — no delivery-mode change required) | `[intake, execute, release]` (skip discovery/research/architecture/sprint-plan/plan-verify/qa/verify-work) | All touched files match `dev_environment_lib.TIER_C_SKIP_PREFIXES` (`docs/`, `handoffs/`, `sprints/`, `decisions/`, `tests/`, `.cursor/commands/`, `template/docs/`) or are `*.md`/`README*` under skip prefixes (L5). |
| **`mini`** | **`ultra_lean`** or **`mega_quick`** (per US-0096 eligibility) | `[spec, plan, build+verify, ship]` (ultra_lean) or `[quick]` (mega_quick) | Single component, ACs = 3, no companion DEC required (L6). Classifier recommends `mega_quick` only when US-0096 `MEGA_QUICK_*` eligibility passes (AC = 3, no DEC, single component, no active sprint, no gate escalation); else falls back to `ultra_lean`. |
| **`code`** | **`standard`** (or honor current `DELIVERY_MODE` if explicitly set) | Full canonical lifecycle (DEC-0052 chain) | Otherwise (L7). |

**Tie-break rule (Q1 LOCKED)**: when a story touches both `docs/` and `src/` (mixed tier), **highest tier wins** (`code` > `mini` > `doc`) per `dev_environment_lib.classify_touched_files` tier_rank A>B>C precedent (`tier_rank={"A":3,"B":2,"C":1}`, L321–L339: highest matching tier wins). Mapping: tier A (lockfiles / Dockerfile / package.json) or any non-skip-prefix source path ? `code`; tier B ? `mini` unless overridden by A; tier C (skip-prefix-only / `*.md` under skip prefixes) ? `doc`. Deterministic, single-pass.

**Rejected alternatives**: (a) 2-tier `doc`/`non-doc` collapsed — rejected as too coarse (conflates `mini` and `code`, loses the `mega_quick` eligibility signal); (b) 4-tier `doc`/`mini`/`standard`/`extended` — rejected as over-engineered (no operator demand for `extended`; 3-tier mirrors `classify_touched_files` tier A/B/C precedent cleanly).

### 2. L8 precedence chain — explicit operator flags always win (AC-6)

**Resolution precedence** (LOCKED):

1. **`start-from=<phase>`** (always wins — intersects with whatever plan is active per DEC-0052 §2.5)
2. **Explicit `DELIVERY_MODE`** (US-0096 / DEC-0082 — argv `delivery-mode=` > backlog row `delivery_mode` when `AUTO_DELIVERY_ROUTING=backlog_then_scratchpad` > scratchpad `DELIVERY_MODE`)
3. **Explicit `AUTO_PHASE_*`** (US-0070 / DEC-0052 — `AUTO_PHASE_PLAN` / `AUTO_PHASE_EXCLUDE` / `AUTO_PHASE_INCLUDE` / `AUTO_PHASE_PROFILE`)
4. **`WORK_KIND_ROUTING`-derived `recommended_delivery_mode`** (US-0118 — only when `WORK_KIND_ROUTING=1` AND backlog row carries `work_kind` AND higher-precedence keys unset)
5. **Current default lifecycle** (full DEC-0052 chain; `standard` delivery mode)

**Conflict rule**: work-kind recommends `X` but explicit `DELIVERY_MODE=Y` set and they differ ? **`WORK_KIND_DELIVERY_MODE_CONFLICT`** reason code (fail-closed). Mid-story `DELIVERY_MODE` switch forbidden per DEC-0082 §2 (`DELIVERY_MODE_SWITCH_MID_STORY`).

**Early-return (zero overhead — Q8 LOCKED)**: when `WORK_KIND_ROUTING != "1"`, `/auto` `resolve_delivery_mode` step 0 returns the pre-US-0118 result without invoking `classify_work_kind`; `/intake` step 5 skips the classifier proposal entirely. Existing backlog rows without `work_kind`/`recommended_delivery_mode` route via current `DELIVERY_MODE`/`AUTO_PHASE_*` precedence (no forced reclassification, no schema-migration).

### 3. `dev_environment_lib.classify_touched_files` reuse boundary — import, not rewrite (Q9 LOCKED)

**Import contract**: `scripts/work_kind_classify_lib.py` imports `TIER_C_SKIP_PREFIXES` + `classify_touched_files` from `dev_environment_lib` — no duplication. The classifier sees file **names** only (no content reads); inputs are `touched_file_hints: list[str]` (names-only). Contract test `test_us0118_classify_touched_files_reuse` enforces the import boundary.

**Rejected alternative**: duplicate `TIER_C_SKIP_PREFIXES` + `classify_touched_files` logic inside `work_kind_classify_lib.py` — rejected because it creates drift risk (R6) and violates DRY; the import contract keeps the tier A/B/C + skip-prefix single source of truth in `dev_environment_lib`.

### 4. Zero-overhead-when-off contract — default `WORK_KIND_ROUTING=0` (AC-3, AC-8, Q8 LOCKED)

**Scratchpad keys** (active `.cursor/scratchpad.md` + `template/.cursor/scratchpad.local.example.md`):

| Key | Values | Default |
|-----|--------|---------|
| **`WORK_KIND_ROUTING`** | **`0`** \| **`1`** | **`0`** (zero overhead when off) |

**Merge precedence** (US-0078 model B per DEC-0060): local > materialized baseline > example.

**When `WORK_KIND_ROUTING=0`** (default):
- `/auto` `resolve_delivery_mode` step 0 returns pre-US-0118 result without invoking `classify_work_kind` (early-return).
- `/intake` step 5 skips the classifier proposal entirely.
- Existing backlog rows without `work_kind`/`recommended_delivery_mode` route via current `DELIVERY_MODE`/`AUTO_PHASE_*` precedence (no forced reclassification, no schema-migration required).
- Contract test `test_us0118_default_off_zero_overhead` asserts byte-identical-to-pre-US-0118 behavior.

**When `WORK_KIND_ROUTING=1`**:
- `/intake` step 5 (after ACs drafted, after US-0051 decomposition evaluator, before persistence) runs the classifier, proposes `work_kind` + `recommended_delivery_mode`, presents to operator for accept/override (Q9). Persist choice in backlog row (`- work_kind`, `- recommended_delivery_mode`) + intake evidence bundle (`work_kind`, `recommended_delivery_mode`, `work_kind_operator_decision ? {accept, override}`).
- `/auto` `resolve_delivery_mode` step 0 consumes `recommended_delivery_mode` when `DELIVERY_MODE`/`AUTO_PHASE_*` are unset (L8 precedence).
- US-0078 evidence gate still runs before any backlog/acceptance write (L10).

**Mirrors precedent**: US-0034 / US-0035 / US-0089 zero-overhead-when-off contract pattern (default-off runtime gates).

### 5. Classifier determinism — pure stdlib, no LLM (Q3 LOCKED, AC-1)

**Deterministic pure-stdlib (rule-based), NO LLM-assisted classification**. Classifier sees `story_prose` + `acceptance_criteria` + `touched_file_hints` (names-only, no content reads) + `component_scope` only. Rationale: deterministic + testable + zero-token-cost + auditable; mirrors `dev_environment_lib.classify_touched_files` rule-engine pattern.

**`--explain` flag** emits a human-readable rule trace (`rule_trace` list of `(rule_id, matched_signal, contribution)` tuples) so operators can override with confidence (per R5). No network, no `.env` reads, no model calls.

**`--self-test`** (AC-12) exits 0; triple-installer parity (PS1/Bash/Python) ships the new script.

### 6. Fail-closed reason codes — four `WORK_KIND_*` codes (AC-7, Q2 LOCKED)

| Reason code | Fail-closed? | Remediation prose |
|-------------|--------------|-------------------|
| **`WORK_KIND_CLASSIFY_FAILED`** | yes | "Re-run `/intake` with explicit `work_kind` override; inspect `--explain` trace; file bug if rule engine is at fault". |
| **`WORK_KIND_DELIVERY_MODE_CONFLICT`** | yes | "Explicit `DELIVERY_MODE` wins per L8 precedence; either unset `DELIVERY_MODE` to allow work-kind routing or update the backlog row; mid-story switch forbidden (`DELIVERY_MODE_SWITCH_MID_STORY`)". |
| **`WORK_KIND_ROUTING_DISABLED`** | no (info-only) | "Set `WORK_KIND_ROUTING=1` to enable per-story routing; current behavior unchanged". |
| **`WORK_KIND_PLAN_COVERAGE_MISSING`** | yes | "Re-run classifier; if persistent, set `DELIVERY_MODE` explicitly or add `AUTO_PHASE_*` override; default to `standard` lifecycle". |

Each emits remediation guidance in `sprints/Sxxxx/qa-findings.md` / `release-findings.md`.

### 7. Intake-time operator accept/override gate (AC-5, Q9 LOCKED)

**Intake evidence schema extension** (`handoffs/intake_evidence/US-xxxx-intake.json`): three new optional fields:

| Field | Values | When present |
|-------|-------|--------------|
| `work_kind` | `doc` \| `mini` \| `code` | When `WORK_KIND_ROUTING=1` and classifier ran at `/intake` step 5 |
| `recommended_delivery_mode` | `standard` \| `ultra_lean` \| `mega_quick` | When `WORK_KIND_ROUTING=1` and classifier ran at `/intake` step 5 |
| `work_kind_operator_decision` | `accept` \| `override` | When `WORK_KIND_ROUTING=1` and operator made an explicit decision |

When `WORK_KIND_ROUTING=1`, `/intake` step 5 (after ACs drafted, after US-0051 decomposition evaluator, before persistence) runs the classifier, proposes `work_kind` + `recommended_delivery_mode`, presents to operator for accept/override. Operator decision recorded in the evidence bundle. If `override`, operator may set a different `work_kind`/`recommended_delivery_mode` (or leave both unset to defer routing to `DELIVERY_MODE`/`AUTO_PHASE_*`). Backlog row gains `- work_kind: <value>` and `- recommended_delivery_mode: <value>` lines when operator accepts; absence is valid (classifier not run or operator declined). US-0078 evidence gate still runs before any backlog/acceptance write.

## Consequences

- **Positive**: Predictable per-story routing derived from story shape; small items skip architecture/qa/verify-work overhead; explicit operator flags always win (no silent override); deterministic + inspectable classifier; zero overhead when off; backward-compatible (no forced reclassification).
- **Negative**: More scratchpad surface area (`WORK_KIND_ROUTING` + `WORK_KIND_*` reason-code family); new code surface (`scripts/work_kind_classify_lib.py` + tests); new intake-evidence schema fields; 6th cumulative byte-stability surface (must preserve US-0113..US-0117 README blocks).
- **Neutral**: Implementation lives in `/execute` (build+verify macro); this decision fixes the architecture contract only. `/sprint-plan` may merge or split the 10 task seeds within the 12-task budget.
