## Context

US-0126 loop-2 needed B-1 remediation after architecture rollover archived `# US-0089` / `# US-0090` / `# US-0091` / `# US-0093` / BUG-0011 while contract tests still assert those tokens on active `architecture.md` (harness Fail:7). Headings were restored; no guard shipped. US-0129 is that guard.

`rollover_architecture` pops oldest story blocks when `ARCH_HOT_MAX_LINES` / `ARCH_HOT_MAX_STORY_SECTIONS` are exceeded and writes an archive pack with **no check** that contract tests still require those headings on the hot file. `/refresh-context` `--check` only covers triad cap oversize.

R-0113 locked DQ1–DQ8. This DEC records the architectural contract execute inherits: wrap (do not rewrite) the archiver; fail closed; default-off bounded H1-stub repair; discover required headings from consumer tests; security_hard never skip.

Highest existing DEC **file** is **DEC-0126**. US-0127 / US-0128 / US-0130 documented “no companion DEC”. This record is **story-aligned DEC-0129** so it does not collide with those “none” records. Historical DEC ids are not renumbered.

## Decision

### 1. Guard wraps `--rollover`; archiver UNCHANGED (DQ3 / D1 / D4 / D10 — AC-1 / AC-4)

Ship `scripts/arch_linkage_guard.py` (+ template mirror) invoked **pre** and **post** `python scripts/enforce-triad-hot-surface.py --rollover`. Import/call `split_arch_stories` and the same while-pop predicate — do **not** copy-fork. Do **not** change heading-split semantics, pack naming, pack-header format, or `ARCH_HOT_MAX_*` policy numbers.

**Rejected**: mutate `rollover_architecture` to skip required headings (DEC-0054 compose); raise caps instead of a guard (D10 — B-1 is linkage).

### 2. Fail-closed `ARCH_LINKAGE_ROLLOVER_BLOCKED` is `security_hard` (DQ4 / DQ5 / D2 — AC-2)

On predicted or actual missing required heading: emit `ARCH_LINKAGE_ROLLOVER_BLOCKED` with story/bug id, missing heading token, archive pack path (predicted or written), remediation. Pre-hook: **no partial write** (no pack file, hot file bytes unchanged). Post-hook: packs are append-only; no pack rollback.

Classify the code **`security_hard`** in `scripts/data/autonomy_stop_matrix.yaml` + `docs/engineering/autonomy-stop-matrix.md` (`auto_repair_kind=n/a`, `cap=0`). **Never skip** — including `AUTONOMY_STOP_POLICY=auto_repair_then_skip`. Register `## US-0129 — Architecture hot-surface rollover linkage guard` in `docs/engineering/reason_codes.md` (after last story family, before `## Other stories`). Do not invent sibling codes in v1 (`ARCH_LINKAGE_REPAIR_FAILED` is message text under the same code unless execute proves a split).

**Rejected**: 10th `auto_repair_kind`; skip-on-policy; extend US-0110 / US-0127 / US-0128 / US-0111 tables.

### 3. `ARCH_LINKAGE_AUTO_REPAIR=0` default-off; not in `AUTONOMY_PRESET` (DQ1 / D3 — AC-3)

New scratchpad flag `ARCH_LINKAGE_AUTO_REPAIR=0|1` (default **0**). Opt-in bounded H1-stub restore only when `=1`. Comment next to `AUTONOMY_STOP_POLICY`. No live `=1` in committed scratchpad. Do **not** add the flag to `AUTONOMY_PRESET` expansion (DEC-0119: twelve flags unchanged). Explicit key only; default 0 even under `AUTONOMY_PRESET=full`. Bounded repair is a **guard-script** path, not a matrix reclassification.

**Rejected**: default-on (would silently rewrite architecture.md under `full`); always-block with no flag (AC-3 requires optional repair + idempotent audit row).

### 4. Discover headings from contract tests; no manifest (DQ2 — AC-1)

`discover_required_arch_headings(repo) -> frozenset[str]`: stdlib scan of `tests/**/*_test.py`, exclude `tests/.tmp*`. Include a heading only when the test reads live `docs/engineering/architecture.md` and asserts membership / `find` / `startswith` of a literal `# US-dddd` or `# BUG-dddd`. Prefer the helper over a hand-maintained YAML/manifest. Do not couple to `validate_readme_feature_coverage` story lists. Live set at R-0113 is **evidence, not a frozen manifest** — helper re-discovers at runtime.

**Rejected**: static allowlist (B-1 class); scanning command-file greps or self-test fixtures.

### 5. Minimal H1 stub shape + insertion (DQ8 — AC-3)

Heading: `# US-xxxx — <title from archived block’s first heading line>` (or `# BUG-xxxx — …`) matching `STORY_HEADING_H1` (`[:\u2014\-]` required). Body: exactly one `pack_ref` pointer line. Insert into the **retained** hot surface **before** the US-0089 / US-0090 tail. Never append after US-0089 except US-0090 itself. Idempotent. Title from archived `first_heading` — do not invent. v1 is **heading-only** (Q3); named body tokens (US-0100 `{semver}-release-notes.md`) are residual R3, not in v1.

**Rejected**: bare `# US-xxxx` without title separator; full-section restore; append-after-0089.

## Consequences

- **Positive**: Rollover can no longer silently drop headings that contract tests still require; operators get an explicit block with remediation; opt-in stub repair is bounded, idempotent, and audited; archiver bytes stay a DEC-0054 compose surface.
- **Negative**: `/refresh-context` gains two stdlib scans; a new fail-closed family and scratchpad flag; first post-ship `--rollover` may block if a required heading is already absent (helper re-discovers — remediate via AC-2, do not pre-seed stubs in architecture).
- **Neutral**: `ARCH_HOT_MAX_*` unchanged; US-0126 B-1 remains a regression fixture; body-token asserts stay a documented residual.

## Risks

All R-0113 risks ACCEPTED: R1 helper false-positive (marker 1 + exclude `.tmp*` / non-architecture reads); R2 stub after US-0089 (DQ8 + marker 5); R3 body-token residual (heading-only v1; do not reopen US-0100); R4 skip-policy surprise (security_hard); R5 dual-hook latency (local stdlib). Architecture adds R6: helper may discover an already-absent required heading at first post-ship rollover — same AC-2 remediation.
