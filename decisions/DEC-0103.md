# DEC-0103: AI Decision Ledger + Plan Fidelity policy (US-0103)

- **Date**: 2026-06-28
- **Status**: Accepted
- **Story**: `US-0103`
- **Composes on**: **US-0070** (phase selection policy), **US-0069** (phase role enforcement), **US-0048** (per-phase subagent isolation), **US-0092** (full-autonomy outer driver) — **do not amend**; US-0103 operates **ON TOP of** `resolved_phase_plan` / isolation evidence
- **Related**: `R-0089` (research anchor), **US-0104..US-0110** (sovereign-loop descendants), **US-0111** (ledger consumer — writes `derivation_decisions[]`), **US-0045** (status authority)
- **Supersedes**: none
- **Default-off**: `AI_DECISION_LEDGER=0` — zero overhead when off

## Context

Sovereign-loop foundation layer (US-0103..US-0110). Every autonomous AI decision made during `/auto` (or any phase writing to `resolved_phase_plan`) must be auditable via an append-only ledger. Plan fidelity — how strictly autonomous agents adhere to previously committed acceptance criteria — is governed by a scratchpad-controlled tri-state (`strict` / `relaxed` / `extended`). QA cross-checks the ledger at every `/qa` boundary. **US-0070 / US-0069 / US-0048 / US-0092 are UNCHANGED** — US-0103 writes alongside, never mutates existing files.

Research basis: `R-0089` Q1–Q7 closed.

## Decision

### §1 — Scratchpad keys (AC-1)

| Key | Values | Default | Notes |
|-----|--------|---------|-------|
| **`AI_DECISION_LEDGER`** | **`0`** \| **`1`** | **`0`** | When `0`, no file writes, no reads, no checks — **zero overhead**. |
| **`AUTO_PLAN_FIDELITY`** | **`strict`** \| **`relaxed`** \| **`extended`** | **`strict`** | Active only when `AI_DECISION_LEDGER=1`. |

Both keys published in **`.cursor/scratchpad.md`** (active + **`template/.cursor/scratchpad.md`** byte-parity per **US-0017**).

**Rejected**: always-on ledger (**rejected** — violates default-off discipline).
**Rejected**: more than three fidelity modes (**rejected** — strict/relaxed/extended cover the full spectrum; orthogonal to scratchpad `*OVERRIDE` keys).

### §2 — JSONL schema v1 (AC-2)

**Canonical path**: **`handoffs/sovereign_decisions/<orchestrator_run_id>.jsonl`**. One file per orchestrator run.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| **`ts`** | ISO 8601 UTC string (`YYYY-MM-DDTHH:MM:SS.sssZ`) | yes | sortable; monotonic per file |
| **`orchestrator_run_id`** | string | yes | matches file name stem; partition key |
| **`phase_id`** | string | yes | **DEC-0086** canonical phase id (`intake`, `research`, `execute`, ...) |
| **`role`** | string | yes | logical role (`po`, `tech-lead`, `dev`, `qa`, `security`, `release`, `curator`) |
| **`decision_id`** | UUIDv4 | yes | globally unique across runs |
| **`decision_type`** | enum | yes | see §3 deviation table |
| **`from_artifact`** | string (path) | yes | `(none)` when no source artifact |
| **`to_artifact`** | string (path) | yes | `(none)` when no target artifact |
| **`rationale`** | non-empty string | yes | operator-auditable prose in English |
| **`plan_fidelity`** | enum | yes | `strict` \| `relaxed` \| `extended` |
| **`cross_model_reviewed`** | bool | yes | `false` default; `true` when US-0104 critic has weighed in |
| **`risk_tier`** | enum | yes | `low` \| `medium` \| `high` \| `critical` |

**Invariant**: `schema_version: 1` implicitly via field inventory. Future changes bump to `schema_version: 2`.

**Semantics**:
- One JSON object per line; newline-terminated.
- Append-only: existing lines immutable; new line = one decision; fsync after append.
- UTF-8 encoded. No BOM.
- File must not be deleted by its writer; archival = rename by orchestrator, not lib.

### §3 — Plan-fidelity deviation classification table (AC-3, AC-4, AC-5)

Deviation kind → (`decision_type`, blocking behavior) per active mode:

| Mode | Deviation kind | `decision_type` | Outcome |
|------|----------------|-----------------|---------|
| **strict** | drop AC | `PLAN_FIDELITY_VIOLATION` | **hard stop** — `PLAN_FIDELITY_VIOLATION` |
| **strict** | reorder AC | `PLAN_FIDELITY_VIOLATION` | **hard stop** |
| **strict** | add scope (new story / feature / target) | `PLAN_FIDELITY_SCOPE_GATE` | **hard stop** |
| **strict** | operator-approved relaxation via scratchpad | `PLAN_FIDELITY_OVERRIDE` | recorded + continue |
| **relaxed** | drop AC | `PLAN_FIDELITY_REORDER` | recorded + continue |
| **relaxed** | reorder AC | `PLAN_FIDELITY_REORDER` | recorded + continue |
| **relaxed** | add scope | `PLAN_FIDELITY_SCOPE_GATE` | **hard stop** |
| **extended** | add scope (new story / feature / target) | `PLAN_FIDELITY_EXTENSION` | non-blocking + appended to extension report |
| **extended** | drop / reorder AC | `PLAN_FIDELITY_REORDER` | recorded + continue |
| *any mode* | generic autonomous decision | `LEDGER_DECISION` | recorded |
| *any mode* | derivation decision (e.g. US-0111) | `LEDGER_DERIVATION` | recorded |
| *any mode* | phase boundary crossing | `LEDGER_PHASE_TRANSITION` | recorded |
| *any mode* | delegation to subagent | `LEDGER_DELEGATION` | recorded |

**Strict-mode operator-approved relaxation**: when operator explicitly sets `PLAN_FIDELITY_APPROVED_OVERRIDES=<csv-of-ac-ids>` in scratchpad or equivalent, ledger records `PLAN_FIDELITY_OVERRIDE`; all other deviations remain hard stops.

**QA cross-check contract** (§6): `PLAN_FIDELITY_VIOLATION` count > 0 on a ledger → QA phase emit `LEDGER_FINDING_VIOLATION_DETECTED` with `decision_id` list.

### §4 — Helper library contract (AC-2)

**Script**: **`scripts/decision_ledger_lib.py`** (+ **`template/scripts/`** mirror — byte-parity per **US-0017**).

| Function / CLI | Purpose |
|----------------|---------|
| **`resolve_ledger_path(orchestrator_run_id, repo_root=None) -> Path`** | Canonical **`handoffs/sovereign_decisions/<id>.jsonl`** |
| **`append_entry(ledger_path, entry) -> (bool, reason_code\|None)`** | Append with fsync; fail-closed on disabled / invalid |
| **`read_entries(ledger_path, last_n=None) -> list[dict]`** | Bounded read (`last_n` tail or full file) |
| **`schema_check(entry) -> (bool, error_message\|None)`** | Validate 12-field schema v1 |
| **`summary_digest(entries) -> dict`** | Bounded QA digest (§6 shape) |
| **`is_ledger_enabled(scratchpad) -> bool`** | `AI_DECISION_LEDGER=1` check; default `False` |
| **`classify_deviation(mode, deviation_kind) -> (decision_type, reason_code, blocking)`** | §3 table |
| **`build_qa_findings_block(ledger_path, orchestrator_run_id) -> dict`** | `ledger_findings` block for `qa-findings.md` |
| **`self_test() -> bool`** | `[DECISION_LEDGER_SELF_TEST_OK]` |

Exit codes: CLI `0` on success, `1` on fail-closed code hit, `2` on usage error.

### §5 — Validator CLI contract (AC-2, AC-8)

**Script**: **`scripts/ledger_validate.py`** (+ template mirror).

| CLI flag | Purpose |
|----------|---------|
| **`--file <path>`** | Validate single JSONL file |
| **`--repo <root>`** | Validate every `handoffs/sovereign_decisions/*.jsonl` |
| **`--self-test`** | Run library contract self-test + exit |
| **`--enforce`** | Non-zero exit on any fail-closed code |

Output on success: **`[LEDGER_VALIDATION_OK]`**.

### §6 — QA cross-check contract (AC-6)

**`/qa`** phase reads the ledger for the current `orchestrator_run_id` and emits a `ledger_findings` block in **`handoffs/qa_to_verify.md`** and/or `sprints/Sxxxx/qa-findings.md`:

```json
{
  "ledger_findings": [
    {
      "decision_id": "<UUID>",
      "decision_type": "...",
      "phase_id": "...",
      "rationale_summary": "<rationale truncated to 200 chars>",
      "risk_tier": "low|medium|high|critical",
      "plan_fidelity_mode": "strict|relaxed|extended",
      "cross_model_reviewed": false
    }
  ],
  "ledger_summary_digest": {
    "total_decisions": 0,
    "by_type": {"PLAN_FIDELITY_VIOLATION": 0, "PLAN_FIDELITY_OVERRIDE": 0, "PLAN_FIDELITY_SCOPE_GATE": 0, "PLAN_FIDELITY_EXTENSION": 0, "PLAN_FIDELITY_REORDER": 0, "LEDGER_DECISION": 0, "LEDGER_DERIVATION": 0, "LEDGER_PHASE_TRANSITION": 0, "LEDGER_DELEGATION": 0},
    "by_risk_tier": {"low": 0, "medium": 0, "high": 0, "critical": 0},
    "violation_count": 0,
    "override_count": 0,
    "scope_gate_count": 0,
    "extension_count": 0
  },
  "ledger_source": "<handoffs/sovereign_decisions/<id>.jsonl>",
  "ledger_orchestrator_run_id": "<run-id>"
}
```

**Fail-closed paths**:

| Condition | Code | Behavior |
|-----------|------|----------|
| `AI_DECISION_LEDGER=1` but ledger file missing | `LEDGER_FILE_MISSING` | **QA hard stop** |
| Ledger file present but parseable lines = 0 | `LEDGER_FILE_EMPTY` | **QA hard stop** |
| Any line fails `schema_check` | `LEDGER_SCHEMA_INVALID` | **QA hard stop** |
| `AI_DECISION_LEDGER=0` | `LEDGER_DISABLED` | no-op; emit info note only |

**Bounded read**: `read_entries(ledger_path, last_n=100)` default for QA; full file only via explicit opt-in. Target max 10K lines per ledger; larger → `LEDGER_READ_BOUND_WARN`.

### §8 — Reason code inventory (AC-8)

**`PLAN_FIDELITY_*`** (5 codes):

| Code | Meaning |
|------|---------|
| **`PLAN_FIDELITY_VIOLATION`** | Unapproved deviation under `strict` (or `relaxed` scope-add) — **hard stop** |
| **`PLAN_FIDELITY_OVERRIDE`** | Operator-approved relaxation recorded in ledger |
| **`PLAN_FIDELITY_SCOPE_GATE`** | New scope request → decision gate |
| **`PLAN_FIDELITY_EXTENSION`** | Extended-mode non-blocking scope extension |
| **`PLAN_FIDELITY_REORDER`** | Relaxed-mode AC drop/reorder recorded |

**`LEDGER_*`** (6 codes):

| Code | Meaning |
|------|---------|
| **`LEDGER_FILE_MISSING`** | `AI_DECISION_LEDGER=1` but no ledger file for run — **fail-closed** |
| **`LEDGER_SCHEMA_INVALID`** | JSONL line fails 12-field schema — **fail-closed** |
| **`LEDGER_APPEND_FAILED`** | Append/fsync failed (permission / IO) |
| **`LEDGER_CORRUPT`** | Whole file fails UTF-8 / JSON parse — **fail-closed** |
| **`LEDGER_READ_BOUND`** | Bounded read truncated (warn + digest) |
| **`LEDGER_DISABLED`** | `AI_DECISION_LEDGER=0` — informational, zero overhead |

**Informational (not fail)**: `LEDGER_FILE_EMPTY` when ledger file exists but empty (emit at QA only, warn).

### §10 — Risks

| Risk | Mitigation |
|------|------------|
| **R1** Ledger contention under concurrent writes | One file per run + append-only + fsync; no concurrent writers per run invariant enforced by orchestrator |
| **R2** Token budget blow-up on ledger reads | `summary_digest` + `last_n=100` bounded reads; 10K lines/run cap |
| **R3** Deviation classification ambiguity | §3 table is architecture-locked; `classify_deviation()` is single source of truth |
| **R4** Ledger corruption | `schema_check` fail-closed per line + recoverable append on next valid line; `LEDGER_CORRUPT` hard stop requires operator remediation |
| **R5** Sovereign-loop composition stability | `test_us0103_us0070_compose_no_schema_change` regression guard; §9 table frozen; US-0104..US-0110 contract depends on v1 schema |
