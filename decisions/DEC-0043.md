# DEC-0043: Cross-Phase Artifact Ownership Guard and Deterministic Archive Verification

- Status: Accepted
- Date: 2026-03-15
- Story: US-0061
- Related: DEC-0040, DEC-0042

## Context

Recent fresh-repo runs reported accidental loss of prior architecture sections
while other artifacts continued to grow. Existing ordering contracts reduce
placement drift but do not fully prevent cross-phase destructive rewrites.
State rollover policy also needs deterministic execution verification, not only
threshold definitions.

## Decision

1. Introduce a canonical phase/artifact ownership matrix:
   `docs/engineering/artifact-ownership-policy.md`.
2. Enforce non-destructive cross-phase mutation guardrails across workflow
   commands:
   - fail closed on non-owned section rewrite/deletion with
     `PHASE_OWNERSHIP_VIOLATION`,
   - require explicit override evidence for any override-authorized mutation;
     missing evidence fails with `PHASE_OVERRIDE_EVIDENCE_MISSING`.
3. Protect architecture history explicitly:
   - `docs/engineering/architecture.md` must preserve unrelated historical
     `US-xxxx` sections.
   - fail on detected non-target deletion with
     `ARCH_HISTORY_DELETION_DETECTED`.
4. Strengthen state archive control with deterministic verification evidence and
   fail-safe mismatch code `STATE_ARCHIVE_VERIFICATION_FAILED`.

## Consequences

- Commands gain stricter non-destructive behavior and clearer ownership
  boundaries.
- Operator diagnostics become deterministic for ownership and archive verification
  failures.
- Active/template policy parity and regression checks are required to avoid drift.
