# DEC-0082: Delivery modes — `DELIVERY_MODE` lifecycle shape, layered memory, and mode-scoped phase resolver (US-0096)

- Date: 2026-06-13
- Status: Accepted
- Story: `US-0096`
- Composes on: **`DEC-0052`** (phase selection — reinstatement **standard-only**), **`DEC-0062`** (run-class hash — extends with **`delivery_mode`** key), **`DEC-0054`** (triad hot surfaces — **`active-context.md`** explicitly **not** triad), **`DEC-0080`** / **`DEC-0081`** (native chain — lean modes reduce per-story spawns; drain-advance unchanged)
- Extends: **`US-0053`** (narrow-read), **`US-0080`** (token metrics), **`US-0072`** (CAVEMAN orthogonality precedent)
- Related: **`US-0001`**, **`US-0092`**, **`US-0095`**, **`R-0082`**
- Supersedes: none

## Context

**US-0080** / **DEC-0062** optimized context **breadth** via **`TOKEN_PROFILE`**; **DEC-0052** non-skippable reinstatement blocks naive phase skips. Operators need an opt-in **lifecycle-shape** axis that reduces spawns and hot-surface reads while preserving code quality and institutional memory.

**US-0096** introduces **`DELIVERY_MODE=standard|ultra_lean|mega_quick`** (default **`standard`**) controlling phase materialization and artifact surfaces. **`standard`** remains byte-compatible with today's full lifecycle. **Tranche A** universal token wins ship always-on without mode toggle.

Research basis: **`R-0082`** Q1–Q7.

## Decision

### 1. Three-mode axis and orthogonality (AC-1)

**Scratchpad keys** (active + `template/.cursor/scratchpad.local.example.md` comment block):

| Key | Values | Default |
|-----|--------|---------|
| **`DELIVERY_MODE`** | **`standard`** \| **`ultra_lean`** \| **`mega_quick`** | **`standard`** (unset counts as **`standard`**) |
| **`LEAN_MEMORY_READ`** | **`0`** \| **`1`** | **`1`** when pack/active-context paths exist |
| **`LEAN_MEMORY_WRITE`** | **`0`** \| **`1`** | **`1`** when pack/active-context paths exist |
| **`LEAN_COLD_READ_MAX_SECTIONS`** | int ≥ 1 | **4** |
| **`LEAN_STATE_INDEX_ROWS`** | int ≥ 30 | **80** |
| **`AUTO_DELIVERY_ROUTING`** | **`scratchpad_only`** \| **`backlog_then_scratchpad`** | **`scratchpad_only`** |

**Non-substitution paragraph** (verbatim in active + `template/` `docs/engineering/auto-orchestration-reference.md` and `docs/engineering/runbook.md`):

> **`DELIVERY_MODE`** controls lifecycle shape and artifact surfaces only. **`TOKEN_PROFILE`** controls context breadth / token cost only (**DEC-0062**). **`CAVEMAN_MODE`** controls reply voice only (**DEC-0072**). None substitutes for another.

**Rejected alternatives**: single combined "lean profile" key (**rejected** — conflates independent axes per **DEC-0062** / **DEC-0072** precedent); mandatory lean mode for all runs (**rejected** — **`standard`** byte-compatibility is AC-2).

### 2. Mode-scoped phase resolver — step 0 (AC-7, AC-2)

**Integration point**: **`/auto`** plan materialization — **before** existing **DEC-0052** pipeline.

**Resolution precedence**: argv **`delivery-mode=`** → backlog row **`delivery_mode`** (when **`AUTO_DELIVERY_ROUTING=backlog_then_scratchpad`**) → scratchpad **`DELIVERY_MODE`** → **`standard`**.

| Mode | `resolved_phase_plan` | Reinstatement | `memory_layer` |
|------|----------------------|---------------|----------------|
| **`standard`** | Full **DEC-0052** chain | **`dec0052_default`** | **`standard`** |
| **`ultra_lean`** | **`[spec, plan, build+verify, ship]`** | **`none`** | **`pack`** |
| **`mega_quick`** | **`[quick]`** (+ conditional +1 on test failure) | **`none`** | **`quick`** |

**Conflict rule**: non-**`standard`** **`delivery_mode`** + non-default **`AUTO_PHASE_*`** → **`PHASE_POLICY_CONFLICT`** (fail closed).

**Mid-story mode switch**: **`DELIVERY_MODE_SWITCH_MID_STORY`** — fail closed; complete segment in one mode.

**Breadcrumbs** (each phase boundary in **`state.md`** + top **`resume_brief`** pointer): **`delivery_mode`**, **`resolved_phase_plan`**, **`reinstatement_mode`**, **`memory_layer`**.

**Native chain composition**: **DEC-0080** / **DEC-0081** drain-advance and spawn-only semantics **unchanged** — lean modes alter **per-segment phase count**, not continuation policy.

### 3. Tranche A universal wins (AC-3)

Ship **always-on** without **`DELIVERY_MODE`** toggle. Explicit operator values override Tranche A defaults (manual-override precedence per scratchpad comment block).

**Default threshold deltas**:

| Key | Pre-US-0096 | Tranche A default |
|-----|-------------|-------------------|
| **`STATE_HOT_MAX_LINES`** | 1200 | **1000** |
| **`PO_TO_TL_HOT_MAX_LINES`** | 800 | **650** |
| **`ARCH_HOT_MAX_LINES`** | 3500 | **3000** |

**Always-on behaviors** (no new scratchpad gate):

1. Narrow-read in **all** phase command **`Inputs`** — section-scoped vision/architecture/decisions when heading exists (**extends US-0053**).
2. Delta-style handoff appends — no full rewrites of prior handoff bodies.
3. Touch-graph read policy documented in runbook — **`codebase-map.md`** component slice + touched paths before execute.

**Token target (Tranche A alone)**: **≥10%** **`cache_read_tokens`** reduction on **`run_class_hash`-matched **`standard`** runs vs pre-US-0096 baseline.

### 4. `ultra_lean` macro-lifecycle (AC-4)

Four macro-phases; **no** eleven-phase reinstatement.

| Macro | Merged canonical phases | Default role |
|-------|------------------------|--------------|
| **`spec`** | `intake` + `discovery` | **po** |
| **`plan`** | `research` + `architecture` + `sprint-plan` | **tech-lead** |
| **`build+verify`** | `execute` + `qa` + `verify-work` | **dev** / **qa** |
| **`ship`** | `release` + `closure` + `refresh-context` | **release** / **qe** / **curator** |

**`AUTO_IMPLEMENTATION_LOOP`** preserved inside **`build+verify`**. QA merges AC checklist + UAT in one spawn.

### 5. Layered memory (AC-5)

| Tier | Surface | Owner | Budget |
|------|---------|-------|--------|
| **Hot** | **`handoffs/active-context.md`** | Lean spawn writers; rollover on **`refresh-context`** or oversize | **30–80** lines; cap **`LEAN_STATE_INDEX_ROWS`** (default **80**) |
| **Warm** | **`work/<story_id>/pack.json`** | All **`ultra_lean`** spawns | Soft cap **16 KiB** |
| **Cold** | Vision / architecture / decisions sections | Section-scoped narrow-read per spawn | Cap **`LEAN_COLD_READ_MAX_SECTIONS`** (default **4**) |

**`active-context.md` is NOT a triad member** (**DEC-0054** unchanged). **`enforce-triad-hot-surface.py`** does **not** scan **`active-context.md`**.

**`pack.json` schema v1** — path **`work/<story_id>/pack.json`**; validator **`scripts/pack_json_validate.py`**; reason codes **`PACK_*`**. Required fields: **`schema_version`** (`"1"`), **`story_id`**, **`delivery_mode`**, **`status`**, **`ac[]`**, **`tasks[]`**, **`refs[]`**, **`deltas[]`**, **`memory_layer`** (`"pack"`).

**Coexistence**: **`standard`** → **`sprints/Sxxxx/`** authoritative; **`ultra_lean`** → **`work/`** authoritative; **`mega_quick`** → **`sprints/quick/Qxxxx/`** — no destructive overlap.

**Memory gates**: **`LEAN_MEMORY_READ=0`** or **`LEAN_MEMORY_WRITE=0`** on **`ultra_lean`** spawn → **`LEAN_MEMORY_DISABLED`** (fail closed).

**Rollover**: oversize or segment close → archive **`handoffs/archive/active-context-<story_id>-<utc>.md`**; hot file rewritten with stub.

### 6. `mega_quick` mode (AC-6)

When eligible, **`/auto`** materializes **`["quick"]`** only.

**Eligibility** (all must pass — fail-closed):

| Code | Rule |
|------|------|
| **`MEGA_QUICK_BUG_SEGMENT`** | Story-only (no bug segment) |
| **`MEGA_QUICK_AC_TOO_BROAD`** | **`ac` ≤ 3** |
| **`MEGA_QUICK_ARCHITECTURE_REQUIRED`** | No companion **`DEC-xxxx`** required |
| **`MEGA_QUICK_SPRINT_EXISTS`** | No active **`sprints/Sxxxx/`** for story |
| **`MEGA_QUICK_STORY_OVERRIDE`** | Row **`delivery_mode`** consistent when routing enabled |
| **`MEGA_QUICK_MULTI_COMPONENT`** | Single component or **`COMPONENT_SCOPE_MODE=0`** |
| **`MEGA_QUICK_GATE_ESCALATION`** | No elevated gates beyond default **`/quick`** |

**Artifacts**: **`sprints/quick/Qxxxx/task.json`** + **`summary.md`** + one **`state.md`** index row. Status flip requires **`acceptance_met: true`** + green tests. Second spawn only on test failure.

### 7. Optional backlog routing (AC-8)

When **`AUTO_DELIVERY_ROUTING=backlog_then_scratchpad`**, story row may declare optional **`delivery_mode:`** field (**`standard`** \| **`ultra_lean`** \| **`mega_quick`**).

### 8. Quality floor (AC-9)

All lean modes:

- Tests run before stop.
- AC traceability in **`pack.json`** or **`task.json`**.
- New patterns → architecture/decision delta written.
- **`active-context.md`** updated on material learnings.

### 9. Run-class extension (AC-12)

Amend **DEC-0062** §2 — add required **`delivery_mode`** key to run-class object (sorted JSON serialization).

**Comparability**:

| Comparison | Valid |
|------------|-------|
| **`standard`** vs **`standard`**, matched keys | yes — AC-2 / AC-3 |
| **`ultra_lean`** vs **`standard`**, same story | **no** — **`TOKEN_COST_RUN_CLASS_MISMATCH`** |
| **`ultra_lean`** vs **`ultra_lean`**, same story | yes — AC-12 |
| **`mega_quick`** vs **`mega_quick`**, eligible class | yes — target **≥70%** vs matched **`standard`** baseline |

**Evidence rows** (**`handoffs/token_cost_runs/<orchestrator_run_id>.md`**): MUST include **`delivery_mode`** column.

## Risks

| Risk | Mitigation |
|------|------------|
| **R1** Partial **`ultra_lean`** without memory index | Tranche B blocked until validator + **`active-context`** template ship |
| **R2** **`active-context`** vs triad confusion | Non-triad lock + **`test_us0096_active_context_contract`** |
| **R3** **`standard`** regression | **`test_us0096_standard_mode_baseline_markers_preserved`** |
| **R4** **`mega_quick`** false routing | Seven fail-closed eligibility codes |
| **R5** **`build+verify`** merged spawn complexity | Runbook operator E2E recipe |
| **R6** **`pack.json`** / **`sprints/`** drift | Coexistence table + no mid-story switch |

## Implementation tranche order

1. **Tranche A** — universal wins (always-on)
2. **Tranche B** — **`ultra_lean`** + layered memory
3. **Tranche C** — **`mega_quick`**
4. **Tranche D** — optional backlog **`delivery_mode`** routing
