# DEC-0108: Parallel Instance Arbitrage for dev phase (US-0108)

- **Date**: 2026-06-28
- **Status**: Accepted
- **Story**: `US-0108`
- **Composes on**: **US-0047** (bulk execute), **US-0092** (full autonomy), **US-0103** (ledger), **US-0104** (critic), **US-0107** (sovereign loop) — **do not amend**; US-0108 adds parallel-dev orchestration only
- **Related**: `R-0096` (research anchor), **US-0069** (phase→role matrix), **US-0045** (status authority), **US-0017** (template parity)
- **Supersedes**: none
- **Default-off**: `SOVEREIGN_PARALLEL_DEV=0` — zero overhead when off

## Context

Execute-phase parallel dev subagents racing in isolated git worktrees on the same task. QA cross-reviewer evaluates all N outputs; single winner selected deterministically. Merge via configurable policy. Resource guard caps system-wide parallelism. Compose with US-0047/US-0092/US-0103/US-0104/US-0107 is **read-only** — US-0108 never writes to upstream schemas.

Research basis: `R-0096` Q1–Q10 closed.

## Decision

### §1 — Scratchpad keys (AC-1)

| Key | Values | Default | Notes |
|-----|--------|---------|-------|
| **`SOVEREIGN_PARALLEL_DEV`** | **`0`** \| **`1`** | **`0`** | When `0`, zero overhead — single dev per US-0047. |
| **`AUTO_SOVEREIGN_PARALLEL_N`** | int ≥ **1** | **`3`** | Number of parallel dev instances spawned. |
| **`AUTO_SOVEREIGN_WORKTREE_MAX`** | int ≥ **N** | **`6`** | Max worktrees per story. |
| **`AUTO_SOVEREIGN_PARALLEL_MAX_TOTAL`** | int ≥ **1** | **`6`** | System-wide cap on concurrent parallel dev processes. |
| **`AUTO_SOVEREIGN_MERGE_RESOLVE`** | **`first_pass_wins`** \| **`last_pass_wins`** \| **`manual`** | **`first_pass_wins`** | Merge resolution policy after QA selection. |
| **`AUTO_SOVEREIGN_WORKTREE_KEEP`** | **`0`** \| **`1`** | **`0`** | When `0`, loser worktrees deleted post-merge. |
| **`AUTO_SOVEREIGN_PARALLEL_QA`** | **`0`** \| **`1`** | **`0`** | When `1`, parallel QA invocations v2 (sequential v1 default). |
| **`AUTO_SOVEREIGN_PARALLEL_MODEL_<idx>`** | string | *(empty)* | Optional per-instance model override. |
| **`AUTO_SOVEREIGN_PARALLEL_LENS_<idx>`** | string | *(empty)* | Optional per-instance critic lens hint. |

Published in **`.cursor/scratchpad.md`** (+ **`template/.cursor/scratchpad.md`** byte-parity per **US-0017**). Config key names in committed scratchpad; values in `.cursor/scratchpad.local.md` or env vars only.

**Rejected**: auto-enable parallel when `SOVEREIGN_PARALLEL_DEV` unset — silent behavior change without operator intent.

### §2 — Worktree isolation (AC-2)

**Naming**: **`.git/worktrees/us0108-<story_id>-<instance_idx>/`** deterministic (e.g. `.git/worktrees/us0108-US0108-0/`, `.git/worktrees/us0108-US0108-1/`, ...).

**Isolation**: Each worktree gets its own `GIT_DIR` + `GIT_WORK_TREE` env vars; per-worktree index + HEAD; no shared lock conflicts.

**Gitignore**: Template `.gitignore` excludes `.git/worktrees/us0108-*` (prevents accidental commit of worktree metadata).

**Cleanup**: Post-selection merge, winner worktree promoted to main; loser worktrees deleted when `AUTO_SOVEREIGN_WORKTREE_KEEP=0` (default); preserved when `1`. Fail-open on cleanup error: log `PARALLEL_DEV_WORKTREE_CLEANUP_FAILED`, continue.

**Rejected**: shared worktree with concurrent checkouts — violates git lock semantics.

### §3 — Model/lens diversity (AC-3)

**Instance 0**: Baseline — same model/lens as non-parallel dev.

**Instance 1..N-1**: Optional overrides via `AUTO_SOVEREIGN_PARALLEL_MODEL_<idx>` and `AUTO_SOVEREIGN_PARALLEL_LENS_<idx>` (idx = 0..N-1). When unset, inherit `MODEL_<PHASE>` per US-0101/DEC-0086.

**Lens hint**: Optional critic lens override for US-0104 cross-model review; when absent, use phase default.

**Rejected**: mandatory diversity — operator opt-in only.

### §4 — Selection predicate (AC-4)

**Algorithm**:
1. Filter N QA evaluations to `qa_verdict=PASS`.
2. If zero PASS → emit `PARALLEL_DEV_QA_NO_PASS`; story continues without pick (no merge).
3. Among PASS instances, pick highest `anti_slop_score` (from US-0104 sprint `qa-findings.md` or `sovereign_critic_findings.jsonl`); when critic absent, default `0`.
4. Tie-break: earliest `proof_issued_at` (from execute runtime proof).
5. Single winner deterministically selected.

**Sequential v1**: QA evaluations invoked sequentially (ordered by instance_idx); deterministic ordering.

**Parallel v2 (optional)**: `AUTO_SOVEREIGN_PARALLEL_QA=1` enables parallel QA invocations; ordering resolved by `proof_issued_at` tie-break.

**Rejected**: random selection — non-deterministic; violates testability.

### §5 — Merge resolution (AC-5)

**Policy** (post-selection):
- **`first_pass_wins`** (default): Select first PASS in spawn order (instance_idx ascending).
- **`last_pass_wins`**: Select last PASS in spawn order.
- **`manual`**: Emit `PARALLEL_DEV_PICK_MANUAL_REQUIRED` reason code; halt for operator pick.

**Merge artifact**: **`handoffs/parallel_dev_pick.json`** v1 schema (write-once at selection):

| Field | Type | Notes |
|-------|------|-------|
| **`schema_version`** | int | **`1`** |
| **`story_id`** | string | `US-0108` |
| **`winner_instance_id`** | int | 0..N-1 |
| **`worktree_path`** | string | `.git/worktrees/us0108-<story_id>-<instance_idx>` |
| **`qa_verdict`** | string | `PASS` |
| **`anti_slop_score`** | int | 0..10 (default 0 when critic absent) |
| **`proof_issued_at`** | ISO 8601 UTC | Tie-break timestamp |
| **`merge_policy`** | enum | `first_pass_wins` \| `last_pass_wins` \| `manual` |
| **`runner_ts_utc`** | ISO 8601 UTC | Pick emission time |
| **`orchestrator_run_id`** | string | Provenance |
| **`loser_instance_ids`** | int[] | Non-winners (for cleanup/audit) |

**Merge conflict**: Bounded retry ≤2; after retry exhaustion, emit `PARALLEL_DEV_MERGE_CONFLICT` + halt for operator resolution.

**Rejected**: auto-retry unbounded — risks infinite merge loops.

### §6 — Resource guard (AC-6)

**Cap**: `AUTO_SOVEREIGN_PARALLEL_MAX_TOTAL` system-wide cap (default `6`).

**Lockfile**: `.git/us0108_parallel_dev.lock` — atomic check-and-increment at spawn; release on instance exit (success or failure).

**Spawn failure**: When `count_active_parallel_dev() >= AUTO_SOVEREIGN_PARALLEL_MAX_TOTAL`, emit `PARALLEL_DEV_RESOURCE_CAP_EXHAUSTED`; no spawn.

**Concurrency**: Lockfile uses `fcntl.flock` (Unix) or `msvcrt.locking` (Windows) for cross-platform atomic ops.

**Rejected**: in-memory counter — survives process restart; lockfile required.

### §7 — Execute phase integration (AC-7)

**Execute steps** (additive to US-0047 step 22 + US-0107 step 24):
- **Step 25**: Parallel dev spawn — when `SOVEREIGN_PARALLEL_DEV=1`, spawn N dev subagents instead of 1; each runs full execute lifecycle in its worktree.
- **Step 26**: QA cross-review — N QA evaluations (sequential v1, parallel v2 opt-in).
- **Step 27**: Selection — winner pick per §4.
- **Step 28**: Merge + cleanup — merge winner worktree to main; delete loser worktrees per `AUTO_SOVEREIGN_WORKTREE_KEEP`; write `handoffs/parallel_dev_pick.json`.

**Compose order**: US-0108 steps 25–28 execute **after** US-0047 step 22 (bulk execute) and US-0107 step 24 (sovereign loop advance). Resource guard check happens **after** bulk execute cap evaluation.

**Rejected**: parallel dev as alternative to US-0047 — compose, do not replace.

### §8 — Backward compat (AC-8)

**`SOVEREIGN_PARALLEL_DEV=0` (default)**:
- Single dev per US-0047 (unchanged).
- No worktrees created.
- No parallel QA invocations.
- No `parallel_dev_pick.json` written.
- No resource guard checks.
- US-0047 / US-0092 semantics unchanged.

**Regression guard**: `test_us0108_backward_compat_single_dev_unchanged` — verifies zero behavior change when flag off.

**Rejected**: default-on — silent behavior change.

### §11 — Risks

| Risk | Mitigation |
|------|------------|
| **R1** Worktree lock conflicts | Deterministic naming + per-worktree GIT_DIR + GIT_WORK_TREE |
| **R2** QA cross-review latency | Sequential v1 default; parallel opt-in v2 |
| **R3** Merge conflicts | Bounded retry ≤2; then `PARALLEL_DEV_MERGE_CONFLICT` halt |
| **R4** Anti-slop unavailable | Graceful degrade default `0` when critic absent |
| **R5** Resource cap race | Atomic lockfile check-and-increment |
| **R6** Bulk execute interaction | System-wide cap preferred; checked after US-0047 step 22 |
