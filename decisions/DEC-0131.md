## Context

Shared Its-Magic lifecycle/governance settings still resolve primarily through Cursor-path scratchpad readers (`.cursor/scratchpad.md` + `.cursor/scratchpad.local.md` per DEC-0055 Model B). OpenCode-only installs (`--host opencode`) must operate without requiring `.cursor/`. OpenCode v2 config (`opencode.json{,c}` under `~/.config/opencode/`, project root, and `.opencode/`) is a host model/providers/permissions/agents surface — **not** a kit governance store (Context7 `/websites/opencode_ai_v2` + https://opencode.ai/v2/docs/config/ confirm).

R-0116 locked DQ1–DQ10. This DEC accepts approach **A1** and closes architecture deferred items + research-critic informational NBs (`us0131rsc-*`).

## Decision

### 1. Approach A1 — `.its-magic/` JSON SOT + LegacyScratchpadAdapter + resolver migration (LOCKED)

| Option | Summary | Verdict |
|--------|---------|---------|
| **A1** | Host-neutral `.its-magic/config{,.local,.example}.json` as shared SOT; Cursor scratchpad = DEC-0055/0039 compatibility adapter into the same `shared` namespace; `host_runtime_config_lib.resolve_runtime_config` injects resolved values into shared-kernel scripts | **Accepted** — meets AC-1..AC-8; OpenCode-only needs no `.cursor/` |
| A2 | Scratchpad-only forever | **Rejected** — fails AC-3 |
| A3 | Store kit governance keys in `opencode.json{,c}` | **Rejected** — DQ4 / host schema collision / US-0132 risk |

### 2. Canonical paths + filename tokens (DQ1 deferred CLOSED)

Ship repo-local kit directory **`.its-magic/`** (not under `.cursor/` or `.opencode/`):

- `.its-magic/config.example.json` — framework catalog (installer-delivered; refreshable)
- `.its-magic/config.json` — team/shared baseline (materialize-from-example when absent; never overwrite if present except explicit overwrite mode)
- `.its-magic/config.local.json` — operator overrides (**gitignored**; never overwritten by install/upgrade/clean)

**Filename token = `config`** (not `runtime`). Reject repo-root `its-magic.json`. Reject requiring `.cursor/scratchpad*` on OpenCode-only. Reject dumping kit keys into `opencode.json`.

### 3. Schema v1 + fail-closed codes (DQ2 deferred CLOSED)

- JSON object with required `schema_version` (int, start at **1**) and `shared` object mapping **scratchpad-compatible KEY names** → string values (1:1 with existing `KEY=VAL` automation keys).
- **`host_overlays.cursor` / `host_overlays.opencode`**: present as empty objects in v1 schema docs/examples; **no required overlay keys in v1** unless a future story proves need (YAGNI).
- **Required-key allowlist**: **not** a global schema-required set. Call sites pass an optional `required_keys: Iterable[str]` into `resolve_runtime_config`; empty/missing after full resolve → `HOST_CONFIG_MISSING_REQUIRED`. Optional absent files → defaults (not the same as invalid present file).
- Forbidden in all layers: credentials, provider API keys, real vendor model slugs in examples/templates → `HOST_CONFIG_SECRET_REJECTED`.
- Fail-closed family (document additively in US-0126 consolidated table via compose):
  - `HOST_CONFIG_SCHEMA_UNSUPPORTED`
  - `HOST_CONFIG_INVALID`
  - `HOST_CONFIG_MISSING_REQUIRED`
  - `HOST_CONFIG_PATH_FORBIDDEN` (resolver asked to treat `.cursor/` as sole SOT on OpenCode-only)
  - `HOST_CONFIG_SECRET_REJECTED`
  - `HOST_CONFIG_KEY_SHADOWED` (diagnostic; non-fatal unless `HOST_CONFIG_STRICT=1`)
- **`HOST_CONFIG_STRICT` default = off (`0`)** — shadowed-key diagnostics only unless operator enables strict fail.

### 4. Cursor adapter merge order (NB1 CLOSED)

1. Within Cursor layers only, preserve **DEC-0055 Model B**: `scratchpad.local.md` > `scratchpad.md` > example (when used as Cursor catalog).
2. Map the **merged** Cursor KEY=VAL dict into the shared namespace (LegacyScratchpadAdapter).
3. Apply **both-host / kit interleave** (DQ6) for final shared values:

   1. Explicit one-run CLI/env overrides (test/`ITS_MAGIC_CONFIG_ROOT` only — not a second SOT)
   2. `.its-magic/config.local.json` (`shared.*`)
   3. Cursor local (adapter output — shared keys only)
   4. `.its-magic/config.json` (`shared.*`)
   5. Cursor baseline (adapter)
   6. `.its-magic/config.example.json`
   7. Built-in code defaults

When kit local and Cursor local disagree → **kit local wins**; emit `HOST_CONFIG_KEY_SHADOWED`.

`MODEL_*` / `MODEL_TIER_*` encountered by US-0131 resolver: **ignore** (do not validate; US-0132 owns) — including when migrating `model_tier_validate.py` path defaults (inject resolver for non-model governance paths only; do not reinterpret model keys).

### 5. OpenCode-only + injection API (DQ4/DQ5 LOCKED)

- OpenCode-only resolves shared settings from **`.its-magic/`** (+ code defaults) only. Never require `.cursor/scratchpad*`.
- API: `scripts/host_runtime_config_lib.py:resolve_runtime_config(repo_root, *, host_mode: str | None = None, required_keys: Iterable[str] | None = None) -> ResolvedRuntimeConfig` with `{values, provenance, diagnostics}`.
- Migrate shared-kernel hardcode consumers listed in R-0116 (outer-driver, OpenCode bridge, triad enforce, `dev_environment_lib`, caveman compress, parallel arbiter, uat probe, autonomy stop matrix, and path defaults in model_tier_validate **without** MODEL validation).
- Cursor-only parity scripts may keep reading `.cursor/scratchpad*` when validating Cursor pair surfaces.

### 6. Installer + tests + docs (DQ8–DQ10 LOCKED)

- Deliver `.its-magic/config.example.json` as **kernel** install path (all `--host` modes) via `[install_include_paths]` (default; no mandatory new section split).
- Never overwrite `.its-magic/config.local.json` or `.cursor/scratchpad.local.md`.
- Ten `test_us0131_*` static/fixture markers (R-0116 DQ9); no live OpenCode CI probe.
- Runbook h2 `## Cross-host runtime configuration (US-0131)` + README + auto-orchestration-reference cross-link; US-0126 table gains additive `HOST_CONFIG_*` rows only.

## Consequences

- Execute implements A1 without reopening DQ1–DQ10.
- US-0132 remains a separate story for model contracts.
- Shared scripts become host-mode aware via explicit injection; OpenCode-only installs stop depending on Cursor scratchpad paths for governance keys.

## Alternatives considered (summary)

See options table in §1. Additional rejects: repo-root `its-magic.json`; global schema-required key set in v1; non-empty `host_overlays` in v1; `HOST_CONFIG_STRICT=1` by default; dumping kit keys into OpenCode host JSON.
