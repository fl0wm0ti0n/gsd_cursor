## Context

US-0121 ships the first vertical slice of the OpenCode adapter epic: an empty-but-valid `template/.opencode/` pack plus an additive `--host cursor|opencode|both` switch on the existing its-magic installer. The six-story epic (US-0121..US-0126) needs a single shared host contract that successor stories inherit without re-deriving. R-0109 Q6–Q12 deepened the open questions; this DEC locks the answers as the cross-cutting contract.

Three encodings were candidates for manifest host-gating (R-0109 Q7): (a) host-tagged rows, (b) parallel sections, (c) prefix filter at copy time. Option (b) is the simplest additive encoding that preserves the existing parser contract and the US-0008 compose rule (additive only); (a) would require a parser rewrite (forbidden by D9), and (c) hides `.opencode/` membership from the manifest (breaking AC-5).

Two critic findings (research phase, `handoffs/sovereign_critic_findings.jsonl` rows 7–9) must be closed in architecture: host-shrink `upgrade`/`missing` silent staleness (`ik_us0121_upgrade_host_transition`), and mixed-section `.cursor/` skip divergence across the triple-installer (`ik_us0121_mixed_manifest_cursor_skip`). A third critic finding (`ik_us0121_gitignore_premature_patterns`) asked to drop Q10's extra gitignore patterns; per the orchestrator brief we decline dropping Q10 and do not add further speculative globs.

Research basis: **`R-0109`** Q6–Q12 (LOCKED for US-0121 execute), Q1–Q5 (LOCKED for `/architecture` only, deferred to US-0122..US-0126).

## Decision

### 1. Host-surface switch `--host cursor|opencode|both` (AC-2, D1, D2)

**Enumeration**: `--host ∈ {cursor, opencode, both}` accepted by `bin/its-magic.js` argv parser, forwarded to PowerShell `-Host`, Bash `--host`, Python `--host`.

**Default**: `cursor` when `--host` omitted. Default remains cursor-only until explicit opt-in (D2). No scratchpad key, environment variable, or host auto-detect may flip the default in this story.

**Normalize-then-validate**: `value.toLowerCase().trim()` before validate. `OpenCode` / `  opencode  ` / `BOTH` normalize to canonical lowercase. Unknown value → exit with reason code `INSTALL_HOST_INVALID` (ASCII diagnostic, no GUI per D11).

**Duplicate / conflicting `--host` argv**: if `--host` appears more than once → fail closed `INSTALL_HOST_INVALID` (no last-wins; closes critic finding 1).

**`--help` documents `--host`** and the cursor-default lock (AC-9 minimal docs hook; full runbook is US-0126).

**Rejected alternatives**: (a) last-wins for duplicate `--host` — rejected as silent ambiguity across triple-installer; (b) environment variable default override — rejected as violating D2 (cursor-only default until explicit opt-in).

### 2. Parallel manifest sections (Q7 LOCKED — AC-5, D6)

Add to `docs/engineering/context/installer-owned-paths.manifest` (and `template/docs/engineering/context/installer-owned-paths.manifest` byte-identical):

```
[opencode_install_include_paths]
.opencode/agents
.opencode/commands
.opencode/plugins
.opencode/.gitignore
.opencode/README.md

[opencode_clean_paths]
.opencode
```

- Existing `[install_include_paths]` / `[clean_paths]` / `[required_install_script_paths]` **unchanged** (US-0008 additive only).
- Triple-installer reads `[opencode_install_include_paths]` only when `--host` includes opencode (`opencode` or `both`); reads `[opencode_clean_paths]` only when `--host` includes opencode.
- `[install_include_paths]` remains the cursor-default + kernel section.

**Rejected alternatives**: (a) host-tagged rows (`.opencode/  @host=opencode,both`) — rejected as a US-0008 parser rewrite (forbidden by D9); (b) prefix filter at copy time only — rejected as hiding `.opencode/` membership from the manifest (breaks AC-5).

### 3. Kernel-vs-host copy filter (Q8 LOCKED — AC-3, AC-4)

`--host` gates **only** `.cursor/` and `.opencode/` surfaces. Kernel paths install regardless of `--host`:
- `docs/`, `scripts/` (manifest-listed), `its_magic/`, `handoffs/`, `decisions/`, `sprints/`, `.github/workflows/`.

Rule: "`--host` is a host-surface switch, not a kernel switch." This is the simplest contract satisfying AC-3 (opencode adds `.opencode/`) and AC-4 (cursor-only byte-identical). No exception needed.

### 4. Mixed-section `.cursor/` skip predicate (critic finding 2 — interface contract)

The existing `[install_include_paths]` mixes kernel rows with `.cursor/**` rows. The triple-installer shares a single predicate:

```python
def host_gates_cursor_row(rel, host):
    # host in {cursor, opencode, both} (normalized lowercase+trim)
    if host == "opencode":
        return rel.startswith(".cursor/")
    return False
```

- `--host opencode`: `.cursor/` rows in `[install_include_paths]` are **skipped**; kernel rows in the same section are **still installed**; `[opencode_install_include_paths]` rows are installed.
- `--host cursor` (default): `.cursor/` rows installed; `[opencode_install_include_paths]` rows skipped.
- `--host both`: both sets installed; no skip.

This predicate is the **interface contract** shared by `installer.ps1`, `installer.sh`, and `installer.py`. Contract test `test_us0121_mixed_section_cursor_skip_when_host_opencode` enforces parity.

### 5. Host-scoped missing / upgrade / clean (Q12 LOCKED — AC-3, D5)

| Mode | `--host cursor` (default) | `--host opencode` | `--host both` |
|------|---------------------------|-------------------|---------------|
| `missing` | Copy `.cursor/` + kernel rows; skip `.opencode/`. | Skip `.cursor/`; copy kernel + `.opencode/`. | Copy all. |
| `upgrade` | Refresh `.cursor/` + kernel; leave `.opencode/` untouched. If `.opencode/` exists from prior `--host both`, emit `OPENCODE_STALE_BY_UPGRADE_CURSOR`. | Refresh kernel + `.opencode/`; leave `.cursor/` untouched. If `.cursor/` exists from prior `--host both`, emit `CURSOR_STALE_BY_UPGRADE_OPENCODE`. | Refresh all. |
| `clean` | Remove `[clean_paths]` (cursor-default + kernel); do **not** remove `.opencode/`. If `.opencode/` exists from prior `--host both`, emit `OPENCODE_ORPHANED_BY_CLEAN_CURSOR`. | Remove `[opencode_clean_paths]` (`.opencode/`); do **not** remove `.cursor/` or kernel. If `.cursor/` exists from prior `--host both`, emit `CURSOR_ORPHANED_BY_CLEAN_OPENCODE`. | Remove both `[clean_paths]` and `[opencode_clean_paths]`. |

- **Host-shrink does not silently delete** (closes critic finding 1): shrinking `--host both` → `cursor` leaves the other-host tree in place and emits a named diagnostic. The operator must run `clean --host opencode|both` to remove the orphan. Symmetric for `--host opencode` shrinking from `both`.
- **No silent deletion**: the only way to delete `.opencode/` is `clean --host opencode|both`. The only way to delete `.cursor/` (cursor-owned installer paths) is `clean --host cursor|both`.

### 6. Template pack layout (Q6 LOCKED — AC-1, D3)

```
template/.opencode/
  agents/.gitkeep
  commands/.gitkeep
  plugins/README.md
  .gitignore
  README.md
```

- One placeholder file per directory. `plugins/README.md` explains the plugin slot is reserved for US-0124.
- **No repo-root `opencode.json`** this slice (R-0109 Q6 — would prematurely lock US-0122 permission matrix + US-0123 provider config).
- **No active `.opencode/` mirror in this kit repo** (R-0109 Q9 — YAGNI for this slice).

### 7. `.gitignore` patterns (Q10 LOCKED — AC-10, D8)

`template/.opencode/.gitignore` ships four pattern groups:

```
.opencode/opencode.json
.opencode/opencode.jsonc
.env
.env.*
*.local.json
*.local.jsonc
auth.json
```

- (1) `.opencode/opencode.json{,c}` — project-local config overrides; template ships no `opencode.json`, but a consumer repo may add one with provider/apiKey and must not commit it.
- (2) `.env` / `.env.*` — provider keys per OpenCode docs.
- (3) `*.local.json{,c}` under `.opencode/` — mirrors kit `.cursor/` volatile-ID convention per US-0102.
- (4) `auth.json` — defense-in-depth; lives outside the repo per OpenCode docs but harmless to list.

**Critic finding 3 (`ik_us0121_gitignore_premature_patterns`)** asked to drop extras (3) and (4). Per the orchestrator brief we **decline dropping Q10** and **do not add** further speculative globs this slice. The four groups above are the locked set.

### 8. Cursor coexistence byte-identity (AC-4, D4)

`--host cursor` (default) must be byte-identical on `.cursor/` and Cursor-owned installer paths versus pre-US-0121 cursor-only install. Contract tests enforce:
- `test_us0121_cursor_only_byte_identical_pre_us0121`
- `test_us0121_cursor_only_no_opencode_files`
- `test_us0121_both_leaves_both_trees`

### 9. Contract tests + parity (AC-7, AC-6)

`tests/us0121_host_mode_test.py` — 14 markers (see `# US-0121` architecture section for the full table). `check_intake_template_parity.py --scope=opencode-adapter` enforces active/template file parity for all US-0121 surface pairs.

- Repo-root `opencode.json` — not shipped.

## Consequences

- **Positive**: Operators can install `.opencode/` into any consumer repo via the existing installer with `--host opencode|both`; cursor-only install remains byte-identical; epic US-0122..US-0126 inherits the host contract via this DEC without re-deriving.
- **Negative**: New template tree; additive manifest sections; additive `--host` argv in 4 installer surfaces; new contract test file (14 markers); new parity scope.
- **Neutral**: US-0008 compose (additive only); DEC-0045 `its_magic/` ownership unchanged; US-0102 volatile-ID rule respected. Implementation lives in `/execute` (build+verify macro); this decision fixes the architecture contract only. `/sprint-plan` may merge or split the 9 task seeds within the 12-task budget.
