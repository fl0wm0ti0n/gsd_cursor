# DEC-0074 — README feature coverage predicate, validator, release gate composition, and grandfathering (US-0091)

## Status

Accepted — 2026-06-06

## Context

**Composes on `DEC-0059`** (US-0077 — dual-README audience profiles, `USER_*` / `DEV_*`
H2 vocabulary, section budgets via `validate_doc_profile.py`) and **extends the release
doc-gate family** alongside **US-0030** (delta-driven command/flag documentation gate).
`DEC-0030` (optional user-guide mode) is **not rewritten**; US-0030 story semantics
(delta-driven README/runbook updates when commands/flags change) remain process-level
and unchanged.

Research anchor **`R-0074`** (intake + discovery + research extensions on
`orchestrator_run_id=auto-20260606-01`) resolved predicate Option A, validator API,
release step **3f**, section-affinity manifest, grandfathering toggle, and template
parity inventory. Repo survey: ~90 story blocks, zero `user_visible:` markers at research
time — migration heuristic H1–H8 required for one-time backfill pass.

US-0091 closes the **static-coverage gap**: `US-0030` blocks **deltas**; US-0091 blocks
**missing initial blurbs** for DONE user-visible work items. Audit, backfill, and blocking
validator ship in one story (operator explicit `story_split=single`).

## Decision

Adopt the architecture below. Acceptance-criteria traceability is published in
§AC-Traceability at the end.

### 1. User-visible predicate — backlog field canonical (Option A)

**Canonical input**: backlog block field **`user_visible: true|false`** on each
`## US-xxxx` and `### BUG-xxxx` block. Validator reads **`docs/product/backlog.md`
only**. Optional acceptance row `(user_visible)` suffix is **human-scan only** — not
machine input.

**Predicate algorithm** (normative):

```
for each work_item in parse_backlog(backlog.md):
  if work_item.kind not in {US, BUG}: skip
  if work_item.status != DONE: skip
  if work_item.user_visible == false: skip (out-of-scope)
  if work_item.user_visible == true: in_scope
  elif work_item.user_visible unset:
    if README_FEATURE_COVERAGE_ENFORCE == 1:
      emit README_FEATURE_COVERAGE_INPUT_INVALID  # heuristic disabled when enforce=1
    else:
      classify = migration_heuristic(work_item)  # one-time backfill pass only
      if classify == ambiguous: emit README_FEATURE_COVERAGE_INPUT_INVALID
      elif classify == in_scope: in_scope
      else: skip
  else: README_FEATURE_COVERAGE_INPUT_INVALID  # malformed value
```

**Alternatives rejected**:

- **Option B** — parse `acceptance.md` `(user_visible)` suffix: violates discovery lock.
- **Option C** — heuristic-only: unbounded false positives; blocks `/release` unpredictably.
- **Option D** — extend US-0030 delta-only gate: does not solve static-coverage gap (AC-2).

### 2. Migration heuristic table H1–H8 (unset `user_visible` only)

Applied **only** when `README_FEATURE_COVERAGE_ENFORCE=0` (grandfathering / backfill
pass). When `README_FEATURE_COVERAGE_ENFORCE=1`, unset fields **fail closed** with
`README_FEATURE_COVERAGE_INPUT_INVALID` — explicit markers required on all DONE items.

| Signal ID | Pattern | Scope | Notes |
|-----------|---------|-------|-------|
| **H1** | `/(?:^|\s)(/[a-z][a-z0-9-]*)/` in summary/title/acceptance bullets | **in** | Slash-commands (`/intake`, `/auto`, `/release`, …) |
| **H2** | Scratchpad key `^[A-Z][A-Z0-9_]+=` or backtick-wrapped key name in summary | **in** | Operator-configurable flags |
| **H3** | `python scripts/[a-z0-9_./-]+\.py` in summary with operator-facing verb | **in** | CLI validators operators run |
| **H4** | BUG `expected`/`actual` fields describe operator-visible behavior change | **in** | Default **in** unless `user_visible: false` |
| **H5** | Keywords `archiver`, `hot-surface rollover`, `intake evidence schema`, `template parity guard`, `triad` without H1–H4 | **out** | Pure-internal invariant surfaces |
| **H6** | Summary contains both H5 **and** H1–H4 | **in** | Operator action wins |
| **H7** | No H1–H6 match on DONE **story** | **ambiguous** → `README_FEATURE_COVERAGE_INPUT_INVALID` | Forces explicit marker during backfill |
| **H8** | No H1–H6 match on DONE **bug** | **out** | Bugs default out unless H4 or explicit `user_visible: true` |

**Post-backfill policy**: execute sprint authors explicit `user_visible:` on every DONE
story/bug touched; new DONE items MUST carry explicit marker before `/release` when
`README_FEATURE_COVERAGE_ENFORCE=1`.

### 3. Coverage detection and three-file target

**In-scope items** MUST have detectable coverage in the README family:

| Surface | Requirement |
|---------|-------------|
| Root **`README.md`** | Bullet or sub-entry under expected `root_h2` containing (a) slash-command token, (b) scratchpad key name, or (c) `\bUS-\d{4}\b` / `\bBUG-\d{4}\b` — root blurbs **SHOULD** prefer (a)/(b) per **US-0071** |
| **`docs/developer/README.md`** | Table row or bullet under expected `dev_h2` containing id + at least one scratchpad key or `related_us` pointer |
| **`template/README.md`** | Byte-identical to root per **US-0017** — not separately indexed |

**No new H2 literals** — backfill adds bullets/sub-entries within existing H2s per
**DEC-0059** / `doc_profile_lib.py`. Post-check: import `doc_profile_lib` for section
budget — violations map to `README_FEATURE_COVERAGE_PROFILE_VIOLATION`.

### 4. Section-affinity manifest

Ship **`docs/engineering/context/readme-section-affinity.json`** (active +
`template/docs/engineering/context/readme-section-affinity.json` byte-identical per
**US-0017**):

```json
{
  "affinity_version": 1,
  "rules": [
    {"tag": "slash_command", "root_h2": "Commands and workflow", "dev_h2": "Workflow"},
    {"tag": "scratchpad_mode", "root_h2": "Other useful capabilities", "dev_h2": "Quality gates"},
    {"tag": "distribution", "root_h2": "Features", "dev_h2": "Architecture notes"},
    {"tag": "release_gate", "root_h2": "Commands and workflow", "dev_h2": "Quality gates"},
    {"tag": "governance", "root_h2": "Other useful capabilities", "dev_h2": "Engineering decisions"}
  ]
}
```

Classifier picks first matching tag from backlog `Summary` keywords / slash-command
presence; default fallback: `slash_command` when H1 matches else `governance`.
Architecture locks tag→H2 mapping; **no new H2 literals**.

### 5. Validator implementation — lib split (Option A)

**Entrypoint**: `scripts/validate_readme_feature_coverage.py` (stdlib-only; mirrors
`validate_doc_profile.py` CLI posture).

**Library**: `scripts/readme_feature_coverage_lib.py` — predicate, backlog parser,
README index builder, affinity resolver, reason-code emitter (same split as
`bug_issue_lib` / `doc_profile_lib`).

| Flag | Purpose |
|------|---------|
| `--repo PATH` | Target repo root (default: parent of `scripts/`) |
| `--backlog PATH` | Backlog file (default: `docs/product/backlog.md`) |
| `--self-test` | Predicate matrix + report schema stability → `[README_FEATURE_COVERAGE_SELF_TEST_OK]` |
| `--report` | Emit stable JSON to stdout (AC-7 idempotence) |
| `--audit-out PATH` | Write gap artifact (execute/audit mode) |
| `--enforce` | Blocking mode when invoked from `/release`; without: report-only for migration |
| `--no-template-parity` | Skip active vs `template/` script/README parity sub-check |

**Exit codes**: `0` = pass; `1` = `README_FEATURE_COVERAGE_BLOCKED` (sub-codes on stderr);
`2` = invocation/self-test failure.

**Audit artifact** (execute phase): `docs/engineering/context/readme-feature-coverage-audit.json`
(active-only snapshot; not mirrored to `template/` per **DEC-0040**).

**Self-test fixtures**: `tests/fixtures/readme_feature_coverage/` (minimal trees).

**Stable `--report` JSON** (sorted keys; UTF-8; LF; no timestamps in body):

```json
{
  "coverage_missing": ["US-0048"],
  "coverage_present": ["US-0030"],
  "coverage_total": 42,
  "gaps": [
    {
      "dev_h2": "Quality gates",
      "id": "US-0048",
      "kind": "US",
      "predicate_source": "heuristic:H1",
      "root_h2": "Commands and workflow",
      "user_visible": true
    }
  ],
  "report_schema_version": 1,
  "repo_root": ".",
  "status": "FAIL"
}
```

### 6. Reason-code vocabulary (AC-5)

| Code | When |
|------|------|
| `README_FEATURE_COVERAGE_BLOCKED` | Umbrella on stderr first line |
| `README_FEATURE_COVERAGE_GAP:<US-xxxx\|BUG-xxxx>` | In-scope DONE item missing coverage anchor |
| `README_FEATURE_COVERAGE_PARITY_FAIL` | `README.md` ≠ `template/README.md` or script pair mismatch |
| `README_FEATURE_COVERAGE_INPUT_INVALID` | Ambiguous predicate / malformed `user_visible` / unset when enforce=1 |
| `README_FEATURE_COVERAGE_PROFILE_VIOLATION` | Backfill exceeds `validate_doc_profile.py` section budget |

No further sub-codes without a subsequent DEC.

### 7. Release-gate composition with US-0030

**US-0030** (delta-driven): release subagent compares command/flag **changes in sprint
scope** against README/runbook updates — remains **unchanged** and primarily
process/agent-driven.

**US-0091** (static-coverage): **scripted** second check — deterministic inventory of
all DONE user-visible items vs README family.

**Gate order within doc-gate family**:

1. US-0030 doc-delta (agent checklist — unchanged)
2. US-0091 static coverage (script — new step **3f**)
3. Both recorded in `sprints/Sxxxx/release-findings.md` § doc gates

**Release command wiring** — step **3f** in `.cursor/commands/release.md` (after **3e**
legacy drift, before step **4** UAT):

```
3f. README feature coverage gate (US-0091 / DEC-0074):
   - Read merged scratchpad `README_FEATURE_COVERAGE_ENFORCE` (default 0).
   - When 0: skip with `skipped` evidence in release-findings (grandfathering).
   - When 1: run `python scripts/validate_readme_feature_coverage.py --repo . --enforce`.
   - Fail → `README_FEATURE_COVERAGE_BLOCKED` + sub-codes; remediation lists missing id
     and target `root_h2` / `dev_h2`.
   - Active + `template/.cursor/commands/release.md` byte-identical step 3f block.
```

**Rejected alternatives**:

- **Option B** — wire into `validate-and-push` / `sync_push_gates.py`: wrong lifecycle.
- **Option C** — fold into `validate_doc_profile.py`: conflates audience budgets with
  feature inventory.

### 8. Grandfathering / first-activation toggle (AC-10)

Scratchpad key **`README_FEATURE_COVERAGE_ENFORCE=0|1`** (default **`0`**).

| Value | Behavior |
|-------|----------|
| **`0`** | Validator invoked from `/release` prints `skipped` and exits **0**; migration heuristic H1–H8 active for unset `user_visible`; no retroactive `/release` block |
| **`1`** | Validator `--enforce` is blocking; heuristic disabled; explicit `user_visible:` required on all DONE items |

**Activation procedure** (same sprint/commit as backfill merge):

1. Complete audit + three-file backfill (AC-2..AC-4).
2. Author explicit `user_visible:` markers for all DONE in-scope items.
3. Flip `README_FEATURE_COVERAGE_ENFORCE` **0→1** in active + `template/` scratchpad
   example/local example with runbook note.
4. Verify `--report` shows `coverage_missing: []` before merge.

### 9. Template parity inventory (US-0017 / AC-9)

Extend `scripts/check_intake_template_parity.py` with **`--scope=readme-feature-coverage`**:

| Active | Template |
|--------|----------|

| `docs/engineering/context/readme-section-affinity.json` | `template/docs/engineering/context/readme-section-affinity.json` |
| `.cursor/commands/release.md` (step 3f hunk; full-file parity per US-0017) | `template/.cursor/commands/release.md` |
| `docs/engineering/runbook.md` (feature-coverage subsection) | `template/docs/engineering/runbook.md` |
| `docs/engineering/context/installer-owned-paths.manifest` (new script paths) | `template/docs/engineering/context/installer-owned-paths.manifest` |

Compose with existing **US-0017** README byte-parity guard — do **not** duplicate
root↔template README diff logic inside the new validator.

**Run-tests harness**: new section **`§27U`** in `tests/run-tests.ps1` +
`tests/run-tests.sh` — self-test + report idempotence fixture.

**Active-only** (no `template/` mirror):

- `docs/engineering/architecture.md` `# US-0091`
- `tests/fixtures/readme_feature_coverage/`
- `docs/engineering/context/readme-feature-coverage-audit.json` (generated evidence)

### 10. Non-goals (hard)

- No rewrite of **US-0030** delta semantics or **DEC-0059** audience profiles.
- No new H2 literals in README family.
- No mandatory per-feature user guides (`USER_GUIDE_MODE` unchanged).
- No npm / pip runtime dependency (stdlib Python only).
- No acceptance.md row format change beyond optional human-scan suffix.
- No retroactive `/release` block before backfill completes (`README_FEATURE_COVERAGE_ENFORCE=0` until flip).

## Risks

| ID | Risk | Mitigation |
|----|------|------------|
| R1 | False positives block `/release` | Explicit `user_visible:` + H7 fail-closed → resolution at backfill |
| R2 | README bloat (~90 items) | 1–2 sentence blurbs; profile budget → `README_FEATURE_COVERAGE_PROFILE_VIOLATION` |
| R3 | Three-file parity drift | US-0017 README guard + scoped parity script |
| R4 | Retroactive lock-in | `README_FEATURE_COVERAGE_ENFORCE=0` until backfill merges |
| R5 | US-0071 leakage in root blurbs | Prefer command/flag tokens in root; run `check-user-visible-metadata.py` |
| R6 | Heuristic ambiguity at scale | H7 forces explicit marker; enforce=1 disables heuristic |
| R7 | US-0030 / US-0091 operator confusion | Runbook subsection: delta vs static inventory |

## Alternatives considered

- **Monolithic validator script** (no lib split) — rejected; breaks established
  `*_lib.py` precedent and complicates self-test fixtures.
- **Baseline manifest at activation** — rejected; duplicates backlog predicate; drifts if stale.
- **Time-boxed env var for enforce** — rejected; not scratchpad-visible.
