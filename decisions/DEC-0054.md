# DEC-0054: Triad hot-surface compaction, archive gates, and bounded phase reads

- Date: 2026-03-22
- Status: Accepted
- Story: `US-0072`
- Research refs: `R-0047`
- Related: `DEC-0042` (state hot rollover), `DEC-0043` (ownership + architecture
  history), `DEC-0040` (artifact ordering), `DEC-0035` (tiered retrieval /
  compact indexes), `DEC-0029` / `DEC-0038` (isolation + strict-proof evidence)

## Context

`docs/engineering/state.md`, `handoffs/po_to_tl.md`, and
`docs/engineering/architecture.md` are primary **hot context** surfaces. Without
deterministic thresholds, same-boundary rollover, and verification evidence,
they grow without bound and overload subagent reads despite prior policy
(`US-0053`, `US-0060`, `US-0061`).

## Decision

### 1. Canonical enforcement triad

Treat these three paths as the **default** hot/archive contract scope for
context slimming:

1. `docs/engineering/state.md`
2. `handoffs/po_to_tl.md`
3. `docs/engineering/architecture.md`

Any additional `handoffs/*` compaction requires an explicit follow-on decision
or story scope (not implied by `US-0072`).

### 2. Scratchpad-bound thresholds (merged active + local)

All numeric caps resolve from **merged** scratchpad (`.cursor/scratchpad.md` +
`.cursor/scratchpad.local.md`) with documented defaults:

| Surface | Line cap key | Section/checkpoint cap key | Default lines | Default sections |
|---------|----------------|---------------------------|---------------|------------------|
| `state.md` | `STATE_HOT_MAX_LINES` | `STATE_HOT_MAX_CHECKPOINTS` | `1200` | `80` |
| `po_to_tl.md` | `PO_TO_TL_HOT_MAX_LINES` | `PO_TO_TL_HOT_MAX_SECTIONS` | `800` | `60` |
| `architecture.md` | `ARCH_HOT_MAX_LINES` | `ARCH_HOT_MAX_STORY_SECTIONS` | `3500` | `120` |

**Semantics**:

- **`state.md`**: a **checkpoint** is a top-level `## ... checkpoint ...` (or
  equivalent documented heading class) under the hot file preamble; rollover
  archives the **oldest contiguous** checkpoint block slice into the next
  deterministic pack (same contract as `DEC-0042`).
- **`po_to_tl.md`**: a **section** is a top-level `## ...` heading; archived
  material moves oldest sections first into deterministic packs.
- **`architecture.md`**: a **story section** is a top-level `# US-xxxx: ...` or
  `# US-xxxx — ...` block; caps bound **lines** and **count** of such sections
  retained in hot file. Archive packs preserve **full** removed sections
  (history-preserving; aligns with `DEC-0043`).

### 3. Archive locations and pack naming

- State: `docs/engineering/state-archive/state-pack-YYYYMMDD.md` (existing
  pattern; append new packs; do not rewrite prior packs).
- PO→TL handoff: `handoffs/archive/po-to-tl-pack-YYYYMMDD.md`.
- Architecture: `docs/engineering/architecture-archive/architecture-pack-YYYYMMDD.md`.

When multiple packs are created the same UTC calendar day, append a
deterministic disambiguator suffix (`-a`, `-b`, …) or monotonic sequence
documented in execute/runbook (implementation detail; must remain stable across
reruns).

### 4. Same-phase rollover or fail-closed

When **either** line **or** section/story cap is exceeded at a mutating
boundary:

- The mutating phase **must** complete rollover **before** phase completion
  **or** stop with a deterministic reason code (no silent leave-behind of
  oversize hot files claiming success).

**Phase ownership (default)**:

| Artifact | Enforced completion gate |
|----------|---------------------------|
| `state.md` | `/refresh-context` (curator) — before marking refresh-context complete. |
| `po_to_tl.md` | PO-owned boundaries that append material (`/intake`, `/discovery`, and any command documented as appending to this file) — before that phase completes when the file is in scope. |
| `architecture.md` | `/architecture` (tech-lead) — before architecture phase completion when `architecture.md` is mutated. |

Any other phase that **mutates** one of these files assumes the same gate for
that run (explicit in command docs).

### 5. Verification tuple (mandatory on successful rollover)

Archive success must record deterministic evidence:

- `boundary` — phase id + story id (if any) where rollover ran
- `moved` — count of checkpoints/sections/story-blocks archived
- `retained` — counts (and optionally line totals) remaining in hot file
- `pack_ref` — path(s) to new or appended archive pack(s)

Reruns must be **idempotent**: if hot file already satisfies caps, **no** new
pack is required; re-invocation does not duplicate moved content.

### 6. Minimal-read and compact pointers (`AC-5` / `AC-6`)

- Each phase command documents a **default minimal read set** (canonical paths
  only) plus numeric **line/file budget** and a single escalation rule: expand
  only to named archive pack + anchor when a question remains unresolved after
  the default set.
- Optional compact pointer surfaces (implementation choice): thin
  `*-context.md` siblings or bounded header blocks in hot files that link
  `latest_decision`, `latest_sprint`, and `pack_ref` without duplicating full
  checkpoint bodies.

### 7. Reason-code taxonomy (minimum)

Use consistently across commands, runbook, and tests:

- `STATE_ARCHIVE_REQUIRED` — thresholds exceeded but rollover not performed.
- `STATE_ARCHIVE_VERIFICATION_FAILED` — tuple missing or inconsistent after
  claimed rollover (extends `DEC-0043` / `DEC-0042` semantics to triad).
- `ARTIFACT_HOT_SURFACE_OVERSIZE` — hot file exceeds policy caps at boundary
  completion.
- `CONTEXT_BUDGET_EXCEEDED` — phase read exceeded declared file/line budget
  without authorized escalation.
- `STATE_ARCHIVE_BOUNDARY_AMBIGUOUS` / `STATE_ARCHIVE_WRITE_FAILED` — retained
  from `DEC-0042` for ambiguous slice boundaries or persistence failures.

### 8. Parity and regression (`AC-9` / `AC-10`)

- Active/template parity for scratchpad keys, command contracts, runbook, README,
  and archive directory README stubs where packs are introduced.
- Regression hooks: threshold-crossing success path, oversize-without-archive
  detection, idempotent second rollover, bounded-read violation, fail-safe
  reason codes.

## Consequences

- Operators gain auditable, configurable caps across the three noisiest surfaces.
- Subagent default reads stay bounded; archives remain linked and
  non-destructive.
- Execute work must wire enforcement and tests; architecture and decision
  records define the contract only.
