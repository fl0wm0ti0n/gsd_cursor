## US-0102 — Direct per-phase model slug override and role-based catalog presets (US-0101 extension)
- user_visible: true
- Title: Extend US-0101 tier-based model selection with direct per-phase slug override and role-based catalog presets, while retaining 3-tier baseline
- Summary: US-0101 delivered per-phase `MODEL_TIER_<PHASE>` (cheap/balanced/strong) with Cursor alias mapping (fast/inherit) and optional local catalog. Operators now request a second axis: direct per-phase model slug assignment (`MODEL_<PHASE>=<vendor-slug>`) that bypasses tier indirection, plus role-based catalog presets (PO/SA/DEV/QA profiles per `ai_modell_auslegung_cursor_highend.md`) for curated model sets without manual tier mapping. The 3-tier system remains as default/fallback layer; precedence: `MODEL_<PHASE>` > `MODEL_TIER_<PHASE>` > `MODEL_TIER_DEFAULT` > Cursor alias. `/ask` phase reinforced with direct override support. Compose with US-0101/DEC-0086 (do not amend — US-0101 stays DONE). Backward compatible: tier-only configurations continue unchanged. No volatile vendor IDs in template files. New catalog schema v2 extends v1 with `roles` section. New contract tests `test_us0102_*` validate precedence, schema, backward compatibility.
